# 集成电路后端速览：设计规则、寄生 RC 与时序模型

数字后端将门级网表实现为物理版图，主要包括布局规划、供电规划、单元放置、时钟树综合和布线，并检查物理合法性、电气约束、时序及可靠性。

核心关系是：**版图与工艺信息 → 寄生电阻电容网络 → 结合单元时序库计算延迟与波形 → 检查设计约束。** 本文概述通用方法，不给出特定工艺的签核阈值，也不将公开模型等同于商业工具的完整内部实现。

## 1. 后端主要检查哪些规则

| 类别 | 典型检查 | 目的与主要依据 |
| --- | --- | --- |
| 物理设计规则（DRC） | 最小线宽、线间距、通孔包围、金属密度、天线规则 | 确保可制造性，依据晶圆厂工艺规则文件 |
| 版图与网表一致性（LVS） | 器件及连接是否与原理图或网表一致 | 排查开路、短路和连接错误 |
| 电气设计规则 | 最大负载电容、最大转换时间、扇出限制 | 保证驱动与接收条件满足库及设计约束 |
| 时序要求 | 建立时间、保持时间、最小脉冲宽度等 | 保证数据在规定时刻被正确采样 |
| 信号完整性（SI） | 串扰噪声、串扰导致的延迟变化 | 检查相邻网络切换造成的影响 |
| 供电与可靠性 | 供电压降（IR drop）、电迁移（EM） | 检查供电质量及导线、通孔的长期可靠性 |

物理 DRC 与电气设计规则是不同层次的检查。最大转换时间限制信号完成电平变化所需的时间（slew），不等同于门的传播延迟；扇出约束也可能采用库定义的负载权重，而不是只统计连接数量。

## 2. 电阻、电容如何计算

### 电阻

对材料与截面均匀的导线，基础近似为：

$$R=\rho\frac{L}{wt}=R_{\square}\frac{L}{w}$$

其中，ρ 为电阻率，L、w、t 分别为长度、宽度和厚度，R□=ρ/t 为方块电阻。线越长，电阻通常越大；截面越大，电阻通常越小。

实际提取还需要工艺模型中的有效尺寸、温度依赖，以及通孔和接触电阻。不能用一个固定电阻率覆盖所有层和工艺条件。

### 电容

时序负载包含接收单元的输入引脚电容、连线寄生电容，以及适用的外部负载。引脚电容通常来自单元库；连线寄生电容由版图提取获得。

平行板近似为：

$$C\approx\varepsilon\frac{A}{d}$$

其中，ε 为介电常数，A 为相对面积，d 为间距。实际互连还存在边缘电场、侧壁和跨层耦合，不能只用平行板公式准确计算。

- 对地电容：导线与参考导体之间的电容。
- 耦合电容：不同信号网络之间的电容；相邻网络的切换关系会影响噪声和有效负载。

因此，连线电容取决于线宽、长度、层厚、间距、介质，以及附近导体和金属填充等环境。延迟计算中使用的有效电容也不一定等于所有电容数值的简单相加。

## 3. 商业工具如何提取寄生 RC

寄生参数提取（PEX）读取版图几何、网络连接及工艺提取模型，将互连分段，生成包含电阻、对地电容和耦合电容的网络。典型工具包括 StarRC、Quantus 和 Calibre xACT；数字时序流程常以 SPEF 交换寄生参数。

常见提取方法包括：

1. **基于规则或模型提取**：根据局部几何和工艺数据使用参数化公式、拟合函数或查表模型，适合大规模设计。
2. **场求解**：根据几何、材料及边界条件进行数值求解。电容提取可通过求静电场与导体电荷，建立电荷和电压的关系，得到电容矩阵。

两类方法可以配合使用，例如先用场求解器计算典型结构，再建立全芯片提取模型。具体组合取决于工具、工艺和精度要求，不能断言所有商业工具都采用同一算法。StarRC 的公开说明包含内置 Rapid3D 场求解器。[1][2]

## 4. 时序工具采用什么模型

路径传播延迟由单元延迟和互连延迟组成。STA 工具读取连接关系、单元时序库、寄生参数与约束，计算每一级的延迟和输出转换时间，并向后传播。[3]

| 对象 | 常用模型或数据 | 基本方法 |
| --- | --- | --- |
| 标准单元 | Liberty（通常为 `.lib`） | 描述时序弧、引脚负载、延迟、转换时间和时序检查约束 |
| 单元延迟 | NLDM，非线性延迟模型 | 通常以输入转换时间和输出负载电容为索引，查询延迟及输出转换时间表，并插值 |
| 单元驱动与接收 | CCS，复合电流源模型 | 用输出电流波形及接收端模型结合互连网络求波形，描述更细的负载响应 |
| 互连延迟 | 提取后的分布式 RC 网络 | 使用有效电容、网络降阶或其他数值方法计算；Elmore 可用于基础估算 |

时序库一般由提前进行的晶体管级仿真表征生成，区分工艺、电压和温度（PVT）。STA 复用这些模型，避免每次分析整个芯片都做完整晶体管级瞬态仿真。CCS 相比仅存储延迟和 slew 的表模型保留了更丰富的波形信息。[4]

基础 RC 树的 Elmore 时间常数可写为：

$$\tau_i=\sum_{e\in\mathrm{path}(root,i)}R_e C_{\mathrm{downstream},e}$$

即对到目标节点路径上的各段电阻，乘以其下游总电容后求和。该表达式假设树形电阻网络及对地电容，是一阶估算；不能直接视为任意波形的精确 50% 传播延迟，也不能代表完整商业签核算法。

## 5. 静态时序分析如何判断是否通过

静态时序分析（STA）在时序图上传播最早、最晚到达时间，根据时钟和约束计算要求时间，并报告裕量（slack）。它不依赖功能仿真的输入激励，但需要正确的时钟、输入输出条件和路径例外。

- **Setup（建立时间）**：在采样边沿前，数据必须提前稳定；主要限制数据路径的最大延迟。
- **Hold（保持时间）**：在采样边沿后，数据必须继续稳定一段时间；主要限制数据路径的最小延迟。
- **Setup slack = 要求到达时间 − 最晚到达时间。**
- **Hold slack = 最早到达时间 − 保持要求时间。**

对应检查中，slack ≥ 0 表示满足要求，slack < 0 表示违例。实际分析还需考虑时钟插入延迟、偏斜、不确定度，以及适用的片上变化模型；在多个工作模式、PVT 角和 RC 角下分别检查，不能只检查单一典型条件。PrimeTime、Tempus 是常见商业 STA 工具。

## 6. 工具与数据的整体关系

```text
门级网表 + 物理库/工艺规则
             ↓
     布局、时钟树、布线
             ↓
     版图 + 工艺提取模型
             ↓
      寄生 RC 提取 → SPEF
                         ↓
门级网表 + Liberty 时序库 + SDC 约束 + SPEF
                         ↓
          STA：延迟、slew、setup/hold、裕量
```

物理 DRC/LVS、信号完整性及供电可靠性检查与该流程协同进行。RC 提取提供电气网络，时序库提供单元模型，SDC 提供设计要求；三者不能相互替代。
