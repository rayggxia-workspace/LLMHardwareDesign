# 可编程控制与搬运 v1（Issue162）

任务 [#162](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/162)。SystemC先行提交已在 [PR146](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/146)，commit `65f9741a0e0a5eecf4d77338e107486e9b585a72`。本分支基于合入六宏的 main `4b1df2c7cbdaa0fa6f9f468f2b5b854cec875609`，不改 M/N/E/G/S/T 已验收 RTL；R 保持未完成、控制端点禁用。

## 本轮交付目标

实现 C 可装载指令控制宏、D 外存/S搬运宏、M/N/E/G/S/T 块旁适配器、固定控制链路和真实有限数据路径，并分别完成300MHz最终物理验收。单独CPU脚本发命令不算硬件控制，测试程序替硬件搬数据不算组合实现。

验证顺序：控制/描述符ABI和参考模型 → 有限队列及错误/背压RTL → 外存→S→M→结果、S→N多遍回放、S→E/G→T或S → C/D及适配器布局布线 → 真实M10内部接点接入和M11/M12布线证据。八模型代表控制轨迹是接口充分性检查，不是整模型整数质量或速度结论。

## C

64bit指令、256条程序、16×32 GPR、8×40地址、四层32bit循环、16×256描述符、32完成槽、16排他租约。一条任务8个32bit flit；完成2个32bit flit。endpoint4bit，首版 D=0/M=1/N=2/E=3/G=4/S=5/T=6/R=7。tag16bit=11bit代次+5bit槽。完成槽只有WAIT/WAIT_ALL/FENCE/END消费后释放；WAIT期间完成接收持续可用。调度为顺序发射、异步完成，首版每个缓冲区保守排他，程序禁止资源等待环。

指令编码 `op8|rd4|ra4|rb4|flags4|aux8|imm32`，数值与PR146 `control/abi.hpp` 一致。C内部配置口是有效/就绪的32bit请求/应答，完整AXI-Lite32数据/16地址包装待接入。编程期间必须停止且已排空；内存内容不依靠复位值。程序低/高32bit分别有有效位，描述符未写字由有效位返回0。

配置地址：0x0000版本，0x0004启动/空闲复位（bit0启动、bit1复位、[15:8]入口PC），0x0008状态，0x000c错误PC/当前PC，0x0010提交计数，0x0014完成计数，0x0018停顿计数，0x0040..007c标量，0x0080..00bc地址寄存器低32/高8，0x1000..17fc程序，0x2000..21fc描述符。内部口仅接受对齐的完整32bit写，其他返回错误；AXI-Lite包装必须保留此错误语义。

当前首轮 RTL 包含 C 核和两任务/两完成块旁队列，尚未通过验证。LOAD_META预留，不能绕过真实DMA读取。当前端点收包另有一份256bit组包寄存器，必须计入面积，不称总共只有两份存储。物理输出不授予系统资格，全部门通过后才列合格。

## D 与适配器目标（待实现）

- AXI4 master 地址40/data128/WSTRB16/ID2，INCR最多16beat，4KiB切分；读/写各两项在途，各32×128数据FIFO；各两项描述符队列。
- DMA包含40bit外存基地址、4bitS实例、14bitS字节偏移、24bit行字节数、16bit行数、32bit外存步距、16bitS步距。S无字节写使能，分配按16byte padding，外存写尾使用WSTRB，读尾清零；有效长度独立记录。
- D完成：load必须在真实S写接受后，store必须收到AXI B。错误停止新增任务并排空在途，不承诺回滚已写外存；系统复位协调总线和端点一起排空。
- S窄128与宽512共享实际端口，宽读独占四bank，首版相位互斥；不能藏一个双口或测试程序预装载旁路。固定空间16KiB不足长N，需有限外存窗口回放并保存同一统计上下文。
- M保留原A128/B512，块旁从S供数并发命令、收结果；N调度统计/EXP/最终回放和尾lane；E持有3输入包；G128分成4个双lane包、处理尾元素；T使用原begin/fill/commit/drain/release语义。
- metadata需真实读取、范围检查和地址映射，MoE动态ID不能当数据已搬完。未合格R不调度。

## 物理和资源边界

300MHz、0.1ns不确定性、原有驱动/50fF负载/IO延时合同保持；M1–M10为宏内固定，内部M10接点。宏间固定逻辑控制拓扑不意味着可穿越已固定宏内部；走M11/M12的公共控制线也计入顶层容量、缓冲和RC。

服务器只经Slurm。最多6～8个本任务节点，可用c96节点13–18/25–26（不使用19–24），有独立工作时按6×16动态补位。初轮只有C和队列两项ready，因此申请同节点32CPU/两项各16，保留核数给真实工作，不造任务填满。后续D、适配器、组合、DRC/功能/LEC形成队列后扩展；内存不足需保存实际available/RSS与并发预算依据。不得取消或改动其他任务。

最终必须保留 RTL/工具/约束SHA、真实最终STA及电气、fresh SPEF覆盖、PG/连通、完整原生与GDS DRC、最终网表三初态功能、严格LEC、六文件/图及哈希。综合/CTS/route完成不等于合格，失败版本保留并迭代。
