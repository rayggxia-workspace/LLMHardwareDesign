## 布线分析包

`ref-project/llm-routing/` 是四个参考项目、六个案例的轻量结果包。首先阅读其 `阅读说明.txt`、`report.md` 和 `index.html`；包内 `package_manifest.json`、`source_manifest.json`、各案例 extraction manifest 和 provenance 文件记录已有的来源与校验信息。更新图表或统计前应保持这些记录与文件一致。

该结果包**不含**原始 ODB/DEF/GDS、全量网表／几何、源代码、工具环境和完整运行日志。因此目前可阅读报告、重新汇总已保存的表格并核查文件完整性，不能只凭此仓库重跑物理实现或独立验证几何。原报告提及的远程原始工作目录属于当时环境；其现时可访问性、代码版本、工具配置和数据版本在本次接入中**未核实**。
