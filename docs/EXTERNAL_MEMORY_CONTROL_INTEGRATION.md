# #156 与 #162 搬运边界

Refs #156；PR159。核对 #162 PR163 `3fcb9770aee91b51cf965fe38627aac501e1a7f1`、#155 Issue 最新公开状态（SRAM完整S物理验收仍待）。本文件不修改其工作树、作业或生产选择。

## 实现选择

系统装配采用 #162 的 `control_d`，不再并列实例化 `finite_dma`。后者保留为独立、已综合的合同参考及M/N/R回归基线；不是AXI子模块，不可直接替换D的planner或transport。复用的是S实际req/ready、valid/take和写应答语义、有限资源回归用例，而不是把两套DMA面积同时计入系统。

| 项目 | finite_dma | #162 D |
|---|---|---|
| 外存 | 32bit、128bit顺序逐字响应 | 40bit AXI、ID/burst、4KiB切分 |
| 信用 | LOAD四字含响应与待S写确认 | 每方向两burst、32字payload，按S确认/AXI B回收 |
| 描述符 | 单活动、完成保持 | 每方向两项队列、tag完成 |
| 错误 | 继续整个描述符并报告失败 | 停止新增burst，排空已发在途；不能声称传完整描述符 |
| T | 直接流出 | T适配器先DRAIN到S，再D store |

`project/experiments/external_memory/control_descriptor.py`只提供软件描述符转换：S字地址/步距乘16、cols乘16，生成CONTROL_V1 W0..W7；C分配tag。拒绝T直流、非法范围和截断，不引入第二套硬件DMA。转换不是总线适配器或组合RTL验证。

## S、所有权与信用

这里“双S”指标准单元S和SRAM S两种可替代实现，各16KiB，不是已实现两个S实例。#162 planner显式拒绝非零实例；不能删掉instance检查或把ID1别名到ID0。未来双实例需另加真实路由、隔离及验证，本轮不宣称支持。

两种S都以请求接受和真实响应消费推进，不固定等待拍数。一次写的req/ready不代表完成，必须valid/take收ACK；SRAM附加响应级和含在途的响应槽不增加容量。读取/写入都持有实际普通口owner到响应消费；交接前排空旧owner请求。普通口与原生feeder竞争真实bank，不能另造RAM端口。

程序/调用方取得目的区间排他租约后才LOAD；LOAD完成才允许计算读。源区间STORE完成前禁止覆盖。并发补料只用不重叠且已取得所有权区间。#156夹具的CPU/DMA选择器不是系统仲裁器；系统使用#162固定仲裁与C租约。S供数完成只表示M收齐操作数，不表示GEMM完成。

背压时请求、响应、完成和payload保持；信用包含已接受未回收事务，不能只数FIFO现有字。LOAD到S写ACK才回收，STORE收到写响应才完成。错误不回滚，整个目的结果失效；响应继续消费以释放在途。无响应/错误RLAST等协议破坏不能假定总能自行排空，需要平台恢复，禁止无限等待被称作成功。

复位必须协调DMA、平台外存队列、S响应、适配器、完成队列及租约；没有epoch过滤的单独DMA复位不能安全接收旧响应。复位不清除S/外存旧数据，不提供数据回滚。

## T 生命周期

begin/fill/seal/commit后才能drain。#156直流只有最后外存写ACK后才release；长度不符可能需协调复位。#162替代路径：T DRAIN到已独占S暂存区，等S写ACK；D STORE该区；等对应tag成功完成；再T RELEASE并归还S租约。DRAIN完成或T read_last不是外存写成功。若外存写失败，可保留S副本以便显式恢复；不得标成功、提前复用S或默默释放唯一副本。

## 状态物理归属及验证限制

| 状态 | 物理归属/责任 |
|---|---|
| AXI在途、payload、搬运游标 | #162 D；不能靠M11/M12生成 |
| 程序、描述符、tag、租约、完成 | #162 C及端点队列 |
| S端口owner、待响应选择 | #162 S仲裁器 |
| N/E/G分包、M命令、T读写游标 | #162块旁适配器 |
| S存储/响应槽及M供数状态 | 被选择的S实现 |
| M累加、N统计、R状态 | 原宏；R仅#156隔离回归，不授权系统发射 |
| finite_dma FIFO/游标 | 独立参考RTL，系统D替代后不实例化 |

#156真实M/N/R计算经过原RTL，数值oracle独立；但S→N/R命令桥、结果回写、参数装载、分窗顺序和M打包仍由夹具承担。不能引用其通过证明#162已实现R或无需主机搬运。#162组合的M/N/E/G/T能力以自身实际回执为准，本轮不授予其物理资格。

软件仍负责模型分块、列优先B打包、描述符/程序编译、租约无死锁安排、T与STORE依赖、失败结果丢弃和平台恢复。DDR/HBM/PHY/CDC仍属平台。本任务只交RTL、综合、接口及验证；不扩大到系统P&R。SRAM接口模型与真实#155银行/完整S物理证据严格分开。
