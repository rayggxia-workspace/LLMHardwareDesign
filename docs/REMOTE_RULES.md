### 节点与任务安排

| 节点编号 | 类型 | 使用限制 |
| --- | --- | --- |
| 1–12 | c64 | 根据当前排队情况选择 |
| 13–26 | c96 | 根据当前排队情况选择 |
| 其余节点 | 96 核 debug 节点 | 任务时限 30 分钟 |

可根据排队情况灵活选择节点与并发配置。可利用 Python 脚本在一个节点内并发执行任务；例如，c96 节点可采用 8 个任务各使用 12 核，或 5 个任务各使用 18 核等配置。并发任务的总用核数应控制在实际分配的资源内。

### 提交任务准则

通过 `sbatch` 提交任务时，脚本中的任务名（`squeue` 显示的 `NAME`）必须采用 **`本人姓名缩写-任务缩写`** 格式，例如 `hpy-block`、`lrz-route`，便于辨认提交人和任务用途。使用本人姓名缩写，如 `lrz`、`hpy`。

在提交脚本中设置，例如：

```bash
#SBATCH --job-name=hpy-block
```

若提交时使用 `sbatch --job-name=...` 覆盖脚本设置，最终任务名也必须遵守上述格式。
