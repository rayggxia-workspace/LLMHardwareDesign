# 0002：openTPU 同资源物理对照采用共同映射网表与分层提取验收

- 日期：2026-10-22
- 状态：proposed（本轮工程约定已执行，待PR独立审查，不是产品底座冻结）
- 决策负责人：@YUZE-LU
- 关联：[Issue #15](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/15)、[PR #17](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/17)
- 替代记录：无

## 背景

ACT／MXU拆分和合并若各自综合，会把逻辑剪枝收益与物理边界代价混在一起。实测合并物理导入还会额外删除135单元（含9DFF），单看Yosys映射库存或进程成功不足以证明同资源。硬宏模型也没有充分表达全部内部周期约束，父层模型时序不能代替完整路径。

## 决策与原因

1. 以同一冻结ACT和MXU映射网表为起点，合并只接线和展开；初始169109单元逐型号核对，并在实际ODB导入后再次核对。固定37023 DFF、12个同型号SRAM和相同接口，不新增流水／缓存／串行化。物理缓冲、时钟树与驱动规格的变化作为边界工程开销单独计入。
2. 块内实际路由限制到M9，为父层共同M10供电保留资源。配置声明不足以证明生效；GRT前显式重置范围，GRT日志和终态详细LEF双核验。完整宏OBS保留，父层PG只剔除确实与其冲突的新增通孔位置，再做原生连通性检查。
3. 外部统一2.5ns／0.5ns预算、BUF_X4输入驱动、5fF输出负载；两组采用共同die和实际外部引脚几何。真实有符号cap／slew余量、setup／hold、DRC／天线和PG分别验收，不能以计数0或作业COMPLETED替代。
4. 在父层提取后恢复真实子块网表，以分层SPEF拼接检查完整路径，只保留原外部SDC。该流程已通过透明ACT包装误差<1ps自检；各块WNS不能相加。物理前后功能用保守逻辑锥证书核对：归一化BUF／INV抵消和驱动规格，逐个比较状态输入和外部输出，并使用状态输入突变负例验证检出能力；不支持的逻辑变换保守失败，不冒充一般RTL形式等价。
5. 每轮独立目录、提交前固定runner身份，封存输出及SHA；所有作业UNLIMITED，无耗时取消条件。实际违例用新尝试继续修复，不覆盖失败证据，也不放宽外部预算。

## 考虑过的其他方案

- 重新跨块综合可以作为之后的优化上界，本轮会改变比较资源，故不作为严格主表。
- 隐藏宏的M10 OBS会掩盖真实几何冲突；改为重新实际布线预留M10。
- 父层只用宏Lib时序无法覆盖所有内部路径；采用真实网表与分层SPEF，并保留宏模型结果供诊断。
- 为减少cap违例而冻结已升级BUF，已实测触发InsertBufferBeforeLoads冲突；驱动升级可继续优化，保留质量检查。

## 影响与验证

本轮是H1分层工程对照：允许新父层有源缓冲及PG资源，目标是测清硬边界代价。依据[项目定义§3.4](../../预制计算底座项目说明_v1.0.md#s3)，H2同一预制底座还要求晶体管、缓冲、端点、时钟／电源资源与固定几何不因目标变化。当前父层允许M2–M10信号路由，不能宣称仅少量高层定制已经实现；后续需要预制端点驱动／接收缓冲库、固定时钟和电源、声明定制层并核对固定几何。

面积同时报告不含填充的叶单元面积、父层标准单元、硬宏占地和共同die；宏占地不与其内部叶面积重复相加。信号线与通孔分块内／父层及金属层统计，PG独立审计。synthetic SRAM没有真实GDS，上游RTL到物理等价与制造签核均未完成。实际数据和证据入口见[实验记录](../experiments/issue-15-opentpu-comparison.md)。改变本约定时新增记录，不改写封存实验。
