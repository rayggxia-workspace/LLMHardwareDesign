# 0004：缺失历史父层时建立独立受控接入基线

- 日期：2026-10-27（中国标准时间）

- 替代记录：无；不替代历史来源或PR120坐标

## 背景

已检查的资料没有建立原始ACT-cap20/MXU-cap20等叶块版本匹配的逐pin历史handoff/实际穿层序列。ACT两个fakeram没有匹配的器件级GDS。用户确认没有额外材料，并明确授权“如果必须，请你自行补充即可”。

## 决策与原因

保持历史未知，不指派虚构的原M8接入。基于已核实的Issue55冻结三叶块图、真实叶块ODB/LEF及逐bit连接，创建 **NEW_CONTROLLED_PARENT_NOT_HISTORICAL**。新父层固定R0位置、外框、顶层接口坐标、连接对象与层级、允许层集合及实际生成的PG；A/A_replay/Aopt/B/C只替换真实已重接叶块视图并重接相关父层网络。宏平移采用M5/M6真实0.28μm轨道节距，避免人为错轨。其signal M2–M10/clock M4–M10是显式的新基线策略，不能冒充缺失的历史策略。

每条连接的叶端口保持真实原M5/M6层；新TOP_IO采用已记录的对端多数层策略，常量或未用声明位单列新策略。其后实际路径/via由数据库检查，不统一要求所有端口上M11/M12。

原openTPU有37个常零顶层声明位a_we/a_wdata/a_be；它们原本就是TOP_IO基础设施，不是遗漏的第四个硬宏。新父层使用37个独立LOGIC0_X1驱动，实现相同功能并避免把所有0字面量误并成物理网。所有对照固定相同实例、规格和位置，明确单列其成本。六块原信号接口不增删，不增加顺序状态或缓冲器。

端口占位Liberty只供物理链接/路由；零电容不是表征值，不用于父层STA、电气、功耗或资格结论。原叶块RC/STA、基线失败继续独立保留。不能通过补建几何GDS声称真实SRAM器件、LVS或生产签核；优先从真实ODB补导所需视图。

## 影响与验证

每个新父层保存完整源图/端口/坐标/层级合同、输入与源码SHA、实际工具输出、独立native DRC、OpenDB几何连通和PG检查。新PG只在A建立并经检查后冻结给后续方案；不得通过删OBS、降低规则或关闭检查来制造通过。

首轮r01因未切行的宏halo失败；r02切出实际halo后，直接M7→M10 PG接入被实际OBS阻塞；r03增加中间局部PG条带仍被默认抽象阻塞。均保留失败和拒绝后续晋级的证据。

实际工具Tcl显示默认write_abstract_lef的bloat_factor=10。r04复用项目Issue7/H1的bloat_factor=0详细OBS导出，并检查尺寸、全部信号/PG pin原文及占用层保留。这改变抽象粒度，不改变DRC规则；它本身不是全部导体覆盖或接入通过证明。r04的真实PG检查已发现新增M8/M9条带与原宏金属冲突，尚未通过，不提前晋级。

独立受控父层能验证具体补建基线中的接入性，不能追溯证明缺失历史父层，也不能替代完整层次GDS/LVS、宏器件模型或系统STA。

后续r04已在确认PG短路后停止该无效变体；r06直接M7→M10堆叠，按实际M7/M8/M9/M10 OBS筛选**新增父层**通孔站点，保守2μm保护大于上述层已读规则表最大1.5μm，双网PG连通通过。但逐端点检查发现转义标量不能正确映射ACT/MXU真实bus，只有3607/6618端点接入，故停止该新无效试验并保留失败。没有取消他人作业，也没有按耗时终止。

r07改用真实Verilog向量端口、Liberty bus/type和LSB位序合同；在PG及路由之前执行原生端点导出与独立连接图检查。实际6618端点、3408条独立网、方向及原叶端层全部匹配；双电源检查通过，正在真实详细布线。llaccel另有27050端点的独立父层基线92458。完整输入合同入库，所有后续变体必须由A的独立DRC/连通/PG通过才能晋级；不得以stub Liberty报告父层STA通过。
