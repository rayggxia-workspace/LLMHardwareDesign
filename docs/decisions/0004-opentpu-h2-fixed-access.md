# 0004：H2 首个切片固定 V7 接入与低层连通关系

日期：2026-10-23（Asia/Shanghai）；[Issue31](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/31)。状态：实验取舍，独立整合 DRC 待终态、审查待指定；不是项目通用制造架构定案。

H1 的 ACT/MXU 同资源实现允许父层新增缓冲及自由布线，不能直接作为少量上层定制的证据。H2 v01 从其实际最终物理库存开始：先记录接口电气／时钟／接入预算，冻结全部有源、引脚、PG、时钟、低层 wire/via 和既有 V7，再只改变 M8–M10、V8/V9。

不能在冻结后靠修复驱动补预算。真实回装的前两轮虽上层 DRC 0，仍出现电容超限，说明上层路由问题必须保留低层已连接的网络拓扑。最终将原上层分解成 1,003 个两接入点的森林，固定低层连通分量作为预付的导体，不绕过它们另建全网连接；二部图证明恢复 690 个逻辑网，再由真实几何连通图和完整 RC／分层 STA 验收。接受的是新的实际几何，而不是仅凭逻辑网名的连接。

代价是强目标条件化：原父层约 92.50% 中心线已经冻结。此切片不能证明多计算图、任意接口重排或通用底座。若未来要求更强复用，须在第二图布线前制定独立接入模板及版本，不修改当前合同来吸收失败。驱动、落点或低层线变化都属于新底座版本。

块内 M8/M9 仍固定，但普通顺序制造时属于定制后的固定图形；不得把几何不变等同于已提前制造。M8–M10 和 V8/V9 是允许改变的层集合，不是 PDK 已确认的 mask／工序数量。详细证据和失败记录见[实验记录](../experiments/issue-31-opentpu-h2.md)。
