# 0006：母控复用同一物理实现验证两种程序格式

状态：已实施并通过所列工程门，待代码审查。日期：2026-11-08 CST。

关联 [Issue #223](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/223)、[PR #224](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/224)。

## 决策

固定 #180 `81663a1e…` 的母控 RTL，原生 ABI 绑定 `0x01930001`，以四颗真实 SRAM bank 实现独立16KiB母控程序存储。保留现有两个驻留目标、八token、每端单在途限制；不将有限原型表述为九局控母控。

取指 RTL 根据镜像版本动态选择128位指令（v1）或64位指令（v2），PM口均为128位。先完整接收64位物理与Block证据，再用同一份最终网表执行128位程序，并切换各Block对应的128位局控RTL。两格式的六文件SHA-256相同，STA没有格式case约束，故复用同一物理资格；功能资格分别验证。保留物理cell名`mother_control_64`，产品清单明确128是该cell的另一已验证程序格式，不宣称第二份独立物理实现。

已有Block局控分别来自不同冻结源，保留其已验收语义，通过相同消息端口和真实程序核对兼容性，不为追求版本名称统一而整体替换。U使用#221已验收31文件锁。组合夹具的局控程序存储为行为模型；五类功能宏和私有S不因母控实现而改变物理边界。

独立fresh路线检查若报告单网的小范围标记，仅当其整区同时被该原网的ODB线段和实际GDS铜覆盖时，才能记录为已证明的几何重叠误报；完整原始报告保留。任何多网/未覆盖/其他规则不予这样接收，原版完整GDS规则仍须独立为0。反向控制必须证明缺少任一侧证据会拒绝。它不是规则豁免。

## 结果与限制

两格式各54项RTL、54项母控最终网表、69项Block组合通过，工程数值及来源见[验收报告](../experiments/mother-control-dual-format.md)。整体LEF/Liberty用于表征母控验收候选，不重新定义P/U/C/F/J的物理封装边界。

当前资格为独立TT300MHz母控及有限Block/局控RTL组合。九实例控制扩展、局控PM实际集成、母控到局控真实线负载/时序、全芯片CTS/PG、M11/M12接入和完整模型程序另验。改变母控有源RTL、实际库/负载或物理六文件时，应重新执行受影响的门，不能沿用本资格。
