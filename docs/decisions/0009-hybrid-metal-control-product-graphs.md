# 0009：金属编码粗控制表与局部握手的混合主候选

- 日期：2026-11-03（Asia/Shanghai）
- 任务：Issue151 / PR152，Melodydt
- 状态：用户确认研究目标与主候选；实现、数值质量和物理冻结待证据
- 总方案：[HYBRID_METAL_CONTROL_PLAN.md](../HYBRID_METAL_CONTROL_PLAN.md)

用户要求共同有源底座冻结后仍能为此前未列出的合法执行图制造永久绑定产品，不启动下载控制程序。只预存全部既知产品程序并用金属选入口，不能保证该目标。

选择“金属编码粗粒度层序/任务表＋固定共同母顺序器/资源管理＋预制端点与真实stored ACK/局部令牌握手＋固定岛内程序”作为主候选；预置家族模板为基线，纯令牌为主要对照，金属逻辑阵列/OTP/独立控制器保留条件路线。

冻结的是全部有源计算/存储/控制、指令语义与资源边界，产品改变有限控制内容及合法路线。禁止逐图重新综合父FSM、增删宏或插buffer冒充同一底座。金属可编码存储不是已有普通ROM的免费属性，须独立证明位单元/读出、编码容量、landing/扇出与布线。

新图仍须经过语义、实现、资源映射、物理及质量的独立门；缺口保持GAP。H1先形成有界图IR、三种不同图执行表/生存期和预算；H2/H3以同RTL证明多图/重入/分支/反馈，H5接收至少两种同底座金属产品。L4质量、R/NUM、MoE、MEM及完整物理不被本决策豁免。

本次只更新方案与交接，既有运行源/回执不改，不赋予RTL或物理资格。
