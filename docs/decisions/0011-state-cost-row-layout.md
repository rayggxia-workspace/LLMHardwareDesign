# 0011：对原生事件重叠和多行布局分别保存可检查证书

2026-11-09，Issue #219 / PR #220，状态：实验原型，系统/产品资格未完成。

既有完整服务预约掩盖了独立 M/E 的可并行工作；另一方面，直接把多个元素改成多行，会改变 S 中记录的排列并引入实际重排。
两者都不能用修改一个静态 ticks 或默认免费片上传递来表示。

采用以下接口与证据边界：

- 事件重叠保留 actor 内原生事件/有限 S 顺序，单独生成绑定具体通道的 DAG 调度证书；图覆盖首次集成仍预约完整资源并集到最终 ACK。
- 多行原型保留逐元素来源，真实布局、外部备份、保护字和 B 银行进入状态；每次动作重新生成并计费命令/搬运。
- 跨私有 S、同 S 重新排列均须有实际动作。没有资格的局部复制或候选上层连接不进入合格映射。
- 保留所有原候选与强基线，新增后端能力对双方开放；共同后端收益、搜索独有收益、局部与整模型结果分别报告。

结果及负证据分别见[迭代19](../../work/YUZE-LU/219/throughput-opt/ALGORITHM_ROUND_19.md)和[迭代20](../../work/YUZE-LU/219/throughput-opt/ALGORITHM_ROUND_20.md)。
当前多行原型固定操作优先顺序，不是任意 DAG 调度与分片的联合优化。后续需据实际搬运负结果扩展就绪节点/分组前沿，不能将更紧估计或更多搜索次数本身称为收益。
