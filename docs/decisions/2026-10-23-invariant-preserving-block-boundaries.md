# 基于单位、范围与状态不变量细化Block候选

2026-10-23；Issue61/PR62；状态：有实测切片支持的候选取舍，未冻结最优库/数量/连接，未PPA验收。继续沿用M/V/A/R/S/D模板和D1–D6，不新增免费算术或存储。

## 问题与证据

算子名称相同不保证接口数值合同相同。新Qwen2.5/Gemma/Qwen3.5主测420线性、56注意力格式条件，以及既有Llama数据，表明激活K组scale、概率精度、KV单位和state生命周期会改变可合法合并的范围。[报告](../experiments/issue-61-server-models.md)与[数据索引](../../project/experiments/server_models/results/issue-61/index.json)记录原条件和失败。

- down_proj动态K128 A通常明显优于单行scale；W128相对Wout增益有限且依模型而异。Gemma其他投影仍有输出饱和，Llama原5.39%失败不被覆盖。
- 注意力P8会丢失低概率贡献；Qwen2.5即使P16，KV8误差仍约12.50%，KV16/P16约0.58%。不能以单一KV8/P8合同固定所有模型。
- 混合scale线性粗界可超32位，但结合固定W和所见单位，所测16输出都存在32位充分界。PV粗界44位也不等于必须44位：归一化Psum、固定Vscale和limb前缀界可使所测条件全程32位安全。
- Gemma窗口逻辑量不等于prefill底层分配量；低位字节少也不保证端口/周期更少。

## 两种可检查的条件证明

线性固定W：对每个输出和实际scale单位，用Σg127·Σ|W8|·2^(unit_g-e0)+|bias_aligned|作充分界。范围需在提交新scale/state版本时核验；守卫未通过必须使用声明宽路径、缩小合法范围或拒绝，不允许饱和后假称等价。当前420条件全可32位，但未覆盖整层所有输出/未来scale。down的16输出L1表约4.5–5.5KB，可与W scale驻留；在线算术与端口仍待实现。

归一化PV：f=P有效分数位，ΣPcode≤2^f+ceil(activeK/2)+1；在同一V单位下，三limb的加权绝对界≤41024。最长4128key的预算34833使limb每个前缀的绝对和<2^31。90046已执行1474560个完整PV I32输出并匹配I64，而非仅观察无溢出；语义证明和实际执行两者分别记录。

该PV合同要求非负P码、归一化/量化规则、窗口/因果有效长度、固定head Vscale和Psum守卫。它不适用于online softmax未归一化O、不同页单位相加、任意长度或尚未证明同样性质的整数exp/div。40000key边界测试明确不能无条件认证。宽旁路保留，不据此宣布64位一律多余。

## 必须继续验证的最小分叉

1. E1输出合同：只针对Gemma已有饱和、Qwen3.5 RQ主导和Llama既有5.39%失败，对输出scale/格式及范围守卫做配对；不先扩模型/上下文，也不看Phi调优。
2. E2b同数值/资源：完整attention包含QK、exp/归约/除法的明确候选实现、Psum守卫、limb移位相加、KV端口与真实因果packet，比较局部闭包与合法跨Block合同。先过数值，再报告周期；避免把聚合32步decode当一个包。新模型账本只是下界，不替代该调度/RTL。
3. E3复用Qwen3.5连续状态，冻结更新格式，比较同资源局部R/共享V并叠加其他请求，核backing与1RW；不重复长模型推理。
4. E4与其他成员物理工程对接的是冻结端口/库存和剩余一对候选；未取得同工艺时序/合法接入，不写芯片端到端收益。Phi封存只在策略/阈值/源码冻结后一次独立验证。

取舍原因：当前证据最支持“先保持合法数值/状态闭包，再比较物理分区”，不支持按算子名切块或固定全8位。最小实验的单位是能翻转D1–D6的条件，不是模型数。执行与后续研究边界见Issue61交接。
