# Llama跨模型验证：scale粒度先于不可绕过硬边界

Issue56，2026-10-23。依据[实际报告](../experiments/issue-56-llama-cross-model.md)。

一组完整GQA4共享KV可以复用现有整数语义，不能据头数倍增固定硬件或复制持久KV。
Llama的norm/RoPE与d64由参数/调度承载，未得到必须新增模型专用Block的证据。

当前down_proj的校准静态A scale把约99.8%输入置零，局部输出误差70%–83%，即使零裁剪/溢出/最终饱和。
逐行动态scale改善但仍有6%–17%局部误差，不能当全模型质量通过；原参数/失败均保留，不调评价输入找有利值。
反量化消融提示大误差已在RQ前，不应靠换最终RQ位置掩盖输入量化问题；该诊断不是硬件成本证据。

不冻结单一静态A格式，不把离线浮点scale编译假定为免费在线硬件。
更细K组scale若被采用，将改变部分和单位与重定标/宽归约需求；完整K INT32内留只在同乘积scale条件下成立。
下一轮最小实验应比较校准/转换粒度及其端口/元数据/宽算术成本，再决定近M或共享V重定标。

384服务对照和等自由度策略包络最大约0.405%周期降低，小于未校准实现不确定性；保留typed INT32旁路和候选RQ位置。
K8192/16行预装容量拒绝显式保留，8行retile只是当前固定bank分配下的可行选择，不外推模型不可能或最优。
原始完整浮点输入仅本机保存并索引，共享pending；小包可复查全部编码整数核心及保存witness，不能假称所有原始输入已远端共享。
