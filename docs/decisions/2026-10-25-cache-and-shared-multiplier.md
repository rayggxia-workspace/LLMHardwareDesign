# 有条件A缓存与共享S32乘法器候选

Issue84实测84条完整整数消费者逐位相等，详见[报告](../experiments/issue-84-cache-share.md)。在当前K512/8expert/H1536、单16KiB1RW、M→Norm串行与固定一步SFU下，优先保留4KiB A缓存及一个共享S32服务：安静周期减少34.68%，logic-only面积净减少10.38%，外部线传输减少49.20%。不再优先追加四步SFU作为默认。

固定语义：全K INT32、带单位RQ、S64 merge/残差和完整行归一化保持边界；A/W读取128bit打包与生命周期必须显式。共享wide service是局部固定连接候选，M/V仍是逻辑角色，不能由单一消费者推定物理合宏。

保留选择：A缓存用现有全部4KiB余量；额外片内操作393472，等待8拍优势消失。需要cache旁路或制造时可选映射、确定端口预算；当前只编译期选择，运行时旁路尚未实现。共享乘法器要有两个有限response槽、握手与公平仲裁；串行零冲突不能推广到重叠流。

替代方案与理由：独立S32在本串行链不快却多面积，保留未来并发需要时选择；新bank未测且不属于免费库存；全H/multi-context不满足16KiB时必须tile/spill/再计价。PPA/时序/宏、在线调度及完整模型质量待验，先不冻结制造边界。

下一步先把运行时旁路、端口仲裁与epoch/安全状态切换做成有证据的接口，再在目标SRAM/工艺资格可用时查STA/物理连接；不得继续只按无争用周期选不可旁路cache或按逻辑面积定M/V融合。
