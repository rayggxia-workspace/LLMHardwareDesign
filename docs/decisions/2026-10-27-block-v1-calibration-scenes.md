# 十二层校准场景保留上下文导体

关联 [Issue121](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/121)、草稿 PR122；2026-10-27 CST。

91915 已逐路径解析实际 classic benchmark 的 133488 条线网，覆盖 M1–M12；这是几何解码通过，尚无场解或 RC 模型资格。复核发现旧分组仅去掉末尾数字，把 `O6_..._cntxM7_1` 与 `O6_..._3` 分到两个场景。这样会遗漏目标导体的屏蔽与跨层耦合，因此旧场景不可用于校准。保留该失败边界及原始输出，使用新不可变 run 重新生成。

修正后，同一实验的信号线及全部 `cntxM*` 导体必须在同一个场景内；只平移 XY 数值原点，保留实际 DEF 单位、端点扩展、ODB NDR 宽度及所有导体几何。地平面由官方求解器固定在 z=0，均匀介质 epsilon_r=3.9 是本研究假设。

校准只请求模型拟合所读取的信号 master 1/2/3（电阻或对角场景按实际存在者）；其他信号线和上下文导体仍完整参与场解。这里输出的是所选 Maxwell 矩阵行，不将其称为整颗校准芯片的完整寄生网表。官方固定源码的 `extModelGen.cpp` 区分 wireNum 1/2/3 并将 `cntxM` 耦合转入模型地电容；后续 SPEF/模型适配仍需实测验证。

先导覆盖每个实际生成的 family/目标层及最大上下文场景。检查有限数、Maxwell 符号、行电荷守恒、总电容统计标准误差不超过 0.3%，以及独立行互易性在 5 sigma 加总电容 1% 范围内。该门槛只是适配资格，不替代原作者参考算例、全量校准、留出几何误差及最终分层边界不重计证明。

参考实现固定为 [OpenROAD 6ea4ca 的模型生成器](https://github.com/The-OpenROAD-Project/OpenROAD/blob/6ea4ca224f3589dd91809933f50f39af66053634/src/rcx/src/extModelGen.cpp)；官方流程是参考 SPEF 经 [bench_read_spef/write_rules](https://github.com/The-OpenROAD-Project/OpenROAD/blob/6ea4ca224f3589dd91809933f50f39af66053634/src/rcx/calibration/script/generate_rules.tcl) 生成模型。不得修改旧十层规则的 LayerCount 来代替实际十二层拟合。

## 全量接收中的统计符号

91925–91930 在 node14–node19 的六个 96 核 allocation（各 8×12 线程）完成场解，随后被接收器的严格非正符号断言拒绝。原失败日志及输出保持不变。只读核查 shard0 的 8 份原始输出：5 个极小反号项，最大约 1.34 sigma、占总电容 0.0013%；这是有限随机游走的带符号估计，不应要求点估计严格满足确定性符号。

更新接收门槛：非对角或地项的正估计必须同时不超过 5 sigma 和总电容 0.01%；总电容仍须严格为正，行守恒、0.3% 总电容标准误差及互易性门槛保留。原始估计不裁剪、不改写。新接收作业逐一校验原失败回执、实际命令、场景列表和原始行文件 SHA 后重验；任一显著反号或其他门槛失败仍拒绝。没有重算或将原失败作业改成成功。

## 模型读回及完整上下文

91932–91937 对原始六分片的接收通过。91946 从 3840 行实际场解和 3344 个 DC 电阻图形拟合候选；SPEF 使用真实 BTerm 名称/方向，允许端口与 net 同名，未测上下文行不伪填为零。互易条目取两行均值，41 项统计上不显著的负物理耦合在拟合输入投影为零；原始场解不变。实际逐网 OpenDB 读回的 R/地 C/耦合 C 最大缩放误差约 6e-8。

该候选未验收：91952 在读旧 write_rules 格式时崩溃；改用当前 gen_rcx_model 后，91955 写出 Version1.2/DIAGMODEL ON，91957 已能读模型，但在实际耦合提取阶段崩溃，尚无留出数值比较结果。

检查发现首批 `over_dist=3/under_dist=3` 仅生成相隔三层以内的上下文，现代规则中残留 1542 个 `DIST count 0` 表，例如 M1 UNDER M5–M12。这违反完整十二层候选的覆盖目标，也是待消除的工具失败因素。下一批生成全部十二层上下文（距离12），逐项实际求解后重拟合；拟合接收新增“不得有空距离表”检查。不能通过复制邻层系数、删表或只修改 LayerCount 填补。

`rc_calibration.json` 显式绑定本次各不可变 run；所有输入仍在同一 Issue 根下。新的场景、参考、模型及留出结果须分别通过，不以旧分片或旧候选替代新批资格。留出门槛预先固定：R 2%，总 C/地 C/耦合总和误差相对总 C 10% 加5sigma；达到总 C 5%的具体耦合对按20%加5sigma检查；跨层参考耦合达到总 C 0.01%的对必须有非零提取覆盖。接入过孔 R/C、分层边界及完整物理仍分别验收。
