# 从平面两段电荷到三维图节点电荷

2026-10-27；Refs #121。研究扩展，尚未资格。

074/087只验证单个x平面的两段通量，即使导体有分支或via，也不能证明任意RC图节点的局部电容。051真实接入图仍使用长度加权C，不能作为完整分布式寄生结果。

新增显式研究变体：在已有来源逐文件核验、平面通量仪表之后，按给定三维图节点的最近欧氏距离对Gaussian起点分桶。结点顺序决定等距处唯一归属；所有节点须有限、互异且位于主导体内部/表面。空节点仍使用原平面或默认上游路径，禁止混用平面与图节点。新增patch记录修改前后SHA，默认原作者goldens、原平面控制及线程确定性仍必须重跑。

这仅将起点通量从一个平面推广到三维Voronoi区域，不改变上游field walk或终点net识别；目前仍是node-to-net而非一般node-to-node耦合。有限offset区域通量不能直接称作导体局部电荷。必须在非共线的分支和跨层via图上，以独立FV的实际导体面位置分桶，与三offset、三网格/外推、远边界、统计、符号和保边际错误重连控制对照。FV不能再用相邻自由体元中心代替实际导体面位置。

预锁误差沿用074/087：外推和细化各≤总C的2%，远边界≤0.5%，相邻offset变化≤总C的1%+5σ，局部σ≤总C的0.1%；主导体局部比较为总C的3%+5σ，外部耦合为参考局部量5%+总C0.5%+5σ。节点乱序、保边际但错误的局部分配须拒绝。不得看结果后放宽阈值。构建/控制通过仍不等于科学对照通过。
