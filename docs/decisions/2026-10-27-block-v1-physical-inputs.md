# Block v1 实体存储与首轮物理输入

Refs [Issue121](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/121)。状态：P0 实施输入已选定，尚未取得物理合格证据；不改变授权计划的阶段门槛。

第一版使用完整标准单元存储实现：一份 S16K 留在 C8 内，一份 T6K 作为消费者侧独立叶块。二者均为实际已映射硬件，无 SRAM 编译器、额外端口或零成本存储假设。`shared121` 的少量组合包装逻辑属于预制父层资源，不能在后定制阶段免费补入。

选择依据是 91901 的独立层次库存：完整 C8＋S16K＋T6K 为 642253 个映射单元，面积 1538342.904 μm²；确有 1024×128、384×128 两个单 1RW 存储及八个 S8／一个共享 S32 乘法资源。面积包含存储，不能继续沿用旧逻辑面积上限。原计数器将符号扩展后的操作数按声明宽度统计而失败，保留91900记录；91901按实际逐位符号接线独立核实有效位宽。

机器可读合同见 [physical-budget.json](../../project/experiments/block_v1/physical-budget.json)。C8 首轮外框2000×2000 μm、标准单元总面积上限1350000 μm²；T6K外框1120×1120 μm、总面积上限450000 μm²，均预留20 μm core边距，由floorplan按实际site/row对齐。全部预制CTS、buffer、resize和hold修复计入上限。A/C*使用同一外框、接口、算术、容量和负载预算，不以放大一方外框制造收益。

时钟10 ns，uncertainty0.1 ns，输入/输出最大2 ns、最小0.2 ns；输入驱动BUF_X2/Z，全部输出（含观察口）2 fF负载。同步复位与配置也按普通输入时序约束，不用宽泛false-path隐藏问题。首次父层完整连接仍须实际STA，叶块IO预算不能代替跨块时序证明。

原生全部M1–M10允许块内使用；固定M10 landing在叶块阶段形成。公共父层PG/CTS、接口引出和任何有源中继必须在P4b另行完成并纳入共同底座冻结。两个产品只能改变M11/M12、via10/via11，不能用改变叶块、端口负载或插入有源器件救回失败。

这些数值是首轮可证伪的实现预算，表示允许尝试的范围。超面积、时序或接入失败如实保留；当前技术资格仍需十二层RC校准、独立几何负例和寄生边界验证，不提前进入正式P3硬化或宣称已得到宏库。
