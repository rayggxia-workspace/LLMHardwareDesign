# 实际捕获位置的跨网节点耦合

Refs #121；原生全部M1–M10预制与M11/M12后定制边界不变。

## 缺口与实现

096已经测量一条真实M10/M11/M12接入路由的八个起点节点电荷，但它是隔离网络；多网SPEF还需要知道电场终点落在哪个邻网节点。不能将两个边际相乘，也不能按导线长度分摊耦合。

新增`capture_field_patch.py`依次组合原partial和graph研究补丁，仅在随机游走已经判定捕获导体时，按真实三维捕获位置选择该导体内最近节点。原导体几何、网络电位、随机数、步进和场核不变；起点节点仍用现有三维分桶。master自身不再拆捕获节点，避免把相邻同导体分区当独立电极。ground维持单列。

按起点b、捕获节点d累计权重W、平方W²；沿用已有逐起点控制变量，以捕获节点全局平方权重比例β_d求均值及标准误。一个邻网所有捕获节点的β相加等于该网原β，故逐起点沿捕获节点求和必须回到已有node-to-net行。此守恒只验证实现一致性，不能证明局部准确。

客户端要求全部非master网络有明确节点，并检查坐标有限、ID/位置不重复、节点处于对应真实导体。不同物理网络若接触或重叠则拒绝。旧074/087/091中相邻的`near_left`/`near_right`是同时接零电位的辅助捕获标签，不能据此宣称两个物理绝缘邻网或一般capture-node模型已经验收；旧原件不改写。

## 构建验收与后续科学验收

新增`fsv-capture-build`重跑原作者goldens、平面/图起点控制及线程一致性，再检查实际捕获节点的线程/边际守恒、原网络估计完全一致、缺失/重复/错网/越界/非有限节点和真实短路负例。补丁在本地固定原始源码上精确转换通过；C++构建和上述运行控制在提交本说明时尚未执行。

构建通过仍不能用作科学资格。下一阶段需保持独立FV矩阵不变，在邻网真实导体面上按同一最近节点划分Dirichlet边界基函数，逐节点施加单位电位；读取master实际导体面的局部通量，核对网格外推、细化、远边界、offset、统计误差、符号、正反方向互易与保边际错误重连负例。原已锁阈值保持，不以通过难度修改。

现阶段**没有**一般节点对、长路由局部FV、全Block分布式RC、窗口所有权、新旧层拼接或完整十二层验收。每一步分别保留输入、工具、命令、输出及失败证据。
