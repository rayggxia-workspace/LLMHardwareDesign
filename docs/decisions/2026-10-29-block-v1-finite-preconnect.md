# 首版下层固定预连的取舍

Issue #121 / PR #122；2026-10-29，适用于300MHz修订版。

首版仍为M/V/R/S/T各一个实现，宏内部固定M1–M10，未来模型适配互联使用M11/M12。此次不将跨宏固定M9/M10网络加入生产宏，避免局部风险试验变成阵列实现任务。

run282在已接收M/T的副本中，按全部原生占用、真实轨道和原生via9规则实现声明的16位水平固定路径：中央240µm搜索带、每条线659.2/960µm、32个via9及32个2×2µm M10落点，实际回读连通和全片原生DRC0；去除via9负例拒绝。旧80µm带7/8条不足16位的诊断保留，不能据此得出整层预留或降M8的必要性。

这项试验表明有限具体路径可行，不授予原生产宏未包含路径的资格，也未做该副本的完整GDS、STA、功能或阵列验收。原生产ODB字节保持。未来若选择下层固定预连，应在新版本冻结前将实际路径、接入、寄生和完整验收纳入宏；冻结后不得依赖重写M1–M10。

证据及实际路径图：`work/YUZE-LU/121/review-20261028/preconnect-0400/README.md`。此取舍与本轮接口建议的“未采用则说明后续预连依赖哪些资源”一致，未引入额外产品或宏版本。
