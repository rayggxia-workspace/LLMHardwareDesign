# 代表性跨宏链路需要同时约定负载和组合时序

状态：有限实验结论，待主线审查；不修改当前基础宏实现。关联Issue121与[48项报告](../reports/2026-10-29-block-v1-interconnect-study.md)。

两个完整原生宏拼接后的验收必须覆盖真实生产者、接收负载、双方内部寄生、跨宏线、数据及反向控制。原先用BUF_X2虚拟输入源的全端口外引测试可以发现风险，不能直接替代真实组合验收。

实际M10内部接点的代表距离达到1.55/1.69mm。声明的较高电容条件下，单独增强端口驱动仍可能超电容上限；预制中继分段在TS案例可使电气/时序全部通过。但MT在电气违规清零后仍有ready时序失败，故不把“缓冲更强”作为统一解决方案。

主线先明确每种接口的驱动/接收、负载/线长/扇出、输入到达和输出延迟契约；MT还需核算真实控制器或正确弹性协议带来的时序分段。新增有源器件必须位于预制M1–M10底座，重做受影响宏的完整P&R与独立验收；M11/M12保持定制连线职责。

high1.5只是敏感性条件；独立理想截面0.219–0.337fF/µm也不是真实工艺标定或通用上界。当前不冻结驱动规格、中继间距或新层制造规则，不增加宏家族、阵列或产品。
