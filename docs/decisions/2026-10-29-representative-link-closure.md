# 代表性互联实验补齐范围

Refs #121 / PR #133。用户在本侧线明确要求完成实验。原 run907/908 的48项 STA 结果保留；它们是阶段性电气扫描，不是完整实验验收。

本次只闭合 M→T、T→S 两类代表接口，不扩展阵列或整模型产品，不改主线工作树和已有生产数据库。新增有源器件必须在固定底座或固定中继宏中实现，M11/M12只承担定制连接。

验收清单：

1. 用真实接口完成事务/背压/在途数据的功能验证，说明控制路径预算；失败保留，不直接寄存 ready 后忽略数据容量。
2. 对选定的端口缓冲/中继完成真实合法放置、PG连接和M1–M10局部布线；不使用未经验证的8µm局部线假设。
3. 对代表链路完成M11/M12真实走线、全线连通/短路/几何检查，并把实际路线与原生寄生一起用于时序检查。
4. 校核新增研究层RC，包括实际几何、邻线/交叉上下层环境、模型误差。声明研究层假设，不声称获得不存在的晶圆厂标定或制造签核。
5. 测试距离、负载、扇出及中继间距的通过/失败边界，给出有限条件的接口规格与裕量。检查cap/slew/setup/hold，不用放宽约束或false path掩盖失败。

资源沿用Issue121共享dispatcher和8 allocation上限（含pending/unknown），c96节点默认6×16独立任务、即时补位；仅有真实依赖或内存证据才降并发。先用分配节点上的只读ODB/API检查选择物理修改方式，避免未经检查就启动大量重布局。

本记录是验收范围，不代表上述工作已经通过。每项最终状态以新run的源码、工具、输入和原始回执为准。
