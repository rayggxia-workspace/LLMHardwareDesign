# 大Block功能资源变体与串行数量参考

日期2026-11-01 Asia/Shanghai，Issue151 / PR152，负责人Melodydt。状态：用户要求的数量研究候选，未冻结实际物理BOM、性能或程序；既有P2剩余矩阵保留。

对八样本十层型保留A/F/D/H/X五功能类，将A按源图分成普通/输出门两种资源变体。以M/N/E/G/R/S/T顺序，A_plain=[1,1,1,0,0,1,1]；A_gate/F/X=[1,1,1,1,0,1,1]；D/H=[1,1,1,1,1,1,1]。每物理Block局控1，全芯片母控另1；NUM/MEM/适配/ROM/控制端点等另计。N内部EXP使普通Attention不需要G，R只在GDN/SSM功能需要。

该表选择串行时间复用并显式依赖可工作MEM/NUM、保存/回放和固定局控，不能当数学最小/吞吐最优或现有七宏已完整覆盖。单M不能保留多份merged，M2也不自动消除完整mid回放；单S loader喂多M需预制选路/owner。S1/T1是本分片接口选择，非算法硬下界。

整体可以1全七包、非R包+含R包、五功能各1等方式复用，7/13/32叶仅是资源算例。计数相同不等于完整包装一致；没有R的产品也可复用含R包的其它能力，但程序/路线/NUM并集必须真实预制。M11/M12不能删已制造的op或补有源资源，裁剪须预制前按跨产品映射需求并集重新验证。

详细数量/用途、模型配置、保存字节、H完整/拆分和外围缺口见[BOM报告](../COARSE_BLOCK_MACRO_BOM.md)。下步先接收程序/数值/存储调度，再依真实吞吐与MEM目标增配和做物理对照。本轮无新RTL、仿真或服务器部署，后续服务器实验按REMOTE_RULES本人目录执行。
