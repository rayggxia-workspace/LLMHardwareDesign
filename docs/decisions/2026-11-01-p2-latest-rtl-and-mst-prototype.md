# P2最新源码与最小MST控制原型

Issue151 / PR152，2026-11-01 Asia/Shanghai，负责人Melodydt。用户明确要求采用PR144最新RTL并开始P2；独立设计/PR审查仍待指定，不将继续实施授权等同于P1独立验收。

当前采用PR144固定707878621b2add4ed218b8c43df2e95c9a56e2ba的14核心源，逐文件核对仅R相对643实现变化、7顶层接口相同。R临时算术扩S128，源码同步不转移其功能/物理资格。M/S/T不变，P1旧回执保留固定版本，P2使用新来源锁和实际验证入口。

第一个可运行控制原型采用母控SERVICE/WAIT ROM、局部有限服务状态机和独立S普通端口helper，实例化真实S/loader、M、T。输出保留S64，只做搬运与保存，写S必须收ACK、loader完成和M计算完成分开、T完整提交/消费/释放后才成功完成。测试fixture固定K8/N8；复杂图/形状和格式将在验证矩阵中单列，不以小例排除允许连接。

当前16bit/21字ROM是有限MST程序骨架。原完整64bit指令、模板capture及十服务物理接收bank尚未在此原型实现，不能说原完整控制ABI或预算已落地。abort选择协调同步复位全部在途端点，不引入无复位取消的虚假回滚；已接受S写和已交给sink的前缀不撤回。外部须按error/reset丢弃不完整批次。

新增控制逻辑现为RTL层次，尚无独立物理bridge宏或后端结果。所有有源逻辑都必须在共同M1–M10底座冻结前实现；永久M11/M12仅选择既有路径/程序。外存接口当前暂缓，系统有外存的目标保持。详见[实施报告](../PHASE2_MST_IMPLEMENTATION.md)。
