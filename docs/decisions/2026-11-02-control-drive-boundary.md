# 控制组合的固定驱动边界（候选，Issue162）

原 M/N/E/G/S/T 的 RTL、已验收六文件和版图基线保留。14 类新增控制宏补入原生 BUF_X32 输出级，重新执行最终布局布线、完整 DRC、300MHz 时序、最终单元功能和严格等价门；单块结果不能替代整个组合。

`joint-wire-feasibility-02` 绑定实际 ODB 输出驱动、原生 pin 和既定 2um M11/M12 low/base/high RC。即使忽略原生电容、负载和绕线，对 S 全部输出使用同一个刚性相对位置，四种旋转、四种非重叠方向均无法连接现有 S 适配器。这是失败下界，不能作为任何通过证明；继续给同一拓扑增加布线随机种子无助于解决该电气约束。

当前按保留原六宏的方向验证独立 `control_link8` 固定驱动候选。它的八条数据路径没有载荷寄存器，内部另有一位同步复位隔离状态；状态、BUF_X32 输出级、输入接入、电源和时钟均归该物理块。其同步复位来自同源计算宏使用的既有复位分支。复位期间输出隔离，复位解除后的第一个时钟启用，不增加正常载荷的寄存周期。复位、时钟新增负载必须进入组合真实 RC 和 300MHz 验收。

拓扑生成器按实际 S 输出 pin 的位置分组，每组最多八位，插入明确实例。末组不足八位时，未用输入复制组内第一位，未用输出保留为无接收端原生端口，不制造未归属的常量驱动。每条原路径及其原/新网络 ID 均留在源绑定图中；收缩这些驱动路径后，原 26 实例的全部连接和主机端口必须逐项完全相等。实际最终单元组合测试、物理布局和 RC 使用这同一份拓扑。

驱动候选仍须完成自身的全部最终物理门、固定 PG、新鲜提取和六文件；组合必须另行完成真实程序、全部端点、上层零冲突布线、实际 GDS/ODB 接入、电源连续性及三种 RC 下 300MHz。新增实例数量按事实登记，不能继续声称组合只有 20 类/26 实例。M11/M12 中不得隐藏驱动、寄存器、仲裁或其他有状态逻辑。若该候选无法通过，继续定位并修正，不放宽门槛。

R 保留，由当前修改任务负责；本参考组合尚未完成 R 的适配与接入，这不是永久禁用或删除 R。
