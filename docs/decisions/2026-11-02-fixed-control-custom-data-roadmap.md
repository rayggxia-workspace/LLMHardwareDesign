# 固定控制网与定制数据网的分阶段实施

状态：**proposed**；2026-11-02；Issue151/PR152；负责人Melodydt。用户要求将三层连接边界纳入八主线，本次完成计划安排，不宣称接口/RTL/物理已冻结。

背景：已有方案明确岛内线路在M1–M10固定，母控/MEM等基础设施端口纳入顶层；母控至各岛控制网的具体层分配未冻结。需要在完整A/F岛扩大前明确边界，避免各岛完成后才发现全局任务/事件或中继/缓冲需求不兼容。

主候选：母控与local CTRL采用共同底座内固定控制网络，模型相关跨岛数据路线及配套握手/存储确认由M11/M12连接或永久选择；各功能岛内部按需求预制固定互联。母控网络集中、分段或区域层尚待端口/扇出/时序论证，不预先指定全交叉或无限带宽总线。

安排：L4/W5新增内部前置子任务W5-IF，先确定逻辑端口/生命周期/能力需求；L5/W2实现固定母控控制网络和双岛真实stored ACK闭环，W6扩一般拓扑；L6/7补状态和动态事件；L8/W10/W11接入真实MEM并最终验证完整产品与共同M1–M10及M11/M12差分。pin/路线、PG/CTS与资源预算从L4/L5持续反馈，最终物理冻结仍需真实证据。

取舍：固定控制网便于多个有限产品复用相同任务/事件基础设施；可定制数据网保留模型路线差异。若物理反馈证明该候选不可行，应在共同底座冻结前调整拓扑或重新评估控制端点走M11/M12的备选；本计划不是不可撤销的物理承诺。无论选哪种，所有有源MUX、缓冲、驱动、仲裁、控制/ROM和必要CDC都必须预制，不能靠定制金属补造。

接收要求：合同、RTL功能、物理冻结分别记录；任务接收/片段末尾/目的存储ACK/源释放/最终发布分开，不承诺全token回滚。当前A8/F8固定帧不自动成为通用岛间接口，首个W2切片须选择匹配合同的核或补实际适配。

执行细节与退出门见[三层互联实施安排](../COARSE_BLOCK_INTERCONNECT_BOUNDARY_PLAN.md)。本轮无RTL变更、无新仿真/服务器/EDA操作；沿Issue151/PR152部分交付、待审查，不标done。
