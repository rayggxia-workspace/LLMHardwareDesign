# W4 单组 N 服务、存储回放和独立原始残差

- 日期2026-11-02；状态proposed（有界RTL实测，产品级设计尚未批准）；负责人Melodydt；Issue151 / PR152。

现有七宏之间数据宽度相同，阶段与数据内容仍不同。N的统计命令不产生归一化张量；Softmax必须在全组统计后生成EXP，保存返回的U16代码，再计算factor并精确回放。G/E的统一一字服务不能替代这套持组过程。为有界验证，新增外侧Ncontroller，使用唯一S helper并完整执行原生阶段，不改叶宏，也不引入独立已物理合格bridge宏的假设。

当前controller一次接收一组count1..257，src/gamma/EXP/dst中使用的区域均不重叠并且不越界；这是已实现profile的保守限制，不是永久算法禁连。硬件捕获服务描述符并按阶段计数，S响应先捕获并take再发下一读；最后目的写ACK后才报告完成。caller在整组期间持有不可变源/gamma，当前没有外部版本标签或多组交错证明。运行期错误置poison直到协调reset，准入拒绝不poison；后继调度不得把error消费当作资源可复用。

F8在固定RMS8之后维持原有M A8/B8投影，新增明确的RNE3/clipS8转换逻辑。gammaQ10、epsilon raw1使N输出S16 Fin10，转换至S8 Fin7；E12仅打包/饱和，不能冒充带舍入缩放。另一选择是M A16并重定投影尺度/存储，不在本切片同时改变。新转换会产生定义内clip，其标志并入done_saturated，独立于协议error；数值一致不代表真实模型精度。

原始x16保存在S466，N输出474、gamma475；归一化窄值写回448供M，残差仍由466扩展至Fin10。保持两个输入生存期是preNorm子层的必要条件，不能把原W3的同输入假设直接套用。固定程序/地址与少量内部服务描述符不等于通用host控制程序装载；未来共同M1–M10仍须预制程序/路由选择等真实有源资源，由M11/M12永久绑定，不能按产品再综合新FSM代替共同底座。

代价为一个N外侧FSM、保持寄存器与S往返、F8新增状态/owner及8lane窄化逻辑。正常RMS/L2服务W字有4W笔S与2W+2条N命令；Softmax有5W笔S与3W+3条N命令。固定F8比W3增加7笔S，总39（29写10读），增加N四命令；S448..475保留448B，仍占用真实16KiB S和6KiB T宏。面积/时序/功耗尚未测量。
