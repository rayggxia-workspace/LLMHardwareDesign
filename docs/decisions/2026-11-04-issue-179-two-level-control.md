# 2026-11-04 Issue179：两级可编程控制与版本化控制编码

- 状态：proposed，待独立审查、执行及物理证据；不表示硬件冻结。
- 负责人Melodydt；[Issue179](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/179) / [PR180](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/180)。
- 用户明确本任务聚焦局控/母控研究，并要求后续模型编译可使用的指令种类和编码。下面的实现选型是本轮建议，不写成用户已批准的硬件规格。

采用固定宏归属/私有S，母控粗任务、局控微程序、固定宏适配与独立收发。块内及块间数据连接均可后制；程序与真实端点图共同生成、检查。共用控制核按P/U/C/F/J配置资源，原生上下文与命令busy分别记账。首轮静态S布局、单活动任务、空闲装载程序RAM及有限并发为研究起点，后续按证据扩展。

提出128bit小端定长控制编码，母控/局控操作码分区、未用字段为0，描述符与任务/事件/数据头有版本。原生数值字段必须绑定已登记ABI，不能因codec可打包就称当前宏支持。旧PR152/163的编码与资格不自动转移。

程序区4KiB/局控只是指令预算；连同候选对象/执行/传输/任务表约8KiB/局控，九块及母控上述静态内容76.5KiB，运行时状态、参数与物理成本另计。RAM/真实金属ROM与控制链路物理选型后续比较。

完整论证、研究门与未完成项见[方案](../local-blocks/TWO_LEVEL_CONTROL_PLAN.md)及[ISA](../local-blocks/CONTROL_ISA_V0_1.md)。本轮只交付文档和编码参考软件；未启动新RTL/服务器/物理任务。已有容量研究、各独立实施分支及验收证据保持原范围。
