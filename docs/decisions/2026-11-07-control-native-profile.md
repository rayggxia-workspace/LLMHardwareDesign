# 五类原生配置与双局控返回缓冲

Issue #179 / PR #180，2026-11-07，Melodydt。状态：候选实现，待审查。

当前 64 bit 局控增加显式 ENABLE_NATIVE 配置，保留 P16 的独立 ABI 入口。原生 ABI 01930001 的组号为 U0/F1/C2/P3/J4。采用 1 至 32 条执行记录、空对象/传输表及适配器资源位 0，适配器执行服务细节。通用 ISA 资源编号和该 ABI 的组类型/入口编号分别解释。

母控到两个局控的任务按固定目标路由，返回端增加一个 512 bit 寄存槽。槽内 valid/payload 在母控背压期间保持，接收后可同拍替换，LC0 固定优先。返回增加一拍延迟，时钟周期维持 3.333333333 ns。当前有界任务协议可以排空；无界持续流量公平性不属于该模块承诺。

复位清槽，单时钟传输不代替生产 CDC、实际 M11/M12 串化或复位证书。五类原生回归、P16 ACK、准入及路由单元测试通过，详见 [验证摘要](../../work/Melodydt/179/frontend-validation.json)。结构综合已通过；新增配置与完整顶层的时序仍待同版物理输入。七项生产绑定尚未冻结。
