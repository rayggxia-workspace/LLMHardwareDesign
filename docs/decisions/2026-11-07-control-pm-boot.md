# 控制PM和统一装载启动入口

Issue179 / PR180，2026-11-07，负责人Melodydt。用户授权完成综合前九步的前三步。

当前核心的cfg、PM、release与START边界原先由测试台连接；本轮新增control_boot_top封装它们。执行ISA仍为版本2的64 bit子集，统一主机管理命令采用独立接口。规模冻结为两个目标、单时钟域，不在本轮扩大母控数组或改变Block组成。

PM采用可综合同步RAM及现有OpenRAM bank两个后端；每端16 KiB，控制器仍独立限制镜像容量。SRAM后端复用存储bank和协议封装，不把任意Verilog数组综合成已验收SRAM。真实bank模型用于功能仿真，bank及P组的明确边界用于控制结构综合。

统一16 KiB用于复用已验证的四bank接口，存在容量余量；母控4736 B、局控8320 B的逻辑镜像上限不变。按实际容量减少bank数量需要另验译码、接口和物理，不在本轮混入。

管理入口维护顺序写/读计数和CRC32，完整读回后才提交核心VERIFY。CRC每周期处理一位，限制组合链长度；装载延迟增加，执行指令格式及目标时钟周期不变。共同部署要求三端同generation和全部准备完成；运行、未闭合链路或待消费结果时禁止装载及数据S访问。响应保持到主机接收。

本轮候选不具有非易失防回放声明；组复位后由可信主机提供新epoch并完整重装。新PM/装载组合映射时序及完整物理属于后续验收；原有独立时序和上游存储宏资格不转移为新组合资格。可复现入口和实际结果见control_boot_v1/README.md和work/Melodydt/179/control-boot-validation.json。
