# 双P控制顶层候选与确认边界

Issue #179 / PR #180，Melodydt。状态：用户授权尝试实现的RTL候选，待正式物理接收。

选择PR214独立叶宏P组，复用当前64 bit控制器及既有P16控制命令ABI；P0/P1身份固定为0/1。块内使用S回放，两个私有S各16 KiB。三端配置及程序存储接口分离，正式PM后端外置。

新增固定P0→P1的数据/身份保持槽和反向提交确认。身份源于实际LC服务请求，目的S响应产生真实commit，再由匹配保护器发布源释放；测试台不承担正常身份通路。START等待host响应排空，作业中禁止host数据访问；结果可背压。

该方案使A1获得可检查的RTL端点和程序版本，同时保留后续选择空间。M11/M12物理分帧、时钟/复位实现、程序存储器及整个组合的同版物理资格仍须单独落实。P组旧控制组合GDS不可直接沿用到当前新顶层。
