# Issue247 面积换速度候选优先级

日期：2026-11-09 Asia/Shanghai；负责人 Melodydt；状态：研究建议，待独立审查，未批准生产实现。

依据[研究报告](../experiments/issue-247-area-speed.md)与[三轮源绑定证据](../../work/Melodydt/247/index.json)，在用户允许增加一定面积、SRAM扩容暂不实装的约束下，下一阶段优先验证P的同容量读写并发。W8/context512条件模型中单项增益7.75%，结合8组部分和增益14.12%；实际宏/RTL、冲突语义、时序、面积及真实生成尚未验收。

多部分和优先保留8组，16组边际收益小且W16/原调度存在退化，不做全局默认。两槽弹性链路只证明局部吞吐改善，原P程序仍288拍，暂不替换生产版本。第三P原两通道均分存在负收益，且新增一份活跃16KiB私有S，不作为同资源配置采用。向量8/16 lane收益较小，后续结合实测面积评估；未测组合不相乘。

该取舍不替代PR241原生S32/96位M/E接口资格，也不授予新SRAM实现或物理验收。实际实施与独立审查负责人待指定。接续[Issue247交接](../handoffs/2026-11-09-issue-247-area-speed.md)，沿既有[PR243](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/243)交付研究证据。
