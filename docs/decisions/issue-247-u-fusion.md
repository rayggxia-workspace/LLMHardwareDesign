# Issue247：融合与流水候选的取舍

2026-11-09 Asia/Shanghai；[研究证据](../experiments/issue-247-u-fusion.md)，Refs #247，PR243待审查，生产化尚未批准为已完成。

采用小范围相邻唯一消费E转发作为融合候选，256B RF、保留中间舍入和原单E工作。仅计实际删除S/cache访问及已测费用，原canonical融合不重复记功。B路线W8 decode512实际条件token/s增量0.0214%，prefill2为2.2776%；局部收益不能代替热点占比。

将分离生产/消费控制作为更有价值的局部RTL候选：同一个N/E/S上32tile1440→1071拍。保留depth1/2对照，不采用无证据的大FIFO；单tile45→48的退化要求短任务旁路。深度2只是调度余量候选，未证明更快。新增FIFO原始数据标签272位，实际面积与时序待综合。

全trace并发结果目前仅是冻结阶段费用的条件重放，不能称实测系统性能。768B输入槽超限的36个prefill region保持串行；不增加免费容量、不丢第四输入。后续真正并发模型必须重算S/DDR/cache竞争，再决定生产投入。

SRAM48/64KiB仍保留既有候选，不在本轮生产实装。正式接入前必须完成异常取消/drain、顶层描述符、地址别名/尾部/背压及同宏库物理验证；当前成功路径允许全组reset恢复不代表完整生产异常协议。
