## 已确定

1. 后续以**外存总51.2 GB/s**为约束，不因旧102.4 GB/s结果达到10量级而更换预算。102.4的已执行结果保留为历史敏感性对照。
2. 新生产设计不用S128；持续部分和/上下文目标S32/Q16，Mid优先S32/Q16，尽量不使用S64长期存储。必要短暂乘法/缩放宽结果需单独证明位宽与费用，不把S64容器等同于整片向量保存。
3. 上述是设计方向，不是新RTL已实现的声明。S32/Mid32通过本轮部分语料筛查，51.2 GB/s、每组多1拍RNE的条件模型为9.21564723269 token/s；不能把原S128独立RTL资格转移到它。
4. 维持独立叶宏＋局控/适配器的控制分组，以及M1–M10预制、M11/M12连接真实预留端点的结构。

## 不能默认选定

G表项数及ROM/逻辑/SRAM实现、四银行或流式前端、FIFO容量、入口/出口组织、信用窗与burst策略、X驻留位置、投影上下文数量、S端口/银行映射、是否新增SRAM、Mid保存或重算、完整FFN跨算子流水、描述符与实际端点，以及物理/能耗/FPGA对照均继续独立评估。

257项G表、X放S、2/4 KiB流式缓冲等是有证据支持的候选/建议，**不是用户已经批准的最终组合**。所有已测负例、未测组合和取消/失败作业保留。具体见台账D01–D24，不以“推荐”替代决策，不将未完成评估写成已解决。
