# Issue248：保持五类逻辑分组，隔离新增有源候选

状态：研究已实施，待 PR249 独立审查；没有替代已验收的生产底座。

保留 P/U/C/F/J 的局控归属与独立叶宏结构，S 仍为 16 KiB。有限权重 bank 直供、K16×N8 W8A8/A16 叶核、定点转换与多通道 DMA 都只在 `stream_quant_synthesis` 的候选中实现/建模。C/F/J、生产 P/U 和旧验收产物不改。

理由：S 端口争用可以在权重 DDR 字节不变时降低；但简单 A8 的真实权重筛查不合格，A16 暂作优先的精度候选。大带宽、更多 P、宽 beat 不是无资源代价的算法收益；负结果必须保留。缓存 DP 仅对明确估计器精确，以 SystemC 实际重放检验，不能宣称整图最优。

新有源资源必须进入新的 M1–M10 实现；M11/M12 只接端点。本轮没有可部署 pin 合同、完整局控程序或物理资格。RTL packet 槽与计时模型 tile bank 的粒度尚需统一，禁止把独立 RTL 吞吐当成整机吞吐。接口需求是部分研究 IR，禁止直接接管原 #180/#220 的生产输出。

验证与取舍见[四轮报告](../experiments/issue-248-stream-quant-synthesis.md)，原始结果和失败见[证据索引](../../work/YUZE-LU/248/README.md)。
