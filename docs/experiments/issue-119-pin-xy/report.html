01 · 先给判断，再看证据

ACT 优先尝试 C 的“数据簇向内、控制口留边”；GEMM 优先选择 C 中有端点依据的活跃读接口簇，并让常量字节和窄控制口留边。B 保留为贴边多排的对照。
二维接点提供更大的局部接入区域，但不能仅靠改变点位消除通道需求。接点移入内部后，原层引出线、局部通孔与固定底座金属仍要容纳它们。

ACT 的宏位置明确，宽输出接口与宏外通道、实际逻辑端点有空间关联。GEMM 无块内 SRAM 宏，但有大量逻辑与 filler；它的权重读数据共 2,048 位，其中 1,363 位集中在下边，单排接入值得疏解。外部存储对象的位置和目标层在本报告中并未取得，不能预先认定将这些输入全部深入计算阵列就能缩短块间连接。

层级约束：M1–M10 是设想的固定底座，M11/M12 是补充适配层；本次不把信号统一提升至 M11/M12。原来 M5→M8 的连接仍需 M5→M8。CSV 中未知目标层明确记 UNKNOWN，不把敏感性假设写成真实层级。原数据库的工艺层到 M10，未取得 M11/M12 的真实规则。

证据级别：B/C 均为 proposed。已检查 pin 清单、边界、宏 bbox、已有 M5/M6 金属矩形、PDN 和假设通孔栈几何；尚未验证完整接入布线和 DRC。没有重硬化、P&R、RC 提取或时序验证，也不报告实际面积或时序收益。

04 · 原层接入、通孔与固定金属压力

衔接方式：pin 仍放在原 M5/M6，沿原所属网络重新安排局部接入线；块内最终连接到同一组逻辑端点，对外继续连接同一对象和原目标层。原金属上的短接入段和经过层级的通孔位置可能改变。把 pin 改到某处不会自动生成可导通路径，也不能仅改 LEF 后继续使用旧 ODB、RC 或时序模型。

目前没有取得父层的逐 pin “连接对象 + 目标金属层”映射。因此三种假设只用于分析敏感性：原 pin 层到 M6、M8、M10；不把它们写回 pin 层或网络。越高的目标层会经过更多已有金属与 cut，风险增加；不能拿最高层通孔规则统一否决所有 M5/M6 接点。

05 · 方法、已检查项与限制

来源一致性：HTML 中信号矩形逐 pin 对照本次同源 ODB 的 BTerm，名称、方向、层和四个矩形坐标全部一致；数量与原报告相符。源 ODB SHA-256 与 HTML 元数据一致，读取前后大小、修改时间与 inode 保持。源数据库由容器只读挂载，所有新脚本、日志、缓存和结果写在独立任务目录。

端点：直接 BTerm net 的 ITerm 逐一导出；沿 BUF_* / INV_* / CLKBUF_* 追踪最多 12 级，停止在非缓冲单元，保留其 ITerm 平均几何坐标和所在层。没有推断逻辑功能重排；无端点位不编造位置。ACT 85 位、GEMM 321 位无直接 ITerm（时钟另不作功能追踪）。C 只移动有已追踪端点的宽总线位和字节束。端点追踪不是全功能锥分析或形式证明。

候选算法：B 除实际字节对外，按同总线、同原边的坐标近邻分束，用原主边和坐标中位位置选择窄条；C 其余宽总线按连续位号分段，再按追踪端点中位位置选择覆盖内二维网格。常量输出字节原位保留。搜索避开宏 bbox + 0.56 μm 人工几何余量、已放束包络 + 0.56 μm，以及保留接点；对 12 个较近合法窗口用异网 pin 层基本间距风险加软代价。两种 0.56 μm 余量是设计假设，不是已验证工艺 halo。候选不是全局最优；矩形窗口和点坐标均保存，可复用脚本调整。

金属筛查：已有信号 wire/path 与通孔的逐层矩形、PG special-wire 矩形及通孔从 ODB 导出；筛查 M5/M6 pin 本体对异网几何直接相交，以及按本层默认 spacing 扩张后的相交。假设栈额外检查其经过的 routing/cut 层。宏区全部保守排除，不尝试从单元图判断其上方可布线。M4 也导出供后续使用；新内部引出线向更低层的完整接入未验证。全体单元/宏的 pin/OBS 形状未作为逐层障碍完整导出，因而该筛查不是数据库全部可布性检查。
