只解释读这页会遇到的词

术语速查

pin / net / instance

pin 是接口接点；net 是应当相互连接的一组电气端点；instance 是设计中具体的一份模块或单元。bit_1011 是对象名，不是问题原因。

M5、M10、M11/M12

不同高度的金属布线层。改 pin 的 XY 是平面搬位置；换层是另一件事。本项目保持原 pin 层，研究上层适配并不意味着把所有 pin 升到上层。

DRT / No access point

DRT 是详细布线。No access point 表示工具没找到合规则的首级接入位置；要检查附近真实金属和通孔条件，不能只挪绘图坐标。

DRC / native DRC 0

检查导线、通孔等是否满足所实施的几何规则。native 0 只表示该工具该次检查没有报项，不能替代完整规则、连通、时序或功能检查。

Short / Metal Spacing

Short 是原本应隔开的网络发生电气接触。Metal Spacing 是几何间距不满足规则；Q01 的六项不能直接改称已证明的异网短路。

RC / STA / setup

RC 描述实际互连的电阻电容；STA 根据约束检查信号到达时间。setup 余量为负，说明在所设研究节拍下迟到，不能据此说所有低频条件也不能工作。

hold / removal / min

hold 检查数据是否保持足够久；removal 检查异步控制相对时钟的释放关系。某些报告的 min 汇总含 removal，不能一律称为 hold。

slew / cap / fF

slew 是信号跳变快慢，cap 是负载电容，fF 是电容单位。驱动过多负载可能导致转换或电容约束失败；增加驱动需要重新接线验证并单列单元成本。

PG / PDN / OBS

PG 是电源和地，PDN 是供电网络，OBS 是抽象视图声明的布线障碍。信号接点不能随意侵入这些区域；看到浅灰背景不能认定可以通行。

LEF / GDS / ODB / SPEF

LEF 提供外框、接口和障碍等抽象；GDS 是真实版图几何；ODB 是物理设计数据库；SPEF 保存提取的寄生参数。拥有一种不意味着另外几种已具备或已验证。

冻结 manifest / SHA

manifest 是被冻结对象及其版本清单，SHA 用来核对内容。只有证明两模式实际复用了同一份 M1–M10 几何，才能声称底座不变。

检查失败 / 尚未验证 / 未执行

检查失败：已经跑了且不满足；尚未验证：证据不足；未执行：该流程还没做。三者含义不同，本页不把后两者写成已证明的功能失败。
