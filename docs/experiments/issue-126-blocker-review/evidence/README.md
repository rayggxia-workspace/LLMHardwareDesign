# 如何区分原文与可读副本

- `*.gz`及`capture.json`保留封存字节；每份SHA和原始输出索引均校验，未修改失败或原生数据。
- `readable/`为显示副本：TSV所有字段加引号以保持末列空字符串，同时满足文档空白格式检查；字段解析值与原文完全一致。其他显示副本只整理文件末尾空白，不作为原执行脚本的字节身份。
- `receipt-summary.json`与`log-extracts/`是明确标记的摘要/片段；完整原文和执行版本以链接的原始gzip及其SHA为准。
- 复现实际执行时采用原始gzip内脚本，不能用经过显示格式整理的副本声称原脚本SHA相同。

此处不包含新的数据库施工或规则放宽。
