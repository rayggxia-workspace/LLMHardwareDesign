# Qwen3.5-4B 注意力与 GDN 两层 RTL 外存联调

2026-11-07，Asia/Shanghai。[Issue #197](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/197) · [PR #198](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/198)

## 执行范围

选择第 0 层 GDN 和第 3 层注意力，取原完整模型前两个连续处理位置。每层使用完整 **2,560 隐藏维度**和原检查点的全部矩阵行、K 维及头数，执行归一化、投影、GDN/注意力、残差及 FFN。两个层的输入分别来自已冻结的完整模型边界，保持各自的 KV 和 R 状态跨位置存续。

- 计算命令由测试台组织，M/N/E/G 与 R 使用原生 Verilator RTL，先逐命令和 SystemC 引擎核对实际响应，再供上层计算使用。R 采用现有 `r_stream_local WORDS=1024`，映射 128 行 × 8 lane 的局部块。SystemC 保留张量编排、动态尺度、格式服务及计算过程中的临时 S 回放。
- 外存传输使用 #182 冻结的 `hbm_group_dma` 与现有 16 KiB S。LOAD 完成后从真实 S 端口取回计算操作数，STORE 从 S 读出更新后的数据，收到外存成功应答后记退休流量。测试台提供有限外存队列、请求与响应背压及宏接口驱动。
- 对齐布局采用 16 字节元数据头、S16 值、适用时的尺度数组及补齐的尾字。R 尺度元数据也写满一个 128 位字。SystemC 参考使用同样的布局和分片策略。
- 各计算宏和 DMA 分别推进时钟。完整 RTL 母控/局控程序、统一周期调度、预取重叠及目标 DDR/HBM 的时序和能量校准仍待接入。

## 验收和计数

每个位置的两层输出需与原冻结结果逐字节一致。新 SystemC 与 RTL 还要核对四个层边界的分类请求字节、宏命令数和数学 MAC。实际流量在原生外存接口配对请求及成功响应，逐类统计退休的 128 位字，要求与 SystemC 计量的总线字节一致。

## 服务器结果

构建 **99624**、执行 **99627** 与证据核验 **99629** 均在 c96/node13 完成，退出码 0。执行作业用 1 核运行 **3 分 50 秒**。四个完整层输出分别与冻结基准相符，新 SystemC 与 RTL 的输出二进制 SHA-256 同为 `e2ff3bb80438a76316231c8ed3e891c6c87da44165cb0dc07f37bd8bcc5272cf`。

表格是每个层边界的增量，含必要的元数据和对齐字节。权重在本次运行中只有读取；末列是同布局 SystemC 与 RTL 的分类总线字节差异。

| 处理位置 | 层 | 权重读 MiB | KV 读 / 写字节 | R 矩阵读 / 写字节 | R 历史读 / 写字节 | 对账差异字节 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 0 GDN | 215.393 | 0 / 0 | 0 / 2,097,168 | 0 / 16,400 | 0 |
| 1 | 3 注意力 | 205.011 | 16,896 / 4,128 | 0 / 0 | 0 / 0 | 0 |
| 2 | 0 GDN | 215.393 | 0 / 0 | 2,097,168 / 2,097,168 | 16,400 / 16,400 | 0 |
| 2 | 3 注意力 | 205.011 | 33,792 / 4,128 | 0 / 0 | 0 / 0 | 0 |

- 首位置 GDN 把 **2,097,168 字节**的递推矩阵及元数据写回。第二位置通过 DMA 读回同等字节，再执行更新并写回。对应的 R 历史写/读也已核对。
- 注意力 KV 每位置写 **4,128 字节**，读量从 **16,896** 增至 **33,792 字节**。16 个查询头按本轮策略读取有效历史，尚未采用跨查询头的缓存复用。
- 两层两个位置合计权重读取 **881,650,432 字节**，权重写为零。总计 **55,503,130 个外存字事务**由原生 DMA 发出并收到成功应答。控制端共提交 **3,580,842 个分片描述符**，均核对标签、状态和已完成字数。
- 计算侧完成 **441,927,024 个数学 MAC**。M/N/E/G/R 命令与数值响应对照均通过；两端的宏命令和饱和计数相符。N 的原生调试响应只提供基础统计，SystemC 扩展的三个观察计数字段由参考端补足，算术结果使用原生响应。
- 收集到的完整输出可在本地重新通过验证器。把第二位置 GDN 的一个 R 读回字从退休计数中去掉，验证器按预期拒绝。原始模型输入、生成代码、源归档和输出摘要也已核验。

## 后续接入边界

本次跑通了测试台驱动的两层功能链路。下一步接入母控/局控的可执行镜像，把分片供数、动态尺度服务、临时存储和 KV/R 地址管理从测试台移入完整 RTL 顶层，并统一时钟、背压、错误恢复与统计。当前 DMA 侧的局部周期计数只描述串行接口仿真；整层时钟、流水效率、真实 DDR/HBM 吞吐与器件能耗需等该顶层接通后评估。
