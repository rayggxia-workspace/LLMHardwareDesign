从 S16×S16 到 S8×S8，B 端口的采样翻转减少 **16.0%–47.2%**。Gemma 和 Granite 的响应数据线翻转小幅增加，反映不同端口的活动变化。**七个模型的能量/token、焦耳和平均功耗均暂无可比数值**。换算需要算术、SRAM、外存、互连和时钟等的能耗系数，以及完整设计活动覆盖。
