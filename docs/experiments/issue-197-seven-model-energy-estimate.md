使用七模型已经跑出的长序列 SystemC 计数及投影 RTL 活动。下面分别给出**整模型工作负载的已计项能量**、**已对账的 C/D 暂存流量及外存覆盖**和**投影切片的局部能量**。旧 C/D 回放和新 SystemC 行为外存回放各有独立的接口计数。 [长度补测](issue-197-long-systemc.md) · [位宽与活动对照](issue-197-seven-model-comparison.md)

SRAM 系数从 #155 的生成器和原始捕获交叉核对。OpenRAM 的 `rise_power/fall_power` 在这份生成器中是 ngspice 的周期**平均功率**，写入前按 0/1 探针分别跨九点取均值。逐点原始窗口均为 **2.916666666667 ns**，对应本次实际表征窗口。将选中操作的均值减去对应未选中的均值，再乘原测量窗口，最后对 0/1 等权平均。直接把表值当 pJ 或乘以 RTL 设定的 3.33 ns 会改变计量口径。系数采用增量能量，未包含空闲银行背景及全程泄漏。原始表征无银行内部连线 PEX。

在查阅的项目分支和验收资料中，找到了 SRAM 与端口负载预算。M 的分位宽能量、DRAM/HBM 和整网端口电容仍缺与本 RTL 同口径的项目校准，表中两项小计使用公开算术参考和项目 SRAM 表征。 [项目 SRAM 源绑定索引](https://github.com/rayggxia-workspace/LLMHardwareDesign/blob/ac29d11ed5728861689046d04a0f03060de2439c/work/YUZE-LU/155/final-033/source-binding-index.json) · [宏输出负载预算](../BLOCK_V2_RESULTS.md) · [M RTL](../../project/rtl/block_v2/block_v2_m.sv) · [Horowitz 原文图 1.1.9](https://pages.cs.wisc.edu/~markhill/restricted/isscc2014_horowitz_power_scaling.pdf#page=5) · [原始九点功率与摘要](../../work/huangpingyang04-lgtm/197/energy-coefficients.json)

#### SystemC C/D 暂存接口

C/D 确实执行了 128 位突发读写。源、目的地址分别是 `0` 和 `16384`，落在仿真器内同一个 32 KiB 暂存数组。每个张量先 LOAD 到 S，再 STORE 回数组的另一个窗口。下表是**单向总线 MiB**，每格 LOAD 与 STORE 相等，均按总线字计，含头部、尺度和尾字填充。STORE 是测试用的镜像回送，不能用来计模型的 KV/R 更新写回。

- **权重**。归一化参数可按调用和参数位置识别，已排除 Qwen3.5 GDN 的单位归一化常数。矩阵权重和卷积系数由 `Checkpoint::memory` 直接提供给宏命令，未经过 C/D 暂存。其余静态参数和未能按来源区分的数据保留在“其他或未分类”。
- **KV**。从 K 拼接和 V 转置回溯到实际缓存切片的 `E.scale` 输入。对齐后的切片、拼接/转置的矩阵和动态 M 的矩阵输入单列为派生操作数。同一数据可多次往返。缓存追加、滑窗淘汰和存放位置由 host 容器管理。
- **R**。Qwen3.5 与 Falcon 的 `R.conv4` 历史输入会往返 C/D。持久递推矩阵 `cache.state` 在 host 读写，状态数据未走 C/D。其余五模型在该测试里没有 R 状态。

服务器对原始轨迹逐文件校验 SHA-256。根据张量序列化、16 KiB 窗口及最多 16 字/突发重建搬运，与七模型全部 165 个处理位置和末尾 C/D 回执的窗口、字和突发数对账。Gemma 有单元素的尺度编码歧义，原轨迹把统一尺度和单元素独立尺度都记作 4 字节。审计先验证受影响的传输都在“其他或未分类”，再用已记录的字数确定该类多出的总线字，其他四类独立核对。表中归属能量已包含在上表 C/D 银行项。 [服务器作业与原始轨迹说明](../../work/huangpingyang04-lgtm/197/README.md#外存访问复核) · [逐类和逐阶段回执](../../work/huangpingyang04-lgtm/197/long/cd-traffic-audit.json) · [C/D 暂存实现](https://github.com/rayggxia-workspace/LLMHardwareDesign/blob/5bc9d4b58ca46101ec4c377de0fc5700ae06539a/project/systemc/llm_cd/payload.hpp)

## 仍缺的输入

- **整模型活动和时间**。需要整模型 RTL 的权重/KV/R 内存轨迹、读写和掩码、各 bank 空闲/时钟门控时长、控制与时钟活动。SystemC 的逻辑流量和抽象时间不足以算整网平均功耗。 [RTL 接口缺项](issue-197-full-model-rtl-gaps.md)
- **计算和片上搬运系数**。M 的不同精度、S40/S64 累加、E/N/G/R/T、寄存器、时钟、互连及 SRAM 实际读写模式尚需按同一电压和活动表征。50 fF 只用于均匀负载情景。
- **权重外存**。为检查点权重、低位分量和尺度元数据分配外存地址，接通权重分片、预取和 S 驻留策略。让模型通过 C/D 或 RTL DMA 发出填充请求，按完成的请求计量。
- **KV / R 外存**。实现 KV 分页、追加、复用和淘汰，确定递推矩阵及卷积历史的驻留/溢出与写回规则。用不重叠的地址区间或描述符标签区分权重、KV、R，记录读写、有效字节、总线字节、掩码和重试，至少分别统计 prefill / decode。
- **外存能量系数**。用与目标接口相符的 DDR/HBM 读写、突发与控制器系数；估算平均功耗还需要 PHY、刷新、背景功率与实际时间。

复算命令会检查两份冻结结果、C/D 审计和新外存汇总 JSON 的 SHA-256，并核对 SRAM 九点原始平均功率与 Liberty 的增量。输出 JSON 可直接用于检查表值。
