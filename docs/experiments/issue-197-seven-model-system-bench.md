## 整模型 SystemC

Slurm `98095` 在 node3 用 8 核运行，21 分 40 秒正常退出。七模型各处理 9 个位置（2 个 prefill、7 个 decode），**63/63 Top-1** 与冻结基准一致。两个 C/D 自测试通过。

| 模型 | Top-1 | 最大 logits 相对 L2 | 导出权重 GiB | 逻辑权重读取 GiB | 逻辑活性峰值下界 MiB | C/D 双向 MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Phi-4-mini | 9/9 | 1.088% | 7.15 | 64.30 | 11.29 | 789.75 |
| Gemma 3-4B 文本 | 9/9 | 0.727% | 7.23 | 65.04 | 6.19 | 887.21 |
| Qwen3-0.6B | 9/9 | 0.953% | 1.40 | 9.99 | 4.36 | 407.54 |
| Qwen3.5-4B 文本 | 9/9 | 0.895% | 7.83 | 70.50 | 2.32 | 379.86 |
| Falcon-H1-3B | 9/9 | 0.686% | 5.87 | 49.98 | 1.35 | 438.15 |
| Qwen2.5-3B | 9/9 | 0.734% | 5.75 | 51.73 | 2.58 | 774.18 |
| Granite 3.3B | 9/9 | 0.060% | 11.77 | 24.92 | 2.06 | 698.92 |

Granite 的导出权重采用历史高低残差项方案，文件体积包含额外表示。Falcon 和 Qwen3.5 的 host 侧 R 状态读写分别为 2.25 GiB 和 0.84 GiB。七模型合计完成 3,120,438 个 C/D 描述符。

整模型沿用 S16 权重和基线数值路径。权重文件大小是已导出的文件大小，权重读取是外层算子按实际访问计数。逻辑活性峰值按算子序号的最后一次使用统计，含跟踪到的尺度元数据。C/D 流量按实际搬运的 128 位字乘 16 字节，包含装载和写回两个方向。各列口径有重叠，应分别阅读。

七模型采用各自的冻结短输入。新跑的 hidden/logits 与此前通过独立参考门的输出逐字节相同，C/D 计数也一致。整模型算术无时钟，静态权重、KV 和部分状态由 host 管理。新的轨迹已把 prefill/decode 分开，逐模型实际 MAC、事务、状态读写和尺度流量见[结果 JSON](../../work/huangpingyang04-lgtm/197/seven-model-results.json)。

## 位宽与 RTL 流水

用各模型第一个 token 的最终 norm 激活和词表投影前八行权重，覆盖完整 K。每种 A×B 位宽经过相同尺度规则和整数点积 oracle，SystemC **28/28** 通过，RTL 三种供数/响应方式共 **84/84** 通过。

下表的周期来自 **双银行预取、无额外背压** 的 RTL 实测。误差为相对冻结解码输入点积的 L2 误差。整模型只跑了 S16 基线，表中的低位宽误差对应八个词表输出。

| 模型 | K | S16×S16 周期 / 误差 | S16×S8 周期 / 误差 | S8×S16 周期 / 误差 | S8×S8 周期 / 误差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Phi-4-mini | 3,072 | 4,720 / 0.0067% | 2,412 / 1.4011% | 2,416 / 0.4370% | 1,644 / 1.4267% |
| Gemma 3-4B 文本 | 2,560 | 3,936 / 0.0240% | 2,012 / 1.7621% | 2,016 / 3.2640% | 1,372 / 3.4932% |
| Qwen3-0.6B | 1,024 | 1,584 / 0.0069% | 812 / 0.7110% | 816 / 1.3448% | 556 / 1.7483% |
| Qwen3.5-4B 文本 | 2,560 | 3,936 / 0.0000% | 2,012 / 0.4888% | 2,016 / 1.3216% | 1,372 / 1.7846% |
| Falcon-H1-3B | 2,560 | 3,936 / 0.0000% | 2,012 / 0.4463% | 2,016 / 0.3642% | 1,372 / 0.3645% |
| Qwen2.5-3B | 2,048 | 3,152 / 0.0046% | 1,612 / 0.5426% | 1,616 / 2.0490% | 1,100 / 2.3100% |
| Granite 3.3B | 1,536 | 2,368 / 0.0034% | 1,212 / 0.8416% | 1,216 / 1.6772% | 828 / 1.9158% |

以 Qwen3.5-4B 为例，S16×S16 从串行的 4,568 周期降到预取的 3,936 周期，640 个操作数装载周期中有 632 个与前一段执行重叠。S8×S8 在同样预取下为 1,372 周期，有效数学工作量均为 20,480 MAC，分别对应 5.20 和 14.93 MAC/周期。每段额外阻塞响应 4 周期时，该例两种格式均增加 320 周期。这些指标覆盖从首个操作数进入到最后一次 S64 读回的 M 通路。

同一例的操作数端口实际传输从 45 KiB（S16×S16）降到 25 KiB（S8×S8）。窄 A 仍经过 128 位物理 A 口，B 变窄使每个 K8 块的 512 位 B 口传输由两拍变成一拍。内部乘法阵列和 S40/S64 存储布局沿用同一 RTL。七宏控制顶层另用三组初态/种子重跑，每组八种组合通过，基础组 217,396 周期，CPU 张量搬运为零。该控制回归使用自身的定向程序。

## 时钟与供数

DMA 扫描固定核心 300 MHz、4S、2 个用户通道、信用 4、外存模型队列 32。两个时钟由 RTL 驱动，吞吐由握手字节和仿真时间得到。

| 外存用户侧假定频率 | 相位（1/3 ns tick） | LOAD GB/s | STORE GB/s |
| ---: | ---: | ---: | ---: |
| 200 MHz | 2 | 1.449 | 1.476 |
| 300 MHz | 3 | 1.948 | 1.964 |
| 500 MHz | 0 | 2.761 | 2.779 |
| 500 MHz | 1 | 2.833 | 2.799 |
| 600 MHz | 1 | 3.191 | 3.198 |

另一组固定 8S、4 通道及 500 MHz 用户侧时钟，信用 1/2/4/8 的 LOAD 为 1.438/2.875/5.623/10.778 GB/s。时钟值是仿真输入。按 300 MHz 换算，上述 Qwen3.5-4B M 切片 S16×S16 和 S8×S8 的预取延迟分别为 13.12 和 4.57 μs。

## 活动量和剩余输入

SystemC 已得到每模型数学 MAC、宏事务、逻辑权重访问、状态搬运及实际 C/D 字数。RTL 已得到切片的 A/B/响应数据线逐周期翻转计数。例如 Qwen3.5-4B 切片的 B 数据线从 S16 权重的 125,394 次降到 S8 权重的 81,977 次，约少 34.6%。采样范围是端口数据线，能耗换算还需计入时钟、控制、内部逻辑、存储访问和外存 I/O。

| 待得到的指标 | 还缺的输入 |
| --- | --- |
| 七模型整网低位宽精度 | 按算子确定量化、尺度和饱和规则，准备低位宽模型导出与完整推理接入，用同一参考门跨输入验证。 |
| 整模型 RTL 周期、流水效率、峰值片上 SRAM 占用 | 可执行的整模型母控/局控镜像和映射，权重/KV/状态进出真实 RTL 接口，逐周期存储/队列/各宏计数，以及与实际 RTL 标定的带时序 SystemC。 |
| 焦耳、平均功耗和能量/token | 一致条件下各位宽宏计算、SRAM 读写、外存事务、数据线及控制的能耗系数，以及整模型调度活动。 |
| 系统实际最高可达频率 | 当前仿真只设置时钟和相位。实际最高频率需要设计实现的时序约束与证据，属于另一个评估层级。 |
