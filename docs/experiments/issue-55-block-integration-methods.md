# Issue #55：Block集成方法与适用边界

本记录配套[实际阶段结果](issue-55-full-block-integration.md)，逐阶段更新；已实现部分以对应作业和输入SHA为证据。两个完整硬件案例不代表任意Block或任意LLM可成功。

## 完整性与版本管理（已实现并完成阶段一验证）

- 输入：实际构建文件表、顶层参数、锁定RTL、选用核心的完整ODB/LEF/Liberty/SDC/SPEF。
- 输出：input_manifest、源码归属前沿、完整展开树、逐状态/内存归属、原生几何表、基准结果索引。
- 方法：从真实顶层保留层次展开，遍历叶实例，按最近的选定核心祖先分配，其他叶归辅助资源；外部测试环境独立标记。类别名不作为额外实例。
- 参数/约束：案例特定顶层、核心选择器和必需辅助层次在配置中。工具未导出参数时，用实际执行参数、锁定源绑定/默认值、实际端口和生成分支作交叉证据；不补造JSON元数据。
- 成功条件：无遗漏/重复、参数和文件一致、实际回归完成；宏清单通过不等于新集成通过。
- 反例：合并ACT+MXU与拆分版重复计数；把llaccel外部SRAM计入core；把raw前端临时环当成RTL缺陷或直接取消check。
- 复跑：对应driver固定commit归档；新输出目录；先核SHA再复用。历史有效同配置回归不重复。
- 正式Block替换字段：核心选择器、原语/状态/存储契约、真实端口位序、模型和工艺版本。

## 基准与逐周期对照（原始观察器已实现验证，集成对照待实现）

- 输入：原完整RTL、原指令/数据、真实外部存储协议、固定seed。
- 输出：完整输出内存、公开请求/应答/状态trace、握手保持和计数证明。
- 方法：观察器只接公共边界；seed驱动独立于DUT输出，并定期解除背压避免环境死锁。逐周期比较valid/ready、写使能/地址/数据和状态，payload只在协议有效时比较，停顿期间另外检查稳定性。
- 约束：保留原参数、容量、协议、复位和断言；预期WAIT超时单独验收。不能以最终数值一致掩盖握手错误。
- 实际证据：open20例、87,160行trace；ll原系统seed0/2补测各30次启动。未完成原RTL与集成结构配对比较。
- 反例/限制：原open旧程序忽略+seed，不能凭参数字符串声称随机覆盖；FakeRAM和二态模拟不证明真实SRAM/X传播。
- 复跑：baseline_extra与open_observer配置；新DUT必须显式绑定，不允许找不到新顶层时回退原DUT。
- 正式接入：提供可执行逻辑模型、协议时序和外存契约；LLM前端以后生成同一计算/存储/通信需求表示。

## 原生几何和迁线（准备与原始目标检查已验证，迁线待验）

- 输入：原生wire/special-wire/via盒、实际pin形状、实例变换、技术层/via规则、可改目标网。
- 输出：目标网列表、固定几何比较、逐端点连通、目标对所有邻近导体短接报告。
- 方法：直接读OpenDB；via按实际cut与两侧包围金属建立连通边；相同层正面积/正长度边接触合并。空间桶枚举所有目标对其他网导体、PG、pin、未连接输出和cut的接触。OBS只作为障碍，不能算导体。
- 约束：同pin不同孤立形状不凭逻辑名自动合并；其他网角接触也保守报出；比较预算耗尽非零失败。非目标-非目标短路不在增量检查范围。
- 冻结方法：原生DEF把非目标线路编码FIXED，用只含NETS的floorplan模式导入派生数据库，并验证所有单元/连接/导体完全一致后才允许运行迁线。实际incremental模式忽略NETS，是已保留的失败。
- 路由验收：仅目标普通线路可变；其余单元/master/坐标/连接/PG/pin/几何精确不变；M9/M10固定占用清零；独立连通与短接；随后同条件DRC/寄生/时序增量比较。
- 复用：PR45四个几何原语注明commit及SHA；此处增加原生表与目标对全部邻居适配，不宣称新算法。
- 正式接入：真实层/通孔、pin几何、OBS、方向和时序模型。工艺规则仍须原生DRC；几何checker不代替制造签核。

## 共同布局、预连线与最终定制（尚未实现验证）

M5/M6→M8扇出须真实固定导体与通孔。M8↔M9定制via的低层包围必须位于已冻结M8落脚金属内；两例不得因via增加底层覆盖。固定有源适配器统一列入资源并集，不在某案例布线后新增。一次完整底座改变须重新验证两例；当前无冻结版本。
