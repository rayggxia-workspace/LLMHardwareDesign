# Block v1：M、V、R、S、T 五种基础宏实施计划

2026-10-27 CST，Issue #121 / 草稿 PR #122。按用户最新指令执行；每种仅一个基础实现，不做裕量版本。完成条件是**五块均有最终 M1–M10 布局布线与逐块接收结果**，不是完成本计划、RTL 或综合即结束。

## 目标与范围

先获得可预制的计算积木。宏内部有源资源、存储、时钟、电源、M1–M10 与原生 via1–9 固定；留出真实 M10 接点，供后续自建 M11/M12 与 via10/11 连接。Nangate45/FreePDK45 本轮原生最高路由层为 metal10。下一轮才做阵列规模、多实例组合、跨块预连、两个完整产品和一般十二层寄生提取。

物理边界固定为 M 完整矩阵乘加、V 三通路向量、R 两模式递推、S 16KiB 工作存储、T 6KiB 结果交接。裸 M8 与混合 VS 已被用户否定为最终边界，旧候选只保留历史证据。计算宏内必要的局部存储计入自身，不能从 S/T 容量中虚借。

## 实施顺序和验收

1. **数值与接口规格**：以 [五宏规格](../../docs/BLOCK_LIBRARY_V1.md) 为当前唯一清单。明确 lane、tile、数值域、缓冲、端口、握手、操作延迟、溢出和复位。对照固定 main 6a681d6 的算子图和数值报告；不以 FP32 单层 prefill 验证推定整数模型质量。
2. **完整 M**：8×8 S8 基础乘法阵列、本地归约/64bit 累加、16bit radix128 分解、128bit 跨组合并、一次最终 RNE/饱和、操作数缓存及有限响应。投影、QK、PV 分别验收；不能把原始乘积送 V 归约。
3. **结构化 V**：八路逐元素/格式，两路 EXP/激活与独立组级 reciprocal/rsqrt，归约统计上下文、回放缓冲和固定内部连接。先验证原语再验证 RMS/L2/Softmax/激活/TopK/RoPE 组合；近似误差、溢出、尾块、跨块统计与背压分别测。
4. **独立 R**：GDN、SSM 共用状态 tile/八路乘加、影子更新和错误守卫；含四抽头因果深度卷积与历史访问。GDN 的完整 key 维局部保留，不能在得出全域误差前按 key tile 提前更新。投影 M、外围归一化/门激活 V；两模型不同 norm/gate 顺序留在宏之间。
5. **S/T**：独立 S16K 的真实标准单元映射/读写协议/初始化约束；T 沿用已选 C 的实际源码和最终结果，补统一导出、版图图、M10 接点与限制。既有 C8 中的 S 不代替独立 S 结果。
6. **逐块最终物理实现**：每块一个默认方案，原生 floorplan/PG/place/CTS/route/finish/RCX；所有端点 setup/hold、actual<=limit 电气、连接、供电、完整 FreePDK45 deck GDS DRC、最终网表功能与源/约束保持。失败就修该实现并版本化，不以第二个裕量版本或弱化门槛绕过。
7. **交付五份最终包**：精确 RTL/配置/工具/输入 SHA，最终 V/SDC/DEF/ODB/GDS/SPEF，pin XY/层/形状，实际面积/外框/存储/频率条件/延迟/吞吐，DRC/STA/功能原始回执和版图图。LEF/Lib 如导出须单独注明资格，叶块 P&R 通过不自动等于通用层次模型合格。

## 资源和调度

本任务使用 6～8 个节点，PENDING/未知 allocation 也计数，其他成员不计入且不操作。c96 申请实际 96CPU，默认 **6×16** 独立任务；不同宏、功能验证、映射、物理阶段进入共享队列，**任务结束立即补下一项**，不整批等最慢项。仅有实际内存不足或真实依赖才降低并发；记录可用 RAM、逐任务测量/保守估计的区别、依赖回执和恢复条件。单任务扩核差就增加独立并发，不把节点内退回两路小任务作为常规方案。资源数是许可上限与目标，不凭空启动重复、无意义或尚无输入的工作来占满节点。

## 开源借鉴与当前证据

M 参考 llaccel 固定 f7db8a2 的阵列、归约、累加、局部缓存结构；openTPU 固定 91df410 的局部完成/有限 FIFO/背压也作参考。先比数值、端口、容量与许可证，再决定是否复用 RTL；本轮没有因引用而直接移植或宣称上游验证等于本宏验证。

启动本计划时，只有 T 的选定叶块 C 已有最终原生物理/完整 deck DRC0/三初态最终网表功能证据。执行后的逐块实际状态以[五宏交付入口](../../work/YUZE-LU/121/delivery/README.md)为准；不把本段启动基线当作当前验收状态。通用层次 Lib 仍须单独验收。全部五块完成前，本任务继续 in_progress，PR 保持草稿，不提前关闭 Issue。
