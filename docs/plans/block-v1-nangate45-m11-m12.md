# 第一版计算积木：清单、规格与逐块最终布局布线

更新：2026-10-27 CST。Refs #121，持续草稿 PR #122；依据用户本次明确纠正执行。本文件是本轮实施范围；历史 P0–P6 系统方案保存在 archive，不再作为本轮整体完成门槛。

本轮交付必须回答“有哪些物理积木、内部放什么、外面留什么接口”，并完成**每种入选 Block 的 M1–M10 最终布局布线与接收**。只交文档、RTL、综合或局部探针均不算完成。

## 1 工艺和范围

- Nangate45 原生 M1–M10、via1–via9 完成块内计算、存储、PG、时钟及固定 M10 landing。布线修复进入库存与面积，最终再冻结。
- 为以后 via10/M11/via11/M12 连接保留真实 M10 接入几何；本轮检查其合法位置、宽度、间距、OBS 与内部连通。
- 阵列规模、多实例组合、公共底座、跨块预连、两个完整产品、任意十二层分布 RC 提取及系统敏感性移至下一轮。它们未完成不阻止合格的单块结果交付；已有失败和假设仍如实保留。
- 所选 Block 内的数值、有限缓存、响应保持、owner 和提交语义仍要验证。不能把功能错误、短路、时序或电气失败当成“范围缩小”后可接受。

## 2 当前进入验证的四种物理边界

清单与逐项规格见 [BLOCK_LIBRARY_V1.md](../BLOCK_LIBRARY_V1.md)。这是从真实已有资源抽出的第一组边界候选，尚未冻结为合格库。

| 物理 Block | 内部内容 | 本轮决策重点 |
| --- | --- | --- |
| 8 路 INT8 乘积块 M8 | 八个 S8×S8→S16 乘法器，无隐藏存储或累加器 | 128 输入/128 输出的乘积接口是否值得独立；不能称为完整 GEMM/MAC 阵列 |
| 向量、归约与状态处理块 VS | 单 S32 乘法器/两响应槽、U128 除法/开方、原有加法/归约/宽 guard/RNE、M/A/R/GDN 控制及有限外存桥 | 明确保留的标量共享与全部控制成本；矩阵累加仍在此，不能隐瞒 |
| 16 KiB 工作存储 S16K | 1024×128 bit，单 1RW、有限同步响应 | 一份真实标准单元存储独立硬化；不把 C8 中已有实现说成独立宏已通过 |
| 6 KiB 事务缓冲 T6K | 384×128 bit、提交/撤销/消费/释放控制 | 优先复用已通过完整原生物理接收的实际 A/C 结果，保留宏模型资格限制 |

A 复用 M8/VS 的计算，R 复用 VS 的算术和 S16K 的 scratch；D 的命令、owner、外存桥留在 VS，结果交接留在 T6K。六类逻辑职责不是六套重复算术硬件。原 C8 是工程基线与恢复比较对象，不再直接充当整个首版 Block 清单。

参考 openTPU/llaccel 的局部乘加、有限 FIFO 和明确存储时序。原始乘积接口的代价必须量化；若实际 pin/时序证明该切口不合理，只做一次有依据的调整：把与矩阵累加紧耦合的部分并入同块或将局部归约移入乘法块，并重跑受影响的单块功能和 P&R。不能靠给乘法块换名字宣称有完整矩阵引擎；不先扩展为通用 ISA、16×16 阵列或新的模型。

## 3 执行顺序与门槛

| 阶段 | 工作 | 实际完成条件 |
| --- | --- | --- |
| B0 边界与规格 | 四种候选、六职责归属、资源唯一性、内部连线、M10 接口、源码版本与参考取舍 | 每个计算/存储/控制资源有归属；区分已实现、候选、未验证 |
| B1 独立顶层与功能 | 从原资源抽出真实顶层；保留原数学；记录组合/时序接口；独立功能和必要的重接比较 | 不删除有效端点或借测试环境免费存储；源码逆变换仅为准备证据，不能代替功能验证 |
| B2 综合与 pin | 全资源映射、真实 pin 位数、实际标准单元面积、同源结构视图/SDC、尺寸与 M10 pin 规划 | 先以映射面积和 pin 容量确定可解释的首轮尺寸/预算；不能把旧 C8 的 4mm²直接套给所有块 |
| B3 逐块完整 P&R | floorplan、PG、placement、CTS（有真实时钟树时）、route、finish、RCX，全部原生层 | 每块有最终网表/ODB/DEF/GDS/SPEF/SDC与实际日志，不以 global route 代替详细布线 |
| B4 独立接收与修复 | 全部实际端点 setup/hold、cap/slew、全 deck DRC、连接/PG、精确 M10 pin、RC 覆盖与最终网表功能 | 失败继续修复；组合 M8 按真实 IO→IO 路径验证，不能伪造寄存端点或 CTS；T6K 允许逐来源复用现有合格物理结果 |
| B5 冻结与交付 | 定型清单、每块参数/接口表、最终物理图/指标/数据索引、失败与适用条件、可接续命令和 PR 审查 | **所有最终入选块有实际完整单块物理证据**；未完成的跨块系统项目单列为后续工作，不冒充通过 |

目标时钟沿用 10ns、uncertainty0.1ns、BUF_X2 输入驱动、2fF 输出负载、输入/输出 max2ns/min0.2ns，见原 physical-budget.json。这些是首轮明确测试环境；M8 用虚拟时钟/IO 预算，不能声称 100MHz 流水吞吐。新顶层每个实际 pin 都要覆盖，容性单位以原生工具读回为准。面积上限/外框由 B2 实际映射库存与 pin 需求生成并在 P&R 前锁定；没有实测时不得填成结果。

每块最终必须交付：RTL/精确最终门级网表、LEF pin/OBS、ODB、DEF、GDS、SPEF、SDC、工具/工艺/source/input/output SHA、面积与外框、时序与电气、全 deck DRC、连接/PG、pin 布局图及功能回执。若导出 Liberty，明确其校验域；现有 #127 暴露的层次寄生问题保留，不能把未合格抽象当作合格系统模型。本轮以真实单块 P&R/原生 STA 为物理依据。
