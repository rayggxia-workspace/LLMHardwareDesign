- 不加入掩盖真实违例的false/multicycle约束；真实register、input/register、register/output路径全部覆盖。新流水延迟/II/队列与旧周期不能混用。
- 数据口先评估128bit每拍一字与有限预取；未确认前不冻结最终端口。若保留128bit口，M批1无权重复用的供数利用率须据实低于64乘法器峰值，不宣称带宽凭空增加；若改宽，完整新端子全部计入物理引出。

## 执行顺序与真实依赖

1. 规则/审阅输入封存；并行读取五个旧最终ODB/SPEF在新约束下的诊断，确定需切开的真实长路径。诊断完成不等于旧版已300MHz合格。
2. 同时做小型完整条带及转向几何检查。先收敛薄条带，失败才增加一个靠边对照，不全参数扫描。
3. 先推进S/T连续接口和M供数/流水合同；V与R按自己的算法依赖实施。更新独立事务/数值参考、周期计数及早期综合/时序；规格与真实端口一起冻结。
4. M/T先行完整端口引出与有限原生预连检查，再将同一选择用于五块真实最终P&R；必要扩大外框时计价并说明原因，不把旧外框当不可变硬条件。
5. 每个新最终源独立完成STA/电气/RC/PG/连接/原生及完整GDS DRC/最终功能/严格LEC，五个包分别接收。所有源/配置/工具/输入/SHA完整保存，不转移旧资格。
6. 用实测周期和字节重算代表模型资源/带宽，只报告有证据的估算，最后统一提交审查。
