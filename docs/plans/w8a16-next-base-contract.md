## 0. 首版实施决定与证据限制

采用 **X放原16 KiB私有S、每P两个外置256 B A片段槽、同对象/同K128多消费者只读复用、有限early-copy**；不装32 KiB共享池及其FIFO，不复制4 KiB X寄存器，不启用LVT。每P另有一个16 B搬运保持槽，全部外置存储和控制逻辑单独计面积。共享方案保留为研究对照，不同时生产两套底座。

[46次完整trace与九包审计](../../work/YUZE-LU/250/performance/README.md)在根分支独立复核通过：共同条件基线9.21564723269，NoPool9.2237871361；准备16拍/phase8且两种ACK2拍为9.21743463751。单256 B A槽为9.1985173609未过门。NoPool不减少DDR/算术任务，S的重复X读取由405798912降为38043648 B；两个槽有可观察用途。

**这些是局部服务严格化的共同条件模型，不是整颗S原生端口已校准的系统成绩。** X/copy和Down prior/结果ACK已按128b，G gather、G/Mid部分`sio`及FFN外矩阵/向量S仍继承原64 B/拍日历。必须用真实RTL将全部调用回校；M输入bank早释放与两个独立结果槽也属于待校准的生命周期变化。不能用这0.02%–0.09%模型余量掩盖未计原生开销，最终仍需达到用户同条件性能要求。

2026-11-11补充[公共S128敏感性诊断](../../work/YUZE-LU/250/native-s/README.md)：八配置16次trace通过，历史数字精确复现。P/U公共服务改128位后Xreg=7.58559135633、NoPool=7.59543329637 token/s；相对原9.215647目标-17.581119%，**性能门尚未通过，资源尚未最终冻结**。后续用真实有限A/copy、G-S、M/W/RF/result和MC/LC周期回填并改进，不回退口径掩盖缺口。单元物理候选可并行迭代，资格与整机冻结分别记录。DDR总线读3,388,365,824 B、逻辑读3,365,952,512 B，两者不混称；全部对照工作量一致。

## 4. 数值与部署格式

普通投影W8/group128，head W8/group16独立scale，embedding保持公开FP16例外。每128项A16×W8点积最大绝对量不超过2^29，S32组和足够；它不证明全K无条件同尺度S32精确累加。

组后按公开FP16 scale和A片段移位转换，RNE到持续S32/Q16，再按已声明顺序累加；每个前缀检查范围。bias的位置、零点、first/continue/final和异常策略逐位定义。G可有临时S64乘积，但随后RNE并只保存Mid32；临时宽量与持续状态分别计账。不裸截位，不保留旧S128大加法器冒充新方案。

普通record仍是1024 B W8+16 B scale+48 B pad，head为1024 B W8+128 B scale。冻结真实N/K/lane字节顺序和scale字段；PR249的header-first/K-major合成检查不能代替公开checkpoint逐字节部署证明。四银行先写齐全部record并收到ACK，再读8个128 B操作数；输入读租约、结果保持和目的S写ACK相互独立。

PR243 A32原接口由两条旧K8容器组成，不自动成为新K16同一行32 B。必须定义读地址、tile/row次序、尾mask、响应tag、拼接槽和背压；必要adapter在M1–M10做有源实现并计费，M11/M12只负责接线。

## 5. 对象、控制与指令

首版NoPool对象：S内4 KiB X有epoch/源窗口租约；最多两个256 B A tile槽，键含对象、kk、generation和消费者序号。加载完成与权重record完成独立；M仅在两者真实JOIN后读取，同一个A可对多个M use重放。END_USE关闭新消费者，全部预定/已发起/已消费次数及读义务排空后才复用槽。

early-copy由U的普通128b源读和三个P各一个16 B保持/写ACK完成；每片归一化的真实写ACK之后才能读走，下一片计算可在有限资源允许时重叠。每P目的X片段实际写入后才能ALOAD。串行/并发端口、在途容量、phase切换和迟到ACK逐项计费，不把整个X就绪提前到首片。

W输入消费与结果S提交是不同租约。生产候选允许W末操作数真实消费后释放输入bank；两个**独立32 B结果槽**各等目的S两个128b字的实际ACK。command metadata槽不等于结果槽；满则反压。输入bank generation可复用，结果ticket身份仍独立有效。此规则需与历史模型的bank持有到结果ACK区别回校。

以下共享池生命周期为研究对照和未来扩展合同，**不在首版NoPool生产路径**：

共享池生命周期为 `BEGIN → 顺序FILL → 全部写ACK → SEAL只读 → 多次LOAD → 停止新LOAD → 排空 → RELEASE`。当前池在只读服务期间不能同时FILL另一个对象；本版不把它当Mid生产/写回池。完整Mid32为44032 B，不能塞入32 KiB后声称容量已解决。

多个P、多轮gate/up和输出tile都可能继续读同一对象。已有接受的LOAD清空不代表未来消费者完成；母控需登记epoch下的预定读阶段或显式关闭读入，再撤销/排空已接受请求。reader mask仅识别读者，不能替代重复消费计数/关闭条件。A片段装入M后可释放该读租约，权重、计算和结果S ACK另保留。

保留64bit `G_CALL/G_WAIT/G_END` 与 `L_EXEC/L_WAIT/L_END`框架，新增**版本化服务/描述符和真实adapter**；不得说旧opcode已实现全部新动作。描述符至少绑定profile/topology、source空间/base/length/epoch、tile/row/尾mask、context/generation、group/scale/rounding、first/continue/final、目的地址和ACK事件。未支持版本必须拒绝。

母控现有物理交付仅有限目标/驻留槽，九组同时运行需要扩目标索引、事件、credit和程序/描述符存储。首版不注册SYS_X共享池target；early-copy/A前端属于实际选定控制资源。若未来另加共享supervisor，控制归属与计算五类区分。指令位宽不一定要变，但服务调度与存储、取消/错误恢复均须重新验证和物理验收。约3028352个M组不能假定每个都由母控零费用装载大描述符；必须实现有限任务模板/局部循环或逐项计取指派发开销。

失败可能发生在A装好但B失败之后，重试必须重装一致的操作数，不能假定回滚。复位先停新请求、排空/确认已接受事务，再协调P和pool generation；旧epoch迟到返回不能污染新对象。共享池监督和LC之间的ACK不能只用延时猜测。

## 6. 物理边界和面积门槛

保持独立功能宏、私有S、局控与必要适配器。面积按实际功能电路+SRAM+保持/选择/缓冲+路由/PG/端点裕量记账，五类分组的包围矩形仅用于展示与布局软偏好，不当硬宏面积。

物理盘点从main紧凑实现提取相同口径的 `standard_cell_area`、`SRAM_macro_area`、`core_area`、`outline_area`、halo/空隙和全部真实pin。**有效占地利用率原则上不得低于匹配的main紧凑基准**；综合设置的utilization参数不能代替最终占地比。新算术增加的真实电路面积单列，任何为端点/PG/时序额外留白给实际失败及最小可行尺寸证据，不自行放宽目标。

接口安排参考紧凑S_P：从真实M10 pin几何、位序、间距、局部逃逸和可用via出发。全位DATA、valid/ready、ACK/tag、时钟/复位/PG逐项纳入；不依赖方框外代理pin。数据边同组和跨组统一登记预连或后制。预制选择器、驱动、中继必须在冻结前存在，单靠M11/M12不能创造多源选择或提高驱动。

最终验收：同原规则/工艺的M1–M10详细布线、原版完整GDS DRC=0、原Liberty电气限制、连接/PG/SRAM时钟、TT1.1V25°C提取RC下300 MHz setup/hold、最终ODB网表多初态回放和必要银行等价、实际M10端点接入/上层规定RC。规定RC模型是研究资格，不替代完整顶层的真实抽取与时序。

新叶宏合格后，五类分组、MC/LC和真实共享/跨组路径联合验收；叶宏通过不能推出系统通过。全产品Attention/FFN/GDN/其他层静态网取并集，程序分时本身不减少金属。
