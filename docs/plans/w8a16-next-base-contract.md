# 下一版独立叶宏底座：W8A16、宽 G 与有限存储合同

状态：候选合同，待独立审查；生产实现、完整整数模型、联合 RTL 和物理验收均未完成。研究依据为 Issue248/PR249 的不可变质量、RTL 和 SystemC 回执。此文件不为当前已验收底座新增能力。

## 目标与边界

支持 Qwen2.5-3B-Instruct 的公开 GPTQ W8 权重、A16 分组激活和有限 FFN。继续保持 P/U/C/F/J 为控制归属、功能宏为独立物理实例；不用五个大硬框封装。母控/局控归属固定，预连逐条登记，模型相关静态数据网由顶层 M11/M12 定制；新有源服务必须在下一版 M1–M10 冻结前实现。

研究条件结果约10.10 token/s，batch1/context512 decode，300MHz、102.4GB/s总外存预算。51.2GB/s约9.24，context2048约6.41。它们不是现有底座或芯片实测。浮点 Attention/RMS 的质量筛查通过，完整整数语义和真实 SRAM/局控尚待闭合；不得把约10的结果写成系统已验收。

模型保守SRAM峰值为16KiB；另外的寄存器/B槽有源预算须单列。宏面积不能用“总字节数差不多”代替；尤其128B/cycle的B读取、S128合并和大移位器可能决定面积、功耗与300MHz是否可达。

## 数值与记录格式

权重 W8 和正 FP16 scale 精确拆成整数mantissa/二进制exponent。普通投影W8/group128，head候选W8/group16，嵌入查表仍保留公开FP16。A16每128个元素一个二进制移位；M按权重scale边界输出部分和。所有部分和先合并到S128，全K完成后一次RNE得到S32/Q16。G输出完整S64/Q32 Mid，再分组归一化给Down。禁止裸截位、未登记饱和、丢弃公开zero-point或假定INT8权重意味着INT8激活。

普通记录为1024B W8+16B scale+48B pad；head记录为1024B W8+128B scale。W按8个K16子拍排序，每拍8输出×16权重=128B。B槽必须等全部17/18拍写入ACK后才可读，M接受所有子拍后才能释放输入租约；结果和S写回租约独立。

## 控制与真实接口

每个资源列出命令/响应位宽、ready/valid、tag、地址、存储窗口、错误和reset/flush规则。候选原生信号包括：M的256bit A、1024bit W、320bit部分和；G的两组64bit输入和128bit输出；scale服务的8路S128状态；B的512bit DMA和1024bit供数。它们不是现有main端点的别名。

新增局控描述符须明确：权重记录/子组数、A片段与scale、投影context、first/continue/final、S128部分和地址、最终bias/shift、G格式、destination ACK和generation。可复用母控的依赖/派发框架，但旧的M服务封装不能自动驱动上述接口。先给这些动作定义版本化服务合同，再实现局控lowering、程序回放与错误恢复；未经检查不可让新程序运行在旧拓扑上。

真实S接口按128bit等原生宽度串行搬运S128状态，不宣称S有1024bit物理端口。分别测首字延迟、持续吞吐、读写/多客户冲突；不能把接口位宽直接当成每拍可用带宽。保留直到真实写ACK，跨组消费者完成前不覆盖Mid。

## FFN与编译器

128个Mid为一片，三个P分摊Down的688/680/680个输出。每P最多64活跃输出的参考验收保留；实际服务一次八路，S存完整部分和。每FFN本地部分和读、写各2,785,280B，必须计入。

综合器候选需同时带数值合同、寄存器/私有S/端口需求、真实端点和静态线束集合。每次前沿扩展按当前驻留、端口预约、bank和ACK重新计费。当前研究固定FFN调度不是#220的布线路径DP；新硬件的收益与同资源调度收益分开报告。全产品跨层静态网取并集，不能因为分时执行就删除金属。

## 分阶段验收与退出条件

1. 固定公开checkpoint/config/scale/tokenizer/执行范围与逐位软件参考；归一化、RoPE、Attention/Softmax、KV、残差、head全部进入同一语义。先执行完整整数模型质量检查，再声称“所有精度问题已解决”。扩到完整语料及长期decode，保留预先声明门槛及失败候选。
2. 串接 M、scale/RNE、G、真实S、有限B/feeder与局控；实际模型片段逐位一致。覆盖填充/写ACK延迟、交叉背压、满槽、错误generation、复位、部分和最后一片及源释放。head的16子组scale服务单独校准。
3. 用联合RTL得到的实际延迟、吞吐、容量、端口争用校准SystemC。源自相同映射/程序/拓扑，报告prefill、context512/2048 decode及更长上下文；达不到约10就保留差额和瓶颈，不调整费用凑数。
4. 新叶宏、feeder/bank与局控分别实现物理；选择器/保持/中继在底座冻结前落实。端点可达、电气负载、时钟、电源、原规则DRC、连接与提取RC下setup/hold均通过后，再验顶层M11/M12静态网并集。
5. 能耗来自实际表征/活动和存储/外存预算；同模型同精度对照FPGA/ASIC，披露资源与未覆盖项。没有证据的实测token/s、J/token和物理资格保持未完成。

若任一新增有源资源导致时序/面积或完整整数质量不合格，回到资源候选和映射共同重选；不能沿用独立叶宏通过来宣布整机通过。
