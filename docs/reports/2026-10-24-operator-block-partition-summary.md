# 算子与 Block 划分阶段性总结

**阶段成果：已完成算子与 Block 的架构级划分，形成六类功能分区、算子映射、状态归属、接口规则及内部预连线候选。**

日期：2026年10月24日

项目：LLMHardwareDesign——面向多类 LLM 工作负载的预制计算底座

主要负责人：Liangruizhi

本阶段已经得到可以用于后续映射、资源调度和 RTL 验证的具体方案。当前完成范围是架构与接口层；独立硬宏的最终边界、资源规格、物理实现及端到端收益仍需后续验证。

## 一、研究问题与本阶段完成的工作

围绕以下共同问题开展研究：

> 给定几类有差异的 LLM 工作负载，哪些计算、状态和通信应当在制造前固定在一个 Block 内，哪些连接值得留到产品确定后再定制？在真实存储、端口、布线和时序约束下，这种划分能带来多少端到端收益？

本阶段完成了四项主要工作：

1. **建立划分方法。** 从计算图中显式拆出矩阵计算、归约、量化、单位对齐、舍入、饱和、状态更新和同步节点，再识别必须共同满足数值与状态约束的操作组合，最后比较它们的物理归属。
2. **形成具体方案。** 给出 M/V/A/R/S/D 六类功能分区，明确各类承担的计算、持有的状态、交换的数据和需要的反馈连接。
3. **用真实模型张量检验关键边界。** 覆盖普通 GQA、QK 归一化、局部/全局注意力和连续递推等结构，检验 scale 传播、INT32 部分和、重新量化位置与状态格式。
4. **建立可复查证据。** 保存源码版本、配置、输入和结果 SHA-256、服务器作业记录、独立整数参考、失败条件及接收工具，形成方案与实验之间的对应关系。

## 二、已经形成的算子与 Block 划分

以下六类是当前架构基线。其中 M/V/S/D 为基础模板候选，A/R 首先作为逻辑功能分区；六类功能不等于已经确定要制造六种独立硬宏。

| 分区 | 主要计算与算子 | 状态与数据归属 | 内部连接和外部接口 |
| --- | --- | --- | --- |
| **M：矩阵计算与归约接口** | QKV、MLP、输出投影及注意力 QK/PV；S8 乘法、INT32 局部累加，按单位完成对齐归约 | 操作数 tile、部分和、单位与组计数；超出已证明范围时保留宽格式或拒绝/回退 | 内部保留 MAC→局部累加反馈；对外区分部分和/完整结果，携带 scale；重定标保留近M或共享V两种位置候选 |
| **V：向量、非线性与格式转换** | 残差、归一化、RoPE、SiLU/GELU、scale处理、量化和重定标 | gamma、epsilon、LUT/scale版本和临时向量 | 归约/转换→舍入与饱和；接收携带单位的数据，完成残差/完整hidden归一化后发布新的激活格式 |
| **A：注意力逻辑分区** | mask、softmax、概率归一化及注意力归约控制；QK/PV 调用 M 的矩阵资源 | 概率归约上下文、mask、长度/窗口与KV版本信息 | score→max/exp/sum/div→概率→PV反馈；与M双向连接，独立A与M+A同宏仍是物理候选 |
| **R：递推与卷积逻辑分区** | 卷积历史处理、完整K预测、delta、递推更新；从新状态生成输出并共同提交 | 连续history、递推状态、位置、owner及scale/epoch；大状态由S提供后备 | history与state反馈；提交前核对版本/范围；可独立实现或共享V的计算资源，具体算术能力待资格验证 |
| **S：存储分区** | 分银行读写、存储仲裁与数据供给 | 权重、共享KV、局部窗口ring、递推后备页及对应元数据 | 接收FIFO→单银行仲裁→SRAM→发送；按实际端口、生命周期与有效长度供给计算分区 |
| **D：搬运与控制** | DMA、地址生成、循环、命令队列、credit、完成/异常处理 | 描述符、队列、状态版本和完成事件 | 有限队列与背压控制；先写数据再发布有效状态，协调已有端点之间的传输 |

矩阵主能力以 **W8A8、INT32累加** 为候选目标。KV、向量、概率和递推状态分别定义格式，不统一假定为INT8；INT16/宽乘、除法、开方、查表和格式转换必须独立计入实现及资源成本。

## 三、已经确定的关键边界规则

### 1. 完整归约与重定标

矩阵部分和必须明确单位及归约进度。相同单位可按受检范围累加；混合 scale 需要显式对齐。最终舍入/重定标必须遵守选定数值合同，不能用提前分组重定标替代完整归约后的一次最终重定标。

因此保留带单位的部分和接口、完整结果接口，以及 ACT8/ACT16 出口候选，避免把唯一出口精度和重定标位置提前固化。

### 2. 残差、归一化与后继量化

将“单位对齐→残差相加→完整hidden统计→归一化→新激活量化”作为共同设计的逻辑链。归一化后重新产生 A8 及其 scale，因此上游 ACT16 不必直接传递成下一矩阵的16位乘法。

完整hidden统计、scale扫描、gamma读取和临时缓冲都需要实际资源；这些操作是否位于同一物理宏内，由后续同资源调度决定。

### 3. 共享KV与连续状态

GQA中多个Q头共享同一KV语义与格式版本，广播、重复读取或受控复制均需计入容量和端口成本。局部窗口与全局注意力采用不同的有效长度和生命周期规则。

递推状态必须连续，不能在每个窗口清零；完整K预测完成后才能形成更新，输出由新状态产生，状态与输出同版本提交。共享K不代表可以合并两个V头的独立状态。owner、位置、scale/epoch和范围守卫属于必要接口内容。

## 四、支持划分的实验依据

模型按架构差异选取，而非扩大品牌数量：

| 已用代表 | 对划分的检验作用 |
| --- | --- |
| Qwen2.5-3B、Llama-3.2-1B-Instruct | 普通稠密 GQA、共享KV及MLP/down投影量化 |
| Qwen3-0.6B | 带QK归一化的注意力与小规模完整GQA整数验证 |
| Gemma 3 4B | 局部/全局注意力、窗口边界及不同非线性 |
| Qwen3.5-4B | 递推/全局注意力混合、连续卷积历史与递推状态 |

Phi保留为冻结方案后的独立验证，尚不计入当前泛化通过。原版DeepSeek-R1的MLA/MoE未被本阶段数值验证覆盖，蒸馏版不能替代该架构证据。

最新一批服务器作业90059–90082共24个，包含采集、双轮数值实验、独立接收和归档，均已正常完成。主要发现如下：

| 实验 | 观察到的结果 | 对划分的影响 |
| --- | --- | --- |
| 完整hidden消费者链 | down的完整H=2560输出→残差→完整RMSNorm→下一投影前16/8192输出；静态ACT8和同范围ACT16各37次饱和，tile动态delta本批零饱和 | 保留逐通道base+tile delta及ACT16候选；增加位宽不能替代范围选择 |
| 提前统一scale | 转K128每行节省128B，但增加norm及最终RQ前next16误差 | 不强制早转K128；scale元数据、重编码和通信必须联合评估 |
| 整数input RMSNorm | 相同X16输入下相对浮点norm误差最高约0.00005%；计入X16重编码后，对原浮点norm误差最高约0.05862% | 已有可独立验算的整数候选，需显式提供宽乘、sqrt/div及舍入能力；不代表所有norm或完整模型已全整数化 |
| 归一化缓冲 | aligned I64整行20,480B超过原定V16KiB；声明的两遍源读为51,200B/行 | V必须采用有成本的重读、流式或spill方案，不能假设整行免费驻留 |
| 连续递推32步 | S16输出局部相对RMSE约0.64%，S32约0.057%，受检新窗口均无state饱和 | S32可作为优先工作参考，同时保留S16取舍；不能据短窗口固定通用范围 |
| 真实长窗口 | 相同物理范围下S16/S32都可触发184/193次最终state饱和 | 范围守卫、合法重定标epoch或回退必须纳入R/S接口，更多位不能自动解决范围问题 |
| R状态缓冲 | K128×V32的S32 old+shadow合计32KiB，已占满原定R scratch | V16 tile、S侧shadow及可证明的原位提交需公平比较，不能仅凭状态反馈决定R独立 |

上述误差是对应局部张量、格式和条件下的相对RMSE，不是模型整体质量指标，也不是硬件加速结果。下一投影只验证所选16输出，不能表述为完整8192输出或整层GDN通过。SiLU、R内部QK L2norm/GatedRMS及gate等路径仍存在明确的浮点桥。

## 五、制造前固定与产品确定后定制的划分

当前建议制造前固定的内容是：矩阵局部累加反馈、银行仲裁、有限队列/背压、已选择数值路径的归约与舍入、状态反馈及提交控制，以及经过资格验证的算术单元和接口端点。具体数量、位宽和吞吐参数需要资源调度与RTL验证后冻结。

留给产品确定后的选择包括：M与V/A的配对、计算分区与S银行的连接、R状态后备连接、广播/复制/多跳路径及资源绑定。连接只能使用制造前存在的端点和获准定制层，不能在产品确定后凭空增加有源资源、存储或端口。

| 完整模型整数质量、RTL/物理实现与端到端PPA收益 | 尚未完成验收 |

下一阶段聚焦三个分叉：

1. **V与重定标组织：** 在相同精度、16KiB缓冲及单口约束下，比较两遍读取/流式处理，以及近M与共享V的组织。
2. **R与状态组织：** 先冻结范围守卫、重定标epoch或合法回退，再比较V16 tile、V32+S-shadow或有证明的原位提交，并加入相同FFN/attention竞争负载。
3. **制造级资格：** 校准宽算术、LUT/除法/开方、银行端口、布局与连接端点；接收现有物理集成工作的时序和布线证据，收敛独立宏边界与资源参数。
