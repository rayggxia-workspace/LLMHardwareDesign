## 4. 怎么理解这份清单

Git blob标识使用Git对象算法，SHA-256用于本次原字节核对，两者用途不同。离线检查会从原字节重算Git blob，核清单、zip成员和声明来源；它不能仅靠哈希证明作者或源实验数学正确。

若PR后来前进，先确定要复现本报告固定版本还是新版本。新结果可以增补，不覆盖旧快照和失败。大文件继续留授权位置，通过各实验索引接收。
