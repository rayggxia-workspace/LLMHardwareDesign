# 有限 S、共同阶段后端与连接条件下的剩余成本

Issue219/PR220，2026-11-09。仅为常量原生/描述符成本模型；不提供真实 DMA、RTL、
地址/银行仲裁、系统周期、能量或 token/s 资格。一般 tile 和脏结果驻留仍见 [MEMORY_REUSE.md](MEMORY_REUSE.md)。

## 共同执行后端

`phased_compounds.variants_for()`保留全部原候选，给部分静态列分片增加一个显式协议：
每个孩子独占自己的 M/S/局控，共享外存通道只在原一字描述符完成边界按 FCFS 交接。
**整个父服务从共同开始到最后 ACK，仍占有全部资源并集。** 其他任务不能进入这段预约。
这是父服务内部的协作执行，不是一般跨任务事件调度。

首版动作族采用共同 K-prefix 配方：孩子的行数、K、数值分量和前缀长度相同；
列宽、所在实例及当前缓存命中可以不同。队列、credits、slots 必须容纳孩子数；
共享局控、S 或 M 的候选拒绝。异构前缀保留原串行候选，不宣称硬件无法执行。
早期允许任意前缀的原型在真实 FFN 的 0/169 前缀组合触及精确事件上限，原件保留；
没有放大上限、用平均带宽替代或把不完整模拟当结果。

每次扩展先按当前真实 S 输入身份、有效前缀、保留策略重算孩子读写，再构造原生阶段。
原始 M 命令、S 访问、完整 K 累加、最终一次舍入、STORE/ACK 和流量都不变。
阶段总工作/读写必须重现原独占服务成本；FCFS 只增加等待并允许独立孩子重叠。
符号程序和时间结果仅按完整格式、形状、命中、原生语法、S 时序与外存参数缓存；
缓存的是编译器求值结果，不是额外片上数据或更大的 SRAM。

## 同池算法改变

`net_tail.ConditionalTail`按当前**全产品静态网并集**重算未来成本：

1. 未来实例/分片的端点与当前网冲突或超过同一预算时，不能继续用于乐观尾部。
2. 对剩余每个任务，在仍可补全全图的候选中取乐观时长，再沿 DAG 反向求最长剩余链。
3. 前沿排名比较已完成时间与“真实依赖到达时间＋条件尾部”。未来竞争、冷缓存等仍被放宽。

无模型名、层号或实例数量特例；相同网络/候选成本特征共享计算。
阶段候选的时长下界取孩子全命中时长最大值，不能再把串行孩子时长之和当下界。
同一修正提供给普通贪心、原 critical-bound DP 和 HEFT 式基线。
这是有界 beam/ready 搜索的排名改进，不保证全局最优。

`net_resource_tail`另外将当前已提交的资源释放时间纳入下一个就绪任务的乐观完成时间。
原串行孩子分别估计，不能虚构一个全资源同时开始的屏障；阶段协议则有这个真实声明屏障。
该策略仅用显式 `--policies resource-greedy resource-dp` 做消融：真实 FFN 小切片上没有超越
已知条件尾部计划，扩展次数和编译耗时明显增加，**不默认启用、不据此声称整网收益**。

阶段后端、更多候选或更精细成本带来的收益不计算法20%。
`phase_review.py`在完全相同硬件/候选池/线束预算下比较普通贪心、旧 DP、HEFT 式基线、
条件尾部贪心及条件尾部 DP。最终保留所有独立检查通过的已知好解。
不同策略按顺序共享符号求值缓存，当前墙钟观测不是冷缓存编译效率的公平排名。

## 独立证据

`verify_primitive_cost.py`重建原生工作、列区间、格式、S、端点与协议准入。
`verify_phased_compounds.py`不导入规划器/转移/阶段生成器，独立重建每个阶段与全资源预约，
再投影到原连续服务检查器以复核缓存、依赖、流量和静态连接。
投影中的通道保持孩子仅为证明，不能进入可执行整数程序。
两者共享已通过独立完整事件枚举核对的整数 FCFS 引擎；不声称两个独立计时引擎。

运行：

```
python phase_review.py COLUMN_IR NEW_OUTPUT --incumbent KNOWN_PLAN --wire-budget 18 --write-ir
python -B -m unittest discover -s project/experiments/block_synthesis -p 'test_*.py' -q
```

数值回放、实际描述符/MC/LC 编码、真实仲裁及完整 SystemC 校准均须分别验收。
减少访问次数和重叠访问分别记账；本协议没有消除原配方的重复外存读取。
