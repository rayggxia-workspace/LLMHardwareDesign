# 有限 S 驻留服务与单一图覆盖前沿

2026-11-09，Issue219/PR220迭代15。实验候选已接入通用图覆盖搜索；来源闭合FFN切片通过
独立成本/原生工作量/有限S与排程检查。完整36层搜索、实际权重的驻留回放尚待服务器终态。
本文件不授予整机RTL、DMA、物理、SystemC、能耗或token/s资格。

## 原生服务与资格

`resident_timing.py`从三种SRAM初态的真实探针重建服务槽。P Scale=4，Execute K1/K2=24，
已测Final=12；E Min双输入=20、Select三输入=25；feeder冷/复用=13/9。
未测Final位宽/移位组合明确拒绝，不外推。探针首次被动计数器有跨posedge进程的竞态，
出现±1变化，原始失败证据保留；v2在同一监测进程内维护独立计数，三初态全部稳定。
功能RTL未改。服务槽不包含母控/局控/DMA完整时序，LOAD/STORE仍沿用显式虚拟内存模型。

每次原生驻留前沿按实际S身份、脏备份、保护字、B银行重新生成动作：

`g(s') = g(s) + Σ复制代价 + Σ经测量的供数/计算/写回服务槽`。

与旧复制目标相比，命中B银行现在同时减少真实供数代价；旧copy_ticks仍单独保留。
只读身份不同、地址/ACK未满足时不能继承命中。独立事件重计不调用驻留规划器。

## 注册的是完整执行方式

`resident_bindings.py`保留原task/binding不变，新增`resident_actions`和可追踪的`resident_recipes`。
候选覆盖连续同形Convert/Product/Add；可额外枚举长度2/4/8等重叠区域，由全图搜索选择分段。
保留原M/E工作，不做隐藏CSE、主机算术或免费跨S连接。跨S仍STORE-ACK后LOAD-ACK。

整个元素域不是从首/中/末三个样本外推：外部输入必须有直接分配，且为标量或完全同形，
没有View别名、一般broadcast或范围重叠；非标量literal须另有索引合同，当前拒绝。
所以每个元素的身份、命令形状和成本均为同一模板，仅外部标量地址或元素地址变化。
内部64字临时区按元素串行复用；每个元素的所有live_out提交后，下一元素才开始。

首版循环**每元素冷启动**，没有假设保护字、常量或B银行跨元素免费保留。
每个候选预留它涉及的完整有限S并使旧只读前缀缓存失效；绑定仅允许显式资格化P/U服务实例，
不按E字母将资格推给C/F/J。资源/线束并集、有限容量和所有搬运都独立重建。

## 一个完成集合前沿

`cover_frontier.py`的done位仍对应全部原task。一次动作可以完成一个task，也可以覆盖多个task；
按完成原task的数量分桶，使一次44-task动作与44次单task动作能在同一个前沿比较。
前沿还保留输出提交时间、资源时刻、缓存、窗口和整个产品的静态线束并集。
覆盖不能绕过外部依赖，也不能包含经外部节点再返回区域的非凸路径。

所有绑定继续经过同一个动态状态转移：当前位置资源等待、缓存失效和静态网是否合法在扩展时重算。
全图可以混用原子实现与驻留实现。已有合法原方案和强贪心可在相同beam预算中保留前缀；
保留时重放实际状态，不复制旧时间戳。独立检查器先确认每个原task恰好覆盖一次，再投影到已有排程检查。

## 完成时间估计

原子task尾部不能照搬给覆盖动作，否则会重复收费。第一版均摊每个cover成本，合法但较松。
`cover_bounds.py`进一步把动作看作“外部输入全部提交 → 完整服务 → 一组输出同时提交”的超边：

`F(v) = min_{a包含v} min_{合法b} [max(max_{p∈boundary(a)} F(p), L_b(s)) + d_b^opt]`。

已完成边界的F取当前真实提交时刻。重叠cover、不同输出选用不一致实现、未来资源争用/缓存失配被放松，
因此是乐观完成估计。每条候选先按当前整颗产品的线束并集/互斥/预算过滤。
可选`L_b`仅使用普通整服务的当前append-only资源释放时刻；有阶段/offset/窗口的资源退回0，避免过估。
有限beam/ready裁剪不保证全局最优。35个小图超过1000个独立穷举可达前沿验证下界，
60个独立小图穷举验证不同覆盖长度、重叠候选和静态网约束下的搜索结果。
