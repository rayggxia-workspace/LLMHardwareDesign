# 可选的剩余资源工作量下界

`loop_dp.search(..., rank_policy='net_work_price')`是消融策略，默认搜索不变。
前沿有已完成集合D、各资源槽可再用时间a、静态网并集E和缓存状态。
对每个尚未完成任务i，保留与E及布线预算兼容的绑定集合B(i,E)。
给资源r任意非负整数价格w(r)，容量c(r)，使用全部缓存命中的乐观资源需求d(b,r)：

```text
L_w = ceil((sum_r w(r)*sum_slot a(r,slot)
             + sum_{i not in D} min_{b in B(i,E)} sum_r w(r)*d(b,r))
            / sum_r w(r)*c(r))
rank = max(已有资源/依赖尾部下界, max_w L_w, 当前完成时间)
```

理由：未来工作只能追加到当前各槽之后，到最终时间T，每资源可容纳的加权工作至多
`w(r)*(c(r)*T-sum_slot a(r,slot))`。对每任务分别取最小值放松了联合绑定与未来互斥，
全部缓存命中也放松了真实搬运，因此得到下界。它不声称最优，也不能把下界当作执行成本。

`work_price.py`确定性地产生12轮整数价格，容量用LCM归一化，以整数交叉乘比较负载；
每个价格向量独立有效，不依赖迭代收敛或浮点LP容差。按当前E重筛候选、按D更新余量，
编译器的表缓存不是硬件S。未解析的动态列宽允许零需求弱下界，不捏造确定的资源消耗。

独立小DAG穷举覆盖容量1/2、当前日历、done集合、静态冲突、复合绑定及大于2^60的整数时间。
随机诊断有胜有负；修正NExp后的真实FFN上与资源尾部DP持平，相对最强同池基线3.890449%，
价格计算更贵。因此仅保留可选策略，不将弱分母或后端升级算作算法20%。
