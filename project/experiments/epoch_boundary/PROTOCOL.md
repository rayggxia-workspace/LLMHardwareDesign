# Issue92 epoch exhaustion protocol

Owner Liangruizhi; base Issue85 PR89 eef976d. Only own server issue92-epoch-boundary-20261025, lrz-i92-*; no other jobs or sources modified. SHA-bound old85 RTL is retained as baseline-chain85.sv for an actual failure witness, never overwritten.

32bit epoch never wraps. A legal accepted command at fffffffe advances to ffffffff and may complete normally. At maximum no new command can be accepted. soft_abort clears the active pipeline; at maximum it also invalidates matching final-tag responses, which must drain without entering memory_link. Exhausted idle drains all replies, including same-tag, while preserving SRAM. Only coordinated hard reset with the external fabric re-enables commands. No CDC/arbitrary reordering/multi-context/fabric fairness claim.

Minimal combinational implementation: terminal_discard=max&&(soft_abort||idle); drop_response=mismatch||terminal_discard; discarded replies are counted. No new state or arithmetic. Same-tag replies during an active final command remain usable. Simultaneous terminal abort+reply is discarded. Reset/soft_abort has priority over configuration requests, pending configuration responses and completion acknowledgements. During either reset signal, cfg_ready/cfg_valid/usecfg/done are deasserted. Accepted pending configuration transactions are cancelled without a response; the controller initiating reset must cancel its outstanding request and retry after release. SRAM writes accepted on an earlier edge are retained; no transactional rollback is promised.

Proof: Yosys proc emits the actual register next-state cone. Extract only original combinational cells feeding epoch D, command handshake and external filter; arbitrary current register Q and peripheral outputs become explicit proof inputs. No hand-written replacement state machine. Ten universal one-step properties cover reset, saturation, increment/hold, command gating and positive legal acceptance, final active-response preservation and terminal discard, plus reset masking of configuration/completion publication. Preserve extraction binding and SAT logs. Original RTL must produce a concrete counterexample for terminal discard. This does not prove whole-core reachability or liveness.

Actual Verilator boundary test injects only the exposed epoch register while fully reset/idle, checks that it holds across an edge, then uses real command/control/response logic. It covers the final full integer command, terminal rejection and late same/different tags, maximum active abort, same-edge abort/reply, coordinated reset and a second delivered full integer command, four actual cfg/reset collisions, and one completed calculation cancelled by simultaneous abort+ack. The additional calculation is not counted as a delivered result. Fixed quiet and existing deterministic backpressure; exact encoded input reused from84 via85. Original RTL is expected to fail the terminal same-tag discard check. This backdoor test is a declared verification technique, not a production write port.

Reuse the unmodified85 sixty complete consumer/recovery commands and independent integer verifier on changed RTL. Re-map full fixed core under the identical Nangate45 logic-only recipe; independently account cell area/registers/8S8+1S32/16KiB1RW. Existing two-slot external response environment and32bit tag wiring remain outside core area and are disclosed. No inherited gate/STA/physical qualification from86/88.
