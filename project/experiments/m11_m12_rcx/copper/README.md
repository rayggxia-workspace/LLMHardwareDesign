# 固定几何的铜参数版本

任务 [#217](https://github.com/rayggxia-workspace/LLMHardwareDesign/issues/217)。[参数文件](parameters.json)是独立研究版本；原 `technology-2um-v1.json`、`candidate/research12.rules` 与 #206 布线保留。

## 参数依据与适用边界

Chang 等人的 [JES 151(1), C81–C88 (2004)](https://doi.org/10.1149/1.1632478) 在 C86、图 10 邻近段落报告：约 1.9 µm 电镀铜膜的电阻率为 2.04 µΩ·cm，400°C 退火后为 1.77 µΩ·cm；较薄的 180 nm 未退火膜为 2.32 µΩ·cm。[可读原文](https://citeseerx.ist.psu.edu/document?doi=d1ebf01817523a50acaf3d8e544cb3cc0bb477e3&repid=rep1&type=pdf)

主版本将 2.04 µΩ·cm 转移到本研究假设的 **2 µm 有效导电厚度**，`Rs = rho/t = 0.0102 Ω/□`。1.77 与 2.32 两种电阻率用于敏感性分析，后者取自更薄铜膜，故只是偏保守的研究假设。它们不是统计置信区间或代工厂工艺角。比较的参考工作温度假设为 20°C，文献没有为本工艺提供温度模型；400°C 是原文制备退火条件，不能解释为工作温度，也不意味着本底座允许该退火。

主版本与电阻率敏感性均保留 via10/via11 原有 **0.08 Ω/个** 总电阻，以隔离线材变化。这个值仍是原研究占位参数，未标定为铜通孔。额外提供理想铜孔体下限：`rho × 0.8 µm / (2 µm × 2 µm) = 0.00408 Ω`，对两种通孔同时应用，并假设接触、阻挡层和扩展电阻为零；它不能代替实际 M10 接口数据。[IBM 对阻挡层、衬层与有效导电截面的说明](https://research.ibm.com/blog/beol-cu-interconnects-iedm)解释了材料电阻率为何不足以确定真实互连电阻。本次不改变外部几何，也没有显式建立多材料衬层。

| 版本 | 电阻率 µΩ·cm | M11/M12 片电阻 Ω/□ | via10/via11 Ω/个 |
| --- | ---: | ---: | ---: |
| 原研究基线 | 等效 6.0 | 0.03000 | 0.08000 |
| `cu-main` | 2.04 | 0.01020 | 0.08000 |
| `cu-low-rho` | 1.77 | 0.00885 | 0.08000 |
| `cu-high-rho` | 2.32 | 0.01160 | 0.08000 |
| `cu-ideal-via` | 2.04 | 0.01020 | 0.00408 |

## 提取和验证

运行器 [`top_copper.py`](../top_copper.py) 读取 #215 的 SHA 绑定输入，检查原始 ODB/DEF/GDS、导体盒、场景、原 SPEF 及读回回执。只改变原模型 M11/M12 表格中的 DC 电阻列；生成的各版本规则只用于提取 R，原查表 C 的已知限制仍然存在。重新在原 ODB 的内存副本中设置电阻参数并运行 OpenRCX；不会写回源 ODB。

每个版本先运行四个独立 DEF 控制网，涵盖 M10→M11、M11→M12 通孔和两种线端延伸。再对全部 2,491 网逐边按实际节点坐标核验 `Rs × (L/2µm + 1)` 或独立通孔 R，保留 #202/#215 对 DEF 默认端延伸的口径。原生 M10 线阻控制保持原参数。

电容沿用 #215 全部导体共同求解的结果。原场求解器的输入没有金属电阻率；几何、介质和地平面相同时，无须重跑同一个静电问题。新 SPEF 只替换电阻段，逐字节核验其余内容，包括所有 Cg/Cc、网名、端点及 `*D_NET`。因此电容相同是模型和复用策略的预期结果，不是另一轮场解得出的独立观测。每个完整 SPEF 均用原 ODB 独立读回，核验全部网、端点、电阻边、网对互容及跨层投影相交网对。

实际运行目录、作业号、全部 2,491 网比较和结果见[服务器回执](../../../../work/huangpingyang04-lgtm/217/README.md)。复现命令也在该处。这里不进行系统 STA；`R×(Cg+Cc)` 只可作为线网 RC 乘积诊断，不能当作含驱动、负载与串扰时序的路径延迟。
