# 更省面积的向量8路＋S16 NExp桥接

Issue247 / PR243，Melodydt。run36的向量16＋S16桥接4路NExp为5.248140条件token/s。
本补充固定共享32KiB、17.1GB/s、M原并行度、原64B本地读与A32B：

- base：原四场景×两端口层，8例全RESULT控制。
- vector8_s16_n4：向量仅8路，S16桥接按1拍/8值计费，NExp保留4路。
- vector8_s16_n4_bridge8：相同配置，将桥接额外费用提高到8拍/8值。

共24个实际SystemC场景，检验面积较小的选择及桥接延迟敏感性，不推测新RTL已达到此成本。
沿用原输入输出/缓存/DDR费用，保持精度与完整原生模型资格边界；生产RTL不改。
复用基线、工作守恒、结果篡改负控和实际生成头文件的数值/FIFO校验。
