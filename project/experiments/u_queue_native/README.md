# U有限队列与真实形状NExp区域回放

Issue247 / PR243，Melodydt，2026-11-11 Asia/Shanghai。起点63089fb9，备份task/247-before-u-queue。
E_QUEUE_DEPTH=0保持旧路径；2/4使用有限描述符、操作数和结果槽，仍共享一个128bit S客户端和原仲裁。
按命令顺序读取/发给E/写回/完成，读可与E计算重叠；RAW等较早目标的实际写ACK，顺序读写保留WAR/WAW。
跨N/IO客户端的依赖由调用者同步；CPU/IO在E区域占用期间不得并发修改依赖地址。
done背压会占用槽位，不丢结果；reset清队列和核心，已写S不回滚。默认关闭，不扩SRAM/端口/DDR。

pu_nexp_region将已暂存且不重叠的连续区域生成NX16/NX32描述符，明确signed Q5.10输入和UQ1.15零扩S32输出合同。
NX32沿用旧协议，最后一个输入字未使用的S32容器必须为零；NX16会屏蔽未使用的packed S16。非法NX32尾部应经U错误响应停止区域，无成功计数或写回。
它不承担DDR、张量分配和真实量化转换；没有尺度声明、地址越界、零长或重叠范围直接拒绝。
原trace有prefill 36×22016值S16→S32 NExp；没有实际激活/完整尺度，原形状配构造Q5.10输入只是区域协议/数值验证。
多数图向量是S32，与8条S16 E通道不同，禁止把微基准增益无条件乘全部vector服务。

必须在授权服务器个人新run目录，用锁定source、inputs.json和SHA清单经job.sh提交Slurm；不在本机或登录节点运行EDA。
最终报告分别给出真实U微负载、原形状回放、模型条件结果、局部同库面积和未完成的整图/物理资格。
