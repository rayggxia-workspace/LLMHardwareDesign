# Issue97 bounded dedicated V → resident M → streamed normalization

The `chain97` profile executes original I32 Q12 expert gate/up through actual SiLU lookup, shared S32 multiply, whole512 scale selection and A8 publication, then runs all K512×H1536×8-expert W8 matrix work, gate-weighted merge/residual and `norm93` streamed-gamma normalization. It is a specialized Granite consumer, not a general V ISA, arbitrary GEMM, router/gate-up projection or complete model.

`vprep97` uses the one shared128bit1RW store: MID rows0–127, generated A rows768–1023. `mfront97` starts directly from resident A and rejects nonzero old host-delta header bits. Actual8×S16 delta interface comes from `vprep97`; no MID/A8/delta is supplied by the host. `chain97` latches command fields, qualifies A owner/version/epoch, arbitrates phase ownership and drains responses before V→M→norm. `norm93` streams gamma into rows384–447 after whole1536 statistics. Reserved512B V scratch/frame is unused by this dedicated implementation; it is not replaced by unaccounted storage.

Arithmetic is explicit: I32 Q12 SiLU input/output and MID; signedS32×S32→S64, RNE12 with I32 overflow rejection; exact unsigned abs(INT_MIN); minimum whole512 delta0…25; symmetric A8[-127,127]. M uses eightS8 multipliers with I32 fullK accumulation and the sharedS32 RQ/merge service. One SFU performs exact division and integer sqrt for normalization. Wide RNE shifts, compares, lookup/address/control and logical five128bit line registers are real mapped logic. Logical128bit delta output has constant upper bits that synthesis may remove; actual register count is measured from the netlist.

Address map is fixed: C0 LUT base0x02000000, reserved128KiB; data0x04000000…0x08000000. Input bases are aligned/disjoint/range checked. No program fetch exists. Every LUT line costs an external128bit request plus the modeled5-beat bridge transaction; the last SiLU word shares a physical line with the beginning of the exp2 table, but only the logical SiLU word is selected.

Reset/soft_abort mask command/config/completion handshakes, invalidate resident A and cancel pending responses. Prior accepted SRAM writes remain. Caller must cancel its pending operation, drain/categorize stale epoch responses and restart. Max32 epoch cannot wrap or accept a new command; coordinated core/fabric reset is required. Exposed metadata/epoch Q injection is used only by the RTL qualification driver, with actual-edge readback. The gate driver contains no such injection.

External two-response test FIFO and physical tag wiring are outside the core. At least320bits of FIFO data/tag plus control and32bit epoch sideband must be included in a system implementation. The core area report excludes SRAM/ROM macros, physical memory/interface buffering, clock distribution and wiring. This profile inherits neither Issue88 timing nor physical closure.
