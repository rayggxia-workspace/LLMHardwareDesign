# 多层金属互连的层级分工、Agile-X 功能等价映射与电源网络约束

> 整理日期：2026-10-14  
> 范围：SKY130（5 层）、GF 28SLP（8 层示例）、Nangate45（10 层研究模型）、Intel 4（16 层常规金属），以及东京大学 Agile-X（180 nm、1P6M）。  
> **证据区分**：金属层数、线宽／间距、公开供电配置、Agile-X 具体实现属于可查资料；单层的“典型任务”和跨制程预制／定制分界属于工程解释或**尚未验证的架构候选**，不能当作晶圆厂规定的层用途或已经验证的制造方案。

## 0. 核心结论

1. **金属层不按逻辑功能独占分配**。同一层可同时有信号线、时钟线、VDD、VSS；布线层的选择主要取决于线长、拥塞、延迟、负载、电阻及供电需求。
2. **由低到高通常从密集局部互连过渡到中距离、全局互连与粗金属供电**。但不是每个制程都有完全相同的层次分界。
3. **Agile-X 的本质不是“保留顶端两层”这个数字规则，而是：底层预制固定 IP + 晶体管／门阵列端子引出，后期用极少的金属层形成客户定制逻辑和互连。**
4. 对先进制程进行 Agile-X 映射，必须同时验证三件事：**固定 IP 能否在预制层闭合布线、定制层是否能连通门阵列、供电网络能否在不依赖未制造顶层的情况下完整工作**。
5. **功能等价 ≠ 制造流程等价**：例如 M5–M6 做定制、M7–M8 做全局供电时，M7–M8 必须在 M5–M6 之后制造；这并不等于 Agile-X 那种加工完 M5/M6 就结束的流程。

## 1. 前道、中道、后道与金属堆栈

| 范围 | 名称 | 主要内容 | 与 M 层关系 |
|---|---|---|---|
| FEOL | 前道（Front End of Line） | 有源区、隔离、晶体管栅极和源漏等 | 制造器件；金属栅极不等于互连 M1 |
| MOL | 中道（Middle of Line） | 接触孔、局部互连、器件至互连网络的接入 | 是否把局部层叫作 M0，依工艺而异 |
| BEOL | 后道（Back End of Line） | 多层金属导线、层间通孔、介质 | M1、M2……一般从下往上编号 |

- **金属堆栈（Metal Stack）**：工艺允许的金属层组合，以及各层线宽、间距、厚度、材料、通孔规则。
- **电源分配网络（Power Distribution Network，PDN）**：在金属堆栈中实际布置的 VDD/VSS 导线和通孔，是具体设计的网络，而不是几层额外的“供电专用金属”。
- **通孔（Via）**：把相邻金属层电连接，通常不会作为独立的横向布线层计数。
- **M0 并不普遍**：SKY130 的局部互连叫 LI1，Intel 4 则有 M0；不能跨工艺直接用层号推断位置和功能。

### 1.1 从电路对象到互连层级

| 互连层级 | 连接对象示例 | 距离概念（仅作数量级直觉） | 布线倾向 |
|---|---|---|---|
| 器件级（Device） | 晶体管端子、栅极与源漏接触 | 亚微米至数微米 | MOL、最低几层细金属 |
| 标准单元级（Cell） | NAND、MUX、触发器及相邻单元 | 约 1–10 μm | 低层细金属 |
| 运算单元／单元簇（Local Cluster） | 加法器、PE 内部各逻辑单元 | 约 10–100 μm | 低层至中间层 |
| 功能块内部（Block） | PE 阵列、ALU 子系统、缓存控制器 | 约 0.1–1 mm | 中层；必要时借用高层 |
| 跨功能块／全局（Semi-global / Global） | 大型阵列之间、全局时钟、供电 | 约 1–10 mm | 中高层、粗金属 |

“模块（Module）”要区分 **RTL 中的逻辑模块** 与 **物理布局中的功能块**。RTL 模块可能被打平、合并或交错放置，所以**不能根据 Verilog 层级直接决定用第几层金属**。上表距离区间会因设计面积和工艺而大量重叠。

## 2. 不同制程的逐层分工

### 2.1 130 nm：SkyWater SKY130（LI1 + M1–M5）

| 层 | 典型互连层级 | 典型任务 |
|---|---|---|
| LI1 | 器件级 | 端子附近的局部连接 |
| M1 | 标准单元级 | 引脚接入、单元电源轨、近邻信号 |
| M2 | 单元之间 | 相邻逻辑门、触发器连接 |
| M3 | 局部逻辑块 | 更远的标准单元连接、局部信号汇集 |
| M4 | 功能块／区域级 | 较长信号、区域电源条带 |
| M5 | 全局级 | 电源主干、跨区信号、较长互连 |

**已公开的实际供电配置**：OpenROAD 的 `sky130hd/pdn.tcl` 使用 **M1 → M4 → M5**：M1 标准单元供电轨，M4/M5 构成区域及上层电源网格。这是**一种具体流程配置**，不是说 SKY130 只能在这三层供电。M5 的公开最小线宽和线距均为 **1.6 μm**，对高密度门级定制并不友好。

### 2.2 28 nm：GlobalFoundries 28SLP（选定 8 层堆栈）

公开推荐堆栈之一：`8LM (6U1x_2T8x_LB)`，即 **6 层常规 1x 金属 + 2 层 8x 等级厚金属**。“8x”是工艺金属尺寸等级，不应解读为任何具体几何参数都刚好是 8 倍。

| 层 | 金属类别 | 典型互连层级／任务 |
|---|---|---|
| M1 | 1x | 单元引脚、局部互连、电源轨 |
| M2 | 1x | 相邻标准单元之间 |
| M3 | 1x | 单元组内信号 |
| M4 | 1x | 功能块内部互连 |
| M5 | 1x | 较远单元组、中距离互连 |
| M6 | 1x | 中距离至跨模块信号、部分电源／时钟分配 |
| M7 | 8x | 较长距离信号、粗电源条带 |
| M8 | 8x | 全局供电、全局信号或大电流互连 |

**关键特点**：M1–M6 与 M7–M8 在物理尺寸等级上明显分化。较粗的最后两层更适合低电阻长线，未必适合密集门阵列连接。28SLP 还支持其他金属层数组合，不能把上述配置推广到所有 GF 28 nm 工艺。

### 2.3 45 nm：Nangate45（10 层，研究用工艺模型）

| 层 | 技术文件中的最小线宽 | 典型层级／任务 |
|---|---:|---|
| M1 | 70 nm | 标准单元引脚、局部电源轨 |
| M2 | 70 nm | 局部标准单元信号 |
| M3 | 70 nm | 单元组密集布线 |
| M4 | 140 nm | 中距离信号、区域供电 |
| M5 | 140 nm | 功能块内部信号与数据总线 |
| M6 | 140 nm | 功能块内部至跨块信号 |
| M7 | 400 nm | 全局供电条带、较长互连 |
| M8 | 400 nm | 时钟、长距离信号 |
| M9 | 800 nm | 全局粗线、供电或信号主干 |
| M10 | 800 nm | 顶层全局互连 |

**已公开的具体 OpenROAD 配置**：

- 标准单元供电：M1，电源条带线宽 **0.17 μm**；
- 区域电源：M4，电源条带线宽 **0.48 μm**；
- 上层电源：M7，电源条带线宽 **1.40 μm**；
- 连接关系：`M1 ↔ M4 ↔ M7`（经所需中间金属和通孔实现电气连接）；
- 普通信号最低布线层可为 M2，时钟最低布线层可为 M4，最大布线层为 M10。

注意：表中的 **70/140/400/800 nm 是最小导线线宽**；0.17/0.48/1.40 μm 则是 **该供电脚本实际选用的条带线宽**，不是同一个量。

### 2.4 Intel 4：16 层常规金属 M0–M15，另有 GM0/GM1

Intel 4 的公开数据适合用“金属间距（Pitch）”理解层级。**下表第三列是工程推断，不是 Intel 强制的层用途**。

| 层 | 间距（Pitch） | 典型层级／任务 |
|---|---:|---|
| M0 | 30 nm | 极局部互连、晶体管接入 |
| M1 | 50 nm | 标准单元局部连接 |
| M2 | 45 nm | 高密度局部信号 |
| M3 | 50 nm | 单元之间的连接 |
| M4 | 45 nm | 局部逻辑单元簇 |
| M5–M6 | 60 nm | 模块内部中距离互连 |
| M7–M8 | 84 nm | 较大的逻辑块、区域连接 |
| M9–M10 | 98 nm | 跨模块互连、供电分配 |
| M11–M12 | 130 nm | 全局信号、时钟网络 |
| M13–M14 | 160 nm | 较长全局连接及上层供电 |
| M15 | 280 nm | 顶层全局互连 |
| GM0 | 1080 nm | 大型金属、低阻供电资源 |
| GM1 | 4000 nm | 顶部大型金属、低阻供电资源 |

因此先进制程并不是“所有金属线都一样细”；其下层解决布线密度，上层为更长、更大电流或时序敏感的网络提供物理资源。

### 2.5 跨制程总体比较

| 比较项 | 5 层（SKY130） | 8 层（GF 28SLP 示例） | 10 层（Nangate45） | 16 层（Intel 4） |
|---|---|---|---|---|
| 局部布线 | 底部 1–2 层为主 | 底部若干 1x 层 | M1–M3 | M0–M4 密集互连 |
| 中距离布线 | M2–M4 分担 | M3–M6 | M4–M6 | M5–M10 逐级展开 |
| 全局布线 | M4–M5 | M7–M8 较粗 | M7–M10 较粗 | M11–M15 与 GM 层 |
| 供电网络 | 可用 M1/M4/M5 | 从细层轨道至上层粗金属 | 公开案例 M1/M4/M7 | 多层供电，GM 层提供粗金属资源 |
| 主要约束 | 信号与供电竞争中高层 | 细金属与厚金属的层数取舍 | 多级 RC 与布线拥塞 | 更复杂的层间规则、全局网与供电 |

**这些“分工”不是一层一功能的硬性规则**。例如一条跨模块但很短的信号可能走低层；一条模块内部但长且时序敏感的信号可能提升到高层。

## 3. Agile-X 的真实预制／定制分工（作为映射基准）

Agile-X（东京大学 Agile-Chip）的公开研究采用 **180 nm、1P6M**。基片预先制造至 **M4**，外围集成 RISC-V、SRAM、ADC、I/O 等固定 IP，中央是预先排布的晶体管／门阵列。

| 阶段 | 层 | 完成什么 | 是否已实现／公开证实 |
|---|---|---|---|
| 预制 | FEOL–M4 | 制造晶体管、门阵列端子引出、固定 IP 及其底层互连；M4 也可预埋旁路线 | Agile-1L 已有实物原型 |
| 定制一层 | M5 + 与 M4 的连接通孔 | **将预制端子连接成具体逻辑门**，并把门阵列和固定 IP 连接起来 | Agile-1L 已有原型 |
| 定制两层 | M5–M6 | 第二个布线平面允许更灵活的线路交叉，提高门阵列可布线性 | Agile-2L 属后续平台与论文评估方案，不能当作与 1L 同程度的流片验证 |

- **不能将 M5/M6 只理解为“模块间的顶层信号线”**：Agile-X 的论文图 4 给出了利用 M5 与 Via45 把预制晶体管端子连接成反相器的例子。
- 只有一层定制布线时，线路交叉受到限制；原论文提到在 **M4 预制旁路线（bypass lines）** 来解决部分绕线问题。
- Agile-1L 实际使用到 M5；Agile-2L 使用到 M6。换言之，**它的客户定制层就是所需互连流程的最后一层／最后两层**。
- 原论文列出的定制线宽与间隔：Agile-1L 为 **5 μm line-and-space**，Agile-2L 目标为 **1 μm line-and-space**。这还表明设备的后期图形化能力可以远粗于 CMOS 底层原生金属。
- 论文图 4 显示了预制门阵列的 VDD/VSS 位置，但**不能据此认定全芯片供电主干分别占用了 M1–M4 中哪些层，或其压降余量**；那需要完整 PDN 布局和提取结果。

功能基准应写成：

> **预制部分** = 固定 IP + 通用可配置器件结构 + 端子引出 + 必要的预制信号／电源资源。  
> **后期定制部分** = 确定门级功能 + 门间布线 + 与固定 IP 的接口连接，尽量在最后 1–2 层金属完成。

## 4. 将 Agile-X 映射到其他节点：功能等价，而非按金属层数机械划分

下面是**初始架构候选**，用途是提出待验证的分界层，**不是**已发表的其他制程 Agile-X 方案，也不能保证固定 IP 在建议的预制层内就能完成。

| 工艺／堆栈 | 候选预制层：固定 IP + 门阵列端子引出 | 候选定制层：门级功能 + 连线 | 余下更高层及其任务 | 与 Agile-X 真正的“最后几层才制造”的差异／主要风险 |
|---|---|---|---|---|
| **180 nm Agile-X，6 层** | **M1–M4** | **M5**（1L）或 **M5–M6**（2L） | 无 | 这是已公开的基准架构；PDN 具体层仍须按实物设计核查 |
| **130 nm SKY130，5 层** | LI1、M1–M2（待验证 IP 布线是否足够） | M3–M4 | M5：粗线、全局供电 | M5 位于定制层之上，后续仍需制造；若强行把 M4–M5 作为最后两层，M5 的大线距不适合密集门级布线 |
| **45 nm Nangate45，10 层** | M1–M3（待验证） | M4–M6 | M7–M10：全局信号、时钟、供电 | M7–M10 不是已预制层，若保留必须后续加工；Nangate45 本身属于研究用工艺模型 |
| **28 nm GF 28SLP，8 层** | M1–M4（待验证） | M5–M6（末两层常规 1x 金属） | M7–M8：8x 粗金属、主干供电／全局信号 | **功能上较合理，但不是末两层定制**；M7/M8 需后续制造；若仅定制 M7/M8，粗线限制门级密度 |
| **Intel 4，16 层 + GM** | M0–M4（待验证） | M5–M8（中层密集互连候选） | M9–M15、GM0/GM1：更长距离互连及粗电源网络 | 若完整保留上层会新增大量后续制造步骤；如果只保留 M14/M15 定制，门级可布线性可能严重不足 |

### 4.1 两种“等价”要分别研究

**A. 电路功能等价（Functional Equivalent）**

目标是让客户只改动少数金属层，仍然能够定义 NAND、MUX、触发器等逻辑门及门间连接。中等密度金属可能比最顶部粗金属更合适，但上层网络未必能够预先完成。上表主要属于这一类。

**B. 预制／后加工流程等价（Manufacturing-Flow Equivalent）**

目标是晶圆从厂内出来时已经制造至 M\(_k\)，然后客户只需要加工 **M\(_{k+1}\) 至实际最后一层**，不再追加大量上层金属。实现这个目标，需要**按目标产品重新选择总堆栈和供电架构**，并确保最后的金属层能够承载需要的门级／模块级信号。

所以，一个分界层在功能上合适，并不代表它满足 Agile-X 式快速后加工的商业价值。尤其是 **28 nm `M1–M4 预制 / M5–M6 定制 / M7–M8 供电`**：若 M7–M8 必须补做，这就是分阶段完整 BEOL 工艺，而非只做最后两层的 Agile-X 式流程。

### 4.2 更高层是否可以省略？

**有条件地可以**，但必须满足：

- 当前工艺选项允许以较少金属层结束，并有对应的顶层工艺规则／钝化／焊盘接口；
- 不使用这些层仍能完成全局信号、时钟、VDD/VSS 的连接和性能指标；
- 改为底层或中层供电后，压降、电迁移、热点及封装引出仍满足要求。

**需要“定制工艺支持”不是因为少制造金属本身必然困难，而是因为设想中的「6 层全部为高密度细金属、且 M6 作为最终顶层」未必是晶圆厂现成提供的标准堆栈。** 如果采用晶圆厂已有的 6 层选项，就不必为“6 层”这一数字重新开发工艺；但其最上层可能是粗金属，造成密集定制受限。

## 5. 必须独立检查的电源网络问题（PDN）

### 5.1 M1、M4、M7 不是三套独立电源

同一颗芯片可以有一组或多组供电电压域。以单个 VDD/VSS 电压域为例：

```text
外部电源焊盘 / 芯片电源环
          │
          ├── VDD 主干（例如 M7）───────────┐
          │       经所需过渡金属及 Via       │
          ├── VDD 区域条带（例如 M4）        │
          │       经所需过渡金属及 Via       │
          └── VDD 标准单元轨（例如 M1）→ PMOS 供电端

接地 VSS 有对应的独立导线网络，经各层到 NMOS 接地端。
```

- **M1、M4、M7 是高度不同的布线层**；每层上可以有 VDD、VSS、信号线。不同层中属于 VDD 的部分相互连接，VSS 也一样，但 VDD 和 VSS 不能短接。
- **全局供电不一定使用最顶层**：Nangate45 的 OpenROAD 示例采用 **M1/M4/M7**，虽然工艺模型具有 M10；SKY130HD 的公开流程采用 **M1/M4/M5**。
- 不存在“电源无条件从顶层垂直打到每个晶体管”。真实 PDN 是在金属层中形成的三维网格，有多个并联横向路径与垂直分支。

### 5.2 为什么不能随便删掉上层供电金属？两个严格情形

**情形 A：电气上断开。** 设计原先依赖 M7 将芯片电源环与远端区域的 M4 电源条带连接；预制晶圆只做到 M6，后面也不制造 M7，且没有其他入口。则该远端区域在电源网表上失去 VDD 连通，即使其内部 M1、M4 电源轨都画好了，晶体管也不能正常获得供电。**这不取决于 M7 是不是“逻辑上全局层”，而是取决于网络连接图。**

**情形 B：仍连通，但电阻太大。** 假设某区域通过重新设计的细金属获得 VDD，但其供电等效电阻由 0.5 Ω 上升到 5 Ω，峰值电流为 10 mA；压降从 5 mV 变为 50 mV：

\[
\Delta V=IR,
\quad 10\,\mathrm{mA}\times0.5\,\Omega=5\,\mathrm{mV},
\quad 10\,\mathrm{mA}\times5\,\Omega=50\,\mathrm{mV}.
\]

此处参数只是说明因果关系的**明确假设案例**，不是对任何晶圆厂工艺的实测。重新接通了电源，不代表电路的时序和可靠性不受影响。

### 5.3 对 Agile-X 迁移最关键的五项 PDN 检查

| 关键检查项 | 必须回答的问题 | 如果失败会怎样 |
|---|---|---|
| **供电连通性** | 所有固定 IP、可配置单元能否从外部 VDD/VSS 引脚获得电源？ | 局部单元／整个模块浮空或不工作 |
| **供电路径预制程度** | 预制层是否已经具有可独立工作的 PDN？还是依赖后期定制／上层粗金属？ | “只做最后两层”难以成立 |
| **IR Drop / 瞬态压降** | 峰值电流、线阻、通孔阻抗、供电裕量是否满足设计规格？ | 时序劣化、逻辑失效 |
| **电迁移与热** | 细金属替代粗金属后，线宽、电流密度和温度是否合规？ | 长期可靠性下降 |
| **资源竞争与后期工艺** | 定制信号是否挤占 VDD/VSS 的布线通道？电源焊盘／钝化／封装能否在最后层正确形成？ | 拥塞、无法签核或无法封装 |

### 5.4 如何真正验证某个 Agile-X 映射方案？

建议对目标工艺建立预制层限制版图，并至少进行以下三组验证：

1. **固定底层验证**：将 RISC-V／SRAM／I/O 及门阵列端子限制在候选预制层，验证固定 IP 完整布局布线与 DRC/LVS。
2. **后期定制验证**：选多个有代表性的逻辑网表，限制客户布线只能使用候选定制层，统计可布通率、通孔数、拥塞、面积、时序。
3. **电源独立验证**：分别测试“只有预制层供电”和“允许后期顶层补供电”的连通性、静态／动态压降、电迁移、封装引出及所需额外工艺步骤。

只有这三部分都通过，才能说这个工艺节点具备**功能与制造流程上可比于 Agile-X**的架构，而不只是金属层号看起来相似。
