## 2. 用户对项目的六点澄清（保留原意与原表述）

> 1. 不一定是M4 V4 M5的分层，应该由需要采用的工艺决定，比如这份md文档，这个回应了你的问题2
>
> 2. BLOCK涉及两大问题，我觉得你都说明了，第一是粒度，这个是需要找一个抽象层级的平衡点，第二是排布
>
> 3. 我觉得定制模型权重的问题是不能实现我们这种预制底座的想法了，我们的核心是相比传统asic便宜（只需要改少量掩模），比FPGA快（无开关互联）。如果预制权重的话还有这个效果吗？这个是值得讨论的
>
> 4. 你说的跨block高速接口是个非常好的问题，我觉得我们可以讨论下，你的意思是如果跨block高速接口全部需要由上层定制，将非常耗费面积，这个能不能有底层预埋轨道的处理方法
>
> 5. 我这个纸上还有一条，文字是电源轨-block内：用不用/开启多少（如70%）（举例：数值精度 浮点数变化 应用层次需求）你觉得是什么？

## 4. 使用这些澄清的边界

- “相比 ASIC 便宜、比 FPGA 快”是项目目标，尚不是实验结果。
- 用户将权重定制的作用列为待讨论问题；不能把“全面采用 ROM”或“永不采用 ROM”写成最终决定。
- 预埋轨道、Block 内按需启用和 CTS 功耗是重点研究问题，具体电路方案尚未确定。
- Block 级表征加上层建模是用户明确认可的评估尺度；完整芯片签核与实际流片不是本阶段默认前置条件。
- 后续提出的小型阵列粒度、分段轨道、分组门控、参数模型和实验基线，属于项目说明中的候选方案，不能倒写成用户笔记已经确定的设计。
