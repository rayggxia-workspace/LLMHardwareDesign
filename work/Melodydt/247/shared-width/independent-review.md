# run33 共享32KiB扩宽独立复核

Issue #247 / PR #243；本报告仅复核服务器实际条件 SystemC 评价，不执行本地 EDA。

最高 **4.42958258026 token/s**，来自 idealdual、双64B服务组、64B行交错，单P消费64B或128B均为同一结果。没有场景达到5 token/s；还需提高 12.8775% 才到5。此前5.0507的Amdahl外推已被本次实际模型替代，不能作为达到或可靠预测的速度。

## 性能平台的实际原因

最佳双组行交错映射的两组读取均为20,125,696次；连续16KiB映射为37,892,096与2,359,296次，明显偏向组0。行交错确实改善了分组平衡，但整机收益很小。不能仅凭单组扩宽的平台就断言全局64B供数仍是最佳方案的最大瓶颈。

在最佳idealdual方案，两P service合计恰为 **107,261,600 core cycles**，与所有方案保持不变的 `M_work_ticks` 完全相等；`adapter_work_ticks` 仍为96,455,680。这说明服务阶段已没有高于原compute/adapter及tail下限的额外时间。共享feed进一步缩短被 `max(local_read, compute, adapt, feed)` 覆盖。compute与adapter可在具体tile上并列，不能据汇总值将全部时间归为某一硬件单元。

| idealdual指标（两P工作量合计） | 原32B单组 | 64B双组行交错 | 128B双组行交错 |
| --- | ---: | ---: | ---: |
| shared feed cycles | 100,203,273.848 | 60,579,136.000 | 59,321,280.000 |
| P service cycles | 111,036,841.848 | 107,261,600.000 | 107,261,600.000 |
| input ACK wait cycles | 28,583,305.976 | 30,470,751.824 | 30,470,751.824 |
| 整机elapsed cycles | 136,397,347.732 | 135,452,943.732 | 135,452,943.732 |

32→64B双组行交错后，idealdual shared feed合计减少约39.54%，P service减少3,775,241.848 cycles；较快消费使输入ACK等候增加1,887,445.848 cycles，最终整机仅减少944,404 cycles，即吞吐增加约0.6972%。128B再令feed减少2.0764%，整机耗时和token/s均无变化。

这里的两P合计是工作量，不是墙钟分解。只有同一P的ready wait、ACK wait、service和output四段之和等于该P elapsed；两P彼此并行，port wait、FIFO credit wait与read latency又与其他工作重叠，不能相加推算节省。ACK等待包括输入服务/排队及重叠暴露，不能等同于纯外存带宽瓶颈。

shared本地单端口层仍有更高的local S服务串行开销：最佳两P service合计151,706,717.656 cycles，比原M工作量多44,445,117.656 cycles；这是并行工作量差，不能直接换算为墙钟可节省时间。两层都保留约64,294,419 cycles非Dot跨度，完全未因本轮扩宽改变。

## 取舍与边界

单组64B相对原32B仅小幅增益；把单组64B变为双组64B行交错，在idealdual仅额外约0.001121%吞吐。128B双组行交错与64B完全相同，因此本场景没有证据支持为128B消费和更复杂多项FIFO访问继续增加面积。继续优化应先研究固定M/适配/tail工作、local S供B与输入ACK路径及未改变的非Dot算子，而不是继续单独扩大共享A入口。

共享容量始终32KiB，共8颗4KiB宏；组重分配不增加容量宏。仲裁、交叉连接、FIFO多项访问、M入口扩宽会增加逻辑，本轮没有综合面积、STA或P&R证据，不能给出可信新增mm²或频率保证。

范围为原S32/K256/S96、prefill2/W8、300MHz等条件模型。未在本轮重跑decode，也没有实装生产RTL扩宽、原生完整模型权重/token生成或物理时序资格。advanced数值测试将旧3个48/96KiB容量夹具改为固定32KiB，保留A/B和725个算术输出；16/32g1控制夹具不变。完整逐配置与逐P账目见同目录independent-review.json。
