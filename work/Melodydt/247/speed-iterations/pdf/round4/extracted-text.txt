1. 瓶颈研究与方案选择
第二轮主W8 decode512理想端口耗时272.510572667ms，3.66958239533 token/s；共享口3.37834376557。Dot占
主理想时间82.2359%。第三轮实现真实四bank、有限包槽和S96控制后，双缓冲理想主项3.66041657326，共享
2.75864978939；局部流水改善受输入服务和仲裁抵消，所以本轮没有默认启用更慢的候选。
曾比较1KiB A寄存器缓存。它能减少FFN-down八context间重复A读取，但不能减少权重DDR流量。第三轮该
shape51.31636584ms，固定853770240B和17.1GB/s给出49.92808421ms的字节服务诊断；只改此shape且保留其他
span时，最乐观主项约3.67911，相对第二轮约0.26%，还未计查询、复制、真实写失效及防过期回填成本。这是范围明
确的筛选估计，不是新实现或通用上界。
本轮选择范围更小的NExp四通道。第二轮已经把批处理四命令缩为单op12，但每次CALC仍只算两个元素。主模型的
NX32包最多四个S32容器，四个元素需要两次CALC/ACCUM；增加两条指数通道可使该包一次处理完。四通道不改变包
宽，也不把八个S32挤进128bit，更不删掉外层S和DDR费用。
评价保持旧PR241/Issue247的300MHz、17.1GB/s、2P/1U、每block 16KiB、ctx8和原trace。主停止项为W8
decode512，共享与理想端口分列；prefill/W16/长上下文仅辅助对照。第四轮完成即满足轮数停止条件，不以更改clock、
精度或带宽凑足5。
2. RTL实现方法
只修改生产block_v2_n.sv和pu_u_group.sv，增加NEXP_DIRECT_LANES参数，默认2，仅允许2或4；非法静态配置在启
动时报错。U只有NEXP_BATCH和NEXP_DIRECT同时开启才向N传递所选宽度，否则仍传2。已有pu_nexp_shared和
nexp_batch_adapter逐字节保持第二轮源码，一个U仍只有一个N。
原U op15/NX32 -> 同一S读客户端 -> 同一N所有权
-> op12 CALC：原两EXP + 可选额外两EXP
-> ACCUM：写回原128bit结果 -> 同一响应
-> 同一S写客户端 -> 实际ACK -> DONE
新增generate分支仅在有效四通道配置实例化。两个额外指数结果寄存器及valid位在op12的CALC阶段更新，读取
position+2与position+3；输入在非op12时关闭。原raw/gamma/square、统计、归一化及EMIT两通道循环完全保持。
ACCUM对op12四通道使用步长4，其余仍步长2。额外有效结果写入原result对应lane；最后一次响应同时直接覆盖当前
额外lane，避免非阻塞赋值使rsp_data看到前一拍result。position、128bit结果和响应寄存器复用，不再增加一组外部
包缓存。

参数两通道必须与第二轮完整事件和周期一致；四通道但DIRECT关闭也必须保留原四命令批处理时序。四通道启用时普通
op0到11的数值、错误、状态和相对完成周期保持；只让无状态op12缩短。这些都是实际测试门，不能只因代码分支看似
隔离就认为成立。
3. 数值、状态与面积
四条EXP通道调用同一整数函数和同一查表常量：非负输入编码32768，低于表范围返回0，中间使用原端点选择、插值及
舍入规则。没有新截断或近似。NX32仍使用每个S32容器的有符号低16位、结果U16零扩展到S32；已用容器高16位按既
有合同忽略，未用容器全零。此合同不等于任意S32指数。
原生op12 count为1到8，param/aux必须为0，未用S16 lane必须为0。外层PACKED16最多八S16、NX32最多四S32；
旧模型S16输入/S32输出的prefill依然不合格，完整回退。额外通道不修改maximum/count、factor、exp统计、replay
和top持久状态，响应背压、唯一N所有权、S写ACK和全组复位路径保留。
新增显式顺序状态为2×16bit指数结果加2bit有效位，共34bit（4.25B）。组合资源增加两条EXP路径，包括四次同时端点
查询、插值算术、舍入和选择布线。单一常量源文件不意味着免费多端口ROM；34bit不能代表总面积。没有复制完整N、
除法/开根、统计阵列或SRAM。实际数据S仍16KiB。
综合面积、STA、P&R及功耗未执行，300MHz仍只是固定比较条件。第二轮完整备份
task/247-pre-m-area-r2-ed9f5ee6和每次不可变源快照保留，第三轮大面积候选另有独立分支。本轮扩通道候选的额外
备份信息在追溯节记录，以便恢复任一资源方案。
