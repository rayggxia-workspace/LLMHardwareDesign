## 原生 RTL 权重对照

104059 的真实前层输出、原始 PR #260 词表部署、完整 1,187 tile、151,936 logits、10 ns 测试核心周期。114150/114151 正常完成 RTL 背压测试，均为 **14,109,900 周期**，5,472,454 DDR 读，token 81917 / logit 1630078，embedding 与 logits 的独立参考核验通过。两作业退出 1:0，原因是旧归档的 `audit_algo1_vocabulary.py` 缺少新审计参数。恢复时校验并补齐原始归档的匹配副本，使用 Python 3.11 针对同一输出重跑审计，验证 `proof.sha256` 和 `head-timing.sha256`。114145/114146 在第一次部署时缺三份归档 KV 模块，止于编译，已从同一原始归档补齐。114152 的快速样本因地址映射错误失败，经修正后 114155 完成 0:0。
