统一口径与算法

Batch=1，三路P FFN，逻辑SRAM/PM写宽512 bit，核周期3334 ps，双通道DRAMsim3 tCK=630 ps，每通道32 credits，权重窗口4、ATT KV窗口8，PR272 combined。保留模型专项优化与冻结数值配置。

短P2从空状态运行两个输入位置，到第二位置末层完成，吞吐=2/时间。Decode从各自真实512位置历史运行两步，以第二次减第一次退休时间的倒数报告；不是长序列稳态统计。

P1 = 第1个Prefill位置末层完成时刻（含启动一次）
L = 第2个Prefill位置增量时间（可见KV=2）
H = 第2步Decode末层完成 - 第1次退休（可见KV=514，不含本步词表头）
b = (H-L)/512
T_body(512) = P1 + Σ[c=2..512] (L + b·(c-2))
T_logits(512) = T_body(512) + (第2次退休 - 第2步末层完成)

末层口径与原短Prefill对齐；含尾部口径最后仅加一次最终归一化和完整词表头。选词仍沿用主机逻辑，没有独立硬件采样器或网络/服务队列计时，因此不称已验证的用户请求TTFT。输入DDR与反馈token入口、边界残差读、地址布局/DDR状态差异保留为模型不确定性；无多token并行、批处理或新增权重复用收益。Qwen3采样计划与速度回执计划SHA不同，已核对对应完整result.json除plan_sha256外逐字段一致；分别保留两套散列，不宣称计划文件字节相同。

中间上下文采样与显著性判据

每个模型选择前/中/后代表层，Gemma另取全局注意力层。每层测c=1,2,4,7,8,9,16,32,64,65,128,129,256,257,512。采用冻结实际描述符、KV地址及真实历史数据；修改上下文长度并重新计算描述符CRC。独立运行原ATT服务、原DRAMsim3和512-bit S128端口，记录回包/排空、输出哈希和输入来源。固定Q仅用于计时敏感性，不宣称对应前缀数值输出正确。

局部筛查比较c=2与512两端连线，在16≤c<512的采样点计算|实际-直线|/实际。5%只是预先声明的局部非线性筛查阈值，不是整模型精度保证；超过阈值仍按用户要求保留端点线性估算并加红色注释。短长度还存在分片/拍数取整。局部采样未包括投影和母控竞争，模型主表继续锚定全层回执，不将组件耗时直接累加为全层耗时。

混合模型补首/末递推层各零态与真实512末态探针，激活输入为固定合成值，使用真实参数及状态读写；不将末态截短冒充中间前缀。Granite只分析已有路由，未新增长提示词路由分布实验。
