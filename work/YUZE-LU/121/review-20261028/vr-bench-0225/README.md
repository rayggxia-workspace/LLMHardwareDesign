四份公共测量覆盖66个相同语义场景的旧/新比较；扩展45个新版场景。两种初始化逐报告一致，总计354次场景执行。逐周期互斥归因、有效/容器字节、生产气泡和背压已记录；每个响应独立核对数值与事务次序。只读公共端口，不访问RTL内部信号。

TopK输出8份S32分值和16bit ID，共48B，未实现专家数据寻址/搬运。卷积覆盖1/17/256个连续token，保留96B历史与64B系数，逐token显式提交；最后历史导出也计价。R逐元素系数仍逐字加载，没有假设共享或免费广播。

## 资格与证据边界

这是实际RTL端口测量，V/R新版最终300MHz物理接收仍未完成。300MHz换算率仅为周期算术；旧基线实际资格100MHz，周期比不能当作物理频率或整模型速度提升。内部lane占用/使能没有直接采样，不用计算相位吞吐冒充内部实测利用率。实际算子图资源预算、有限预连P3、其余最终接口/图和五宏最终接收仍需完成。
