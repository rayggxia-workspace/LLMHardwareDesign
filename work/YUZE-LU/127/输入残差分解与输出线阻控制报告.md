# 输入残差分解与输出线阻控制

对应 #127 / PR128，2026-10-27 CST。延续原生 driver 分量去嵌入的同源 run168 T6K 实测。**本轮解释误差，不校正原始观测，不改变既有失败或签发模型资格。**

## 输入端：将剩余误差与父层驱动响应分开

新增 `input_driver_residual.py`。先复验原 probe 输入/输出 SHA、原候选依赖、两份导出上下文、实际 pair 原始 TSV/SPEF 与模型加载绑定，再核对 canonical 单时钟 SDC 中每个输入的 min/max delay。只支持理想父层线、这一有限 canonical SDC 和固定源原生驱动 probe；复杂父层或约束语法直接拒绝。

完整 RC 图导出日志给出源原生 driver load-dependent 分量 Df；抽象输入到宏 pin 的实际 arrival 减原始 input delay 得到父层分量 Da。setup slack 差预测为 Df−Da，hold 差为 Da−Df。它只作归因核对，不能把预测差从验收报告中减掉后宣布通过。

| 同源候选 | 实际输入观测 | 预测后最大未解释残差 |
| --- | ---: | ---: |
| T6K A | 756 | 0.006171 ps |
| T6K C | 756 | 0.006513 ps |

A 最坏输入 `write_data[29]` fall/max：Df=20.0885 ps、Da=29.968416 ps，预测 slack 差 −9.879916 ps，实际 −9.885426 ps，剩余 −0.005510 ps；同一输入 fall/min 预测 +9.830639 ps，实际 +9.833717 ps。C 最坏输入 `begin_generation[16]` fall/max 预测 −1.011614 ps，实际 −1.008971 ps。

这些有限上下文的数据支持：当前输入聚合 slack 的主要残差是完整分布 RC 与静态 lumped 输入电容下的外部驱动响应差异。内部约束仍保留原 wire RC，不应通过删掉 wire delay 消除差异。它不是对任意新驱动、corner、父层 RC 或全部弧的误差包络证明。日志原生分量只有六位有效数字，模型 Liberty 的标量亦有输出精度，不能把约 0.0066 ps 宣称为通用精度承诺。

固定源 `MakeTimingModel::makePorts` 使用 `loadCap` 生成静态输入电容；它没有保留输入 RC 网络的完整阻抗。源参考：[MakeTimingModel.cc](https://github.com/The-OpenROAD-Project/OpenSTA/blob/bc7af6f02679074eaf43657488ca117c05f98eed/search/MakeTimingModel.cc)、[GraphDelayCalc.cc](https://github.com/The-OpenROAD-Project/OpenSTA/blob/bc7af6f02679074eaf43657488ca117c05f98eed/dcalc/GraphDelayCalc.cc)。不把上述有限核对提升为唯一物理机制的普遍证明。

## slew 必须区分输入和输出

| 同源候选 | 输入 slew >1 ps 坐标数 | 输入最大差 | 输出 slew >1 ps 坐标数 | 输出最大差 |
| --- | ---: | ---: | ---: | ---: |
| A | 17 | 5.719 ps | 146 | 4.753 ps |
| C | 0 | 0.894 ps | 106 | 3.680 ps |

这里一个坐标是 pin × min/max × rise/fall，并非一个 pin。C 的 106 个 slew 超差全部位于输出；不能用输入 driver 分量去嵌入解释或豁免它们。原始总超差仍为 A192/C110。

## 输出 wire 控制

`native_control.py` 增加显式 `--output-resistance-ohm`，默认维持 1 Ω。只改变 q→DFF Q 的 SPEF 电阻；源网表、时钟、输入场景、输出负载和原生工具保持绑定。两档电阻各实际执行四个 DFF 模型对照和两个 exact-flat reread；详细结果和 SHA 见 `input-output-residual-summary.json`。

| 输出线电阻 | 输出 slack 最大绝对差 | 输出 slew 最大绝对差 | 完整输出 rise/fall slew | 抽象输出 rise/fall slew |
| --- | ---: | ---: | --- | --- |
| 1 Ω | 0.007105 ps | 0.003 ps | 12.765 / 8.623 ps | 12.766 / 8.626 ps |
| 20 kΩ | 25.454638 ps | 44.883 ps | 54.651 / 53.509 ps | 12.766 / 8.626 ps |

上述输出结果在两档输入线阻、两个输入 driver 的四个组合中相同；两档输出电阻共八个 model pair、四个 exact reread 均已真实运行和独立复算。这一反例用原始 STA 导出、原始 STA 测量，不以私有原型工具制造差异。20 kΩ 的 setup 输出 slack 差为正（约 +25.454305 ps，乐观），hold 为负（约 −25.454638 ps）；不能只记录绝对值后忽略方向。

固定源 `makeGateModelTable` 的输出 transition 表直接计算内部末级 gate table 的 slew，未通过当前分布输出 RC 网络重新产生输出端口 slew；gate timing arc 的选择、表格与输出 load 映射亦存在适用范围。线阻控制用于检验这一限制，不将小例子的失败直接当作 T6K 全部输出误差的唯一原因。

## 接收含义

1. 输入驱动上下文的归属已有可复算的定量说明。主线需要审查：限定有效驱动/阻抗/slew 场景、采用显式边界 RC 表示，或提出有证据的保守模型；不能针对这两份测量加常数就泛称问题解决。
2. 输出 slew 与输出 min/max/slack 仍单独接收；保留完整 V/SPEF/ODB 参考，继续核验输出模型的负载工作域。
3. 本轮没有更改 T6K 模型、任何原始观察或 1 ps 诊断阈值；完整宏资格仍 false，#127 保持开放。主线继续负责物理/功能/完整来源与冻结、审查集成，合格 C8 交付后再接收。

恢复入口：`input_driver_residual.py --probe PROBE_DIR --measured MEASURED_DIR --output NEW_JSON`；参考目录在同目录 SHA 索引，不覆盖旧输出。控制测试与实际 EDA 证据分别记录；协作登记/看板限制见 README/Issue 回执。
