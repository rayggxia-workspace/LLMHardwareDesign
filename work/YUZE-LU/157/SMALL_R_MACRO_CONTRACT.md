# 小容量R独立宏合同

Issue #157 / PR #160。本文定义研究候选的集成边界；物理是否通过以绑定实际文件SHA的验收记录为准，不继承生产R资格。

## 本体与数值

R-stream256包含两个各256条S32状态bank（合计2KiB有效载荷）、8路S32×S33乘法流水、8路S64跨块点积上下文、key/query系数、更新/输出向量、四抽头因果深度卷积的tap与历史缓冲以及命令/响应控制。256条等于32行×8lane，不是256个head或完整模型层。

当前状态bank是标准单元寄存器阵列，不是SRAM宏；2KiB只统计状态有效载荷，系数、历史、流水和控制另计。

GDN执行衰减、全局状态/K点积、误差、外积更新和Q读出；SSM执行衰减、注入、C读出及skip。外部控制负责顺序、state bank角色和跨分块事务。投影、外围归一化和激活不固化进R。这里实际新增的是专用宽算术，不假定原M/E免费具备这些能力。

关键舍入按RTL的round-to-nearest-even执行。状态/更新结果超S32范围时置错误；错误情况下写出的低位不能当作有效饱和结果，控制端必须中止事务而不提交。点积、各Q格式移位及溢出范围以冻结RTL和已执行整数参考为准，不把本研究整数测试推广成浮点等价或完整模型精度验证。

具体缩放是：key/query/tap为S16乘数，乘积或完整点积按14位右移RNE；decay/beta为U32乘数，乘积按31位右移RNE；skip系数为S32，乘积按16位右移RNE。状态、输入和历史的S32公共数值尺度由调用端保持一致，不能把S32直接解释成IEEE FP32。8路点积是S64，乘法流水保留S65乘积；分块之间先合并完整点积，再舍入。

## 外部端口

|接口|合同|
|---|---|
|load|128bit valid/ready；目标选择状态bank、系数、当前向量、参数或历史/tap；状态每包4个S32，系数每包8个S16|
|state read|128bit、bank/index寻址；异步版R256为组合读，索引必须在当前bank合法范围；R1024S另有两拍固定读延迟，不能共用零延迟调用假设|
|command|valid/ready；3bit操作、行数、bank角色、清点积标志及模式。R256合法状态运算行数1–32；算子序列不是生产R原ISA|
|response|512bit valid/ready、error；下游必须遵守背压，完成响应不等于跨分块全局提交|
|clock/reset|冻结300MHz研究约束；reset复位协议/控制状态，状态数组及历史/系数需在有效使用前装载|

以下是现有test_r_stream/test_r_stream_sync逐命令断言的延迟：从命令被采样的上升沿之后计数，到rsp_valid首次置1；不含外部装载、状态换页和响应消费等待。

|cmd_op|含义|响应延迟cycle|
|---|---|---|
|0 / 1 / 2 / 3|衰减 / K点积 / 外积更新 / Q或C读出点积|cmd_rows + 2|
|4|全局误差与beta更新|4|
|5|完整点积舍入及可选skip|SSM模式5，其他模式2|
|6|四抽头8lane点积|6；随后cmd5完成输出舍入|
|7|清除全局错误和点积|采样沿直接响应（0）|

R256行批命令的有效cmd_rows为1–32；非法行数直接错误响应。命令执行期间不接受新load，系数/操作数应先装完；响应在背压下保持。state read没有独立ready/valid，调用端必须按bank角色、合法地址及读写碰撞合同安排访问。

## 换入换出与事务

超过256条的状态由控制端分块交换。全局dot/error在换页间保留；全部分块运算及写确认成功后才改变全局版本。不能每块提交一次冒充全局原子更新。控制器、DDR/S搬运及跨块提交成本已在RTL/SystemC研究中显式计算；该控制成本原型并非已完成全系统物理集成。

冻结S是16KiB标准单元存储、四个128bit 1RW bank、共享窄口及宽读仲裁。不得把另一个任务的SRAM版本、额外端口、预取重叠或DDR旁路带入本轮成绩。Qwen1024条strip在R256内需4块，Falcon2048条strip需8块；代价见[容量和换页实测](SMALL_CAPACITY_REVIEW.md)。

## 物理交付边界

内部仅使用Nangate45现有M1–M10；信号接点保持本轮固定M10坐标与形状，未来M11/M12互联不在本轮宏验收内。R256采用1000×1000µm die；标准单元面积与die面积分别报告。新输入缓冲也计入面积、提取、等价、PG和原版GDS DRC，不能只在图上补接口。

交付视图是实际最终GDS、ODB、DEF、门级网表、SDC、SPEF及由最终数据库/寄生生成的LEF和典型角Liberty。典型角300MHz独立宏结果不等于多角工艺签核、生产R替换或完整LLM/系统已实现。容量512/1024/2048的综合或周期结果不继承R256的物理资格。
