# 九实例布线与试验路径电气迭代

本轮延续 [被动试布](remote-acceptance.md)。九块仍按 P×3、U×2、C×1、F×1、J×2 摆放。P、C、U 的输出驱动使用工程候选视图，F、J 使用原验收视图。

## 试布与改版

| 对照 | 改动 | 实测结果 |
| --- | --- | --- |
| 被动直连 | 保持原验收 M1–M10 底座 | 296/296 通过研究几何检查，基准 RC 下 296/296 超原 BUF_X4 负载上限 |
| 原生输出缓冲 | P、C、U 增加 34、131、131 个 BUF_X32，原信号 pin 坐标保留 | C 在原摆位的高 RC 负载下 setup −12.5 ps |
| 缩短 C/U 距离 | U0 向下移动 1160 µm，C0 与 U0 之间保留 196 µm | 24 个尝试中 22 个通过全网几何检查。C 加载候选的高 RC 及 40 fF 负载后 setup +4.7 ps，hold +9.4 ps |
| P 的 VALID 加中点缓冲 | 在 P16 原生层内添加 BUF_X32 和一对 M10 接点 | 4800 µm 的单线拆为 2416 和 2400 µm。高 RC 的路径 setup 由 −239.1 ps 改善至 +33.9 ps |

紧凑版在 10332 × 9328 µm 外框内摆齐九块并保留 45 个不重叠的控制、传输、侧边接入、时钟和供电预留区。最终连通包含 296 条逻辑连接及 297 根上层物理网。P 的 34 条连接对应 35 根物理网。C/U 的 262 根网包含 256 根数据、2 根 VALID、2 根存储确认和 2 根 READY 到代理端点。逐网几何、连通和独立 KLayout 回读通过，所有 via10 在实际 M10 图形内。上层 GDS 仅含 M11/M12 及两类上层通孔。

缓冲属于冻结前的原生 M1–M10 工程改版。三种更新视图保留原有信号 pin，P 增加两枚中继接点。逐单元网表检查分别比对了 43497、274819、117544 个原实例的连接。C 和 U 局部释放相邻实例给缓冲器腾出位置，原有输入信号的外部端点合同保持一致。

## 300 MHz 组合试验

TT 1.1 V、25 °C。P、C、U 门级网表配合原生抽取 RC，顶层为理想共享时钟，各块内使用原生传播时钟。M11/M12 使用 0.7 倍和 1.5 倍研究 RC，四段分布模型。将父级 SPEF 先读入，再拼接块内 SPEF。两次读回的线电容随模型变化，避免把无上层寄生的结果计作闭合。

| 接收路径组 | 低 RC 最差 setup / hold | 高 RC 最差 setup / hold |
| --- | ---: | ---: |
| P M→G 的数据、VALID、TAKE | +285.5 / +1433.4 ps | +33.9 / +1513.2 ps |
| C/U 的数据、VALID、存储确认至寄存器 | +398.2 / +657.2 ps | +367.5 / +681.2 ps |

组合试验保留所有代理边界报告。高 RC 下复位到组合 READY 代理输出的最差 setup 为 −543.9 ps，U 命令输入到内部触发器的最差 hold 为 −2.8 ps。该试验的正裕量覆盖表中的真实接收寄存器，READY 仍使用代理，父级控制、PG、CTS 和完整顶层时序需在真实实现上验收。M11/M12 参数来自研究规则，工艺 RC 未校准。
