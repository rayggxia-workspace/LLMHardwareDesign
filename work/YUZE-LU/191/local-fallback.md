# 本地回退与负载初筛

远端 SSH 登录握手持续超时。以下结果通过本地可运行的构造器和独立审计生成。它们补充 Issue #191 的证据，远端详细布线结果仍待回收。

本地 C/U/F LEF 直接取自 #189 的验收包。C/U 的负载检查读取同包最终网表和原 Liberty。P/J 目前使用验收版图可视化中导出的 pin 中心，以 2 µm 方形重建研究端点。P/J 原始 LEF 在远端已经和验收包核对，但此次本地路径未读入该原件。

| 候选 | 独立几何与连通检查 | 输入边界 |
| --- | --- | --- |
| 纵向相邻 C0↔U0 | 262/262，简化间距违规 0 | 两边 Block 使用真实 LEF。2 根 ready 的另一端是代理。 |
| 纵向相邻 C0↔U0 加 P0 M→G | 296/296，简化间距违规 0 | C/U 真实 LEF，P M10 矩形近似。 |
| 裁切 P0 M→G | 34/34，简化间距违规 0 | P M10 矩形近似。 |

每个九实例候选都检查了 33 个不重叠预留矩形，包含控制、传输、侧面接入、PG 与时钟走廊。这里只落实摆位预留。

C/U 的真实输出驱动由最终网表追到 Liberty。研究规则的均匀电容近似为约 0.1554 fF/µm，先只算上层线电容。在纵向候选，262/262 根估算均超过原驱动上限，即使用每根网的曼哈顿距离作为最短线长也如此。例如 C0→U0 数据位 49 的构造线长为 7768 µm，均匀线电容约 1207 fF，对应 BUF_X4/Z 上限 242.31 fF。其曼哈顿长度为 3712 µm，对应约 577 fF。应先比较横向布置和分段驱动，再做校准寄生、真实接收端负载与完整 STA。该初筛未计算耦合、电容工艺校准或真实 parent PG/时钟。
