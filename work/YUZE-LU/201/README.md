## 上层容量与三排对照

Nangate45 的默认标准单元 PDN 在 M1、M4、M7，M8 没有同一用途的独立电源条。作业 98329 的早期容量脚本覆盖了其他层的默认设置，作为不受控结果保留。作业 98394 改为先加载原 Nangate45 FastRoute 配置，只覆盖 M7/M8 的容量调整。G 200 µm 把这一调整从 0.25 降至 0 后，GRT 溢出从 295 降到 0，仍未达到详细布线验收。G 210 µm 的两排和三排都通过原生及完整 GDS DRC，分别在 98430_2 和 98418_3 的独立电气门失败，保留 220 µm 两排为交付。G 220 µm 同尺寸的三排候选在独立原生 DRC 中出现 M2 间距标记。E 三排和四排有通过原生物理与完整 GDS 规则的候选，最终选择面积更小且最大空区更少的 340 µm 两排 E。
