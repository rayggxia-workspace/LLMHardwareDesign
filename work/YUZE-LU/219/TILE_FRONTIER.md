# Algo1 自动分块与 Qwen 首层对照

2026-11-14 CST。Refs #219，基线 3e696988d18829a583d573b8cb474ae587301660。

## 自动分块

类型化算子图入口按算子签名、属性、张量形状和切片轴匹配已有硬件配方。切片必须覆盖原张量范围。编译器沿数据依赖自动发现可共用切分网格的连通区域，并检查区域外可见结果的拼接配方。DP 比较整算子方案和最多 `--event-tile-trials`（默认 8）个自动布局，按模型工期、DDR 字节和静态线束成本排序。

同个算子内按原本的 tile 顺序排定。某个原算子有已排和未排 tile 时计为部分排定。DP 按原图依赖的可达关系限制同一依赖链上同时部分排定的原算子数，`--event-tile-depth` 默认为 2，设为 0 关闭自动分块。运行时的并行、窗口生命周期和完成事件仍由所选绑定决定。

## 原生范围命令

从原生整数原语的实际数据依赖自动发现可分块算子。每条范围命令执行完整输出行，其归约包含整个 归约长度 或归约轴。两段沿用原张量布局和绝对记录地址，使用原分配的临时区域，同一算子的后一段等待前一段结束以保护暂存。可证明行对齐的上下游只等待对应范围的末次存储确认。重排视图、无法证明对齐的广播、矩阵右操作数和未分块端点仍等待整份输入。

每段发出带绝对迭代范围和目标 DDR 记录区间的 `RUN_LOOP` 控制 IR。服务时长和访存按现有原生叶命令与逐字记录合同计算，检查两个范围覆盖原工作量。范围自带的末次确认由执行器解释，现有 Block V2 产品入口仍需实现并验证范围指令编码和物理 ACK。普通整算子提供者不会自动继承到范围服务。

## Qwen2.5-3B 第 0 层

使用真实权重、归档整数图和 Block V2 有限循环服务模型。Batch 1、序列长度 2，层入口已经拿到 Embedding 结果。原始图含 30 个派发任务、120 个硬件绑定。自动发现 23 个原算子可分成两段，得到 53 条派发、212 个绑定。远端回放按生成指令逐段登记写入提交，在消费时核对对应外存记录已经可读。词元 `[1,2]` 和 `[42,43]` 的层输出均与整算子回放逐位一致。两种深度均保留同一原始数值程序及常数。
