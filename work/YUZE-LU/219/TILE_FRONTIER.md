# Algo1 自动分块与 Qwen 首层对照

2026-11-14 CST。Refs #219，基线 3e696988d18829a583d573b8cb474ae587301660。

## 自动分块

类型化算子图入口按算子签名、属性、张量形状和切片轴匹配已有硬件配方。切片必须覆盖原张量范围。编译器沿数据依赖自动发现可共用切分网格的连通区域，并检查区域外可见结果的拼接配方。DP 比较整算子方案和最多 `--event-tile-trials`（默认 8）个自动布局，按模型工期、DDR 字节和静态线束成本排序。

同个算子内按原本的 tile 顺序排定。某个原算子有已排和未排 tile 时计为部分排定。DP 按原图依赖的可达关系限制同一依赖链上同时部分排定的原算子数，`--event-tile-depth` 默认为 2，设为 0 关闭自动分块。运行时的并行、窗口生命周期和完成事件仍由所选绑定决定。

## 原生范围命令

从原生整数原语的实际数据依赖自动发现可分块算子。每条范围命令执行完整输出行，其归约包含整个 归约长度 或归约轴。两段沿用原张量布局和绝对记录地址，使用原分配的临时区域，同一算子的后一段等待前一段结束以保护暂存。可证明行对齐的上下游只等待对应范围的末次存储确认。重排视图、无法证明对齐的广播、矩阵右操作数和未分块端点仍等待整份输入。

每段发出带绝对迭代范围和目标 DDR 记录区间的 `RUN_LOOP` 控制 IR。服务时长和访存按现有原生叶命令与逐字记录合同计算，检查两个范围覆盖原工作量。范围自带的末次确认由执行器解释，现有 Block V2 产品入口仍需实现并验证范围指令编码和物理 ACK。普通整算子提供者不会自动继承到范围服务。

## 同一块 SRAM 驻留

编译器沿范围任务的依赖自动找有明确 128 位记录格式的生产与消费。当前支持直接对齐的 Dot 左输入和逐元素 Convert、Product、Add。按原生宏绑定确认最终写入 SRAM 和读取 SRAM，保留所需资源预约，检查临时区、活跃窗口和版本地址。窗口位置从每站点既有容量分配，放不下的中间值仍采用原生外存脚本。覆盖一个仍有未来使用的唯一片上副本之前，先写回 DDR。跨站点优先选择满足到达时间和成本的已声明可用路径，缺路径时经过 DDR。

计价只扣除每个消费站点一次可明确替换的 DDR load，以及生产端一次数据写回。后续宏内部访存暂按原模式计价，归约、权重格式和每条原语不变。显式回退仍付相同的逐记录 DDR 描述符成本。范围控制 IR 携带窗口地址和版本，`COPY` 等目的提交确认，`RUN_LOOP` 等相应前驱，放行前验证窗口中确实有正确版本。写回路径缺失或覆盖窗口会由原生控制解码和独立调度校验检查。

## Qwen2.5-3B 首层远端对照

真实权重和整数原语，batch 1、序列长度 2，沿用归档 Block V2 计算及 PR182 外存时序模型。比较整算子、原始全外存范围命令、相同窗口机制强制写回，以及允许片上驻留。23 个原算子可自动分成两段，范围计划含 53 条计算派发。另外列出的 COPY 是模型内显式命令，每条命令传送一个 tile。两组输入 `[1,2]` 和 `[42,43]` 的输出均与整算子逐位一致。

束宽 8 时 3 次回读、5,120 B 从 DDR 移除，束宽 32 时 6 次回读、17,408 B 从 DDR 移除。折合总层读写 50,583,128,704 B 的比例不到 0.00004%。强制 DDR 的工期已比旧范围模型略低，因为独立搬运可在不同通道重叠。束宽 32 下同样的条件再允许驻留，关键路径短 10,240 个模型拍。两档 P0.S 和 U0.S 活跃交接峰值均为各 8,192 B，另有各 128 B 原生暂存。

QK 的两段各有 512 B。M 在 P0 生成，后续 S32 缩放在 P0.M 和 U0.E 均读该数据。归档未声明可用的 P0.S→U0.S 路由。P0 可用原地副本，U0 仍经 DDR，六次写回均保留。本版对大投影仍以完整行作为分块单位。例如 MLP 的一行有 11,008 条 16 B 记录，远大于 16 KiB 的单块 SRAM，所以当前没有把大值记为片上可留。产品 Block V2 的范围执行编码和其物理 ACK 未纳入本次模型回放。
