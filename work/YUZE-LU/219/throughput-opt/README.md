## 首个改进重点：操作数准备的循环不变量（正在实施）

现Dot配方每个输出都执行S32分量准备；A(r,k)不依赖输出列n。
只针对实际3分量输入，将A准备调用从R*N*K减少到R*K，B准备与所有乘加、最终舍入保持。
分量放在显式外存区，地址base+((r*K+k)*a+c)，容量与生命周期必须计账；不假设私有S装下整张矩阵。
preparation_reuse.py生成模型名无关的配方，测试以一维字地址验证分量值与地址唯一性、容量和边界。
