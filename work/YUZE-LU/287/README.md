## 实际电路和范围

- C V3、U39 v02 的网表/ODB/SPEF SHA逐项匹配main回执，见inputs.json。基线作业119509：C setup/hold +272.389442/+6.445178 ps，U +17.806424/+0.566186 ps。U与文档17.839730 ps差约0.033306 ps，记录本次实际读回值，不改验收阈值；原SDC序列化周期为3.3333ns。
- 原计划的`outgoing_data→incoming_data`在U39到达延后接回的叶宏边界，作业119514虽执行成功，但不作为完整接收路径结果。最终改为原生128位`C.native_tx_data_o→U.native_rx_data_i`电气回放（119515）。这两个口属于原生控制传输框架；本轮不证明C响应包可直接作为U合法命令，也不等于原存储数据接口的C→U功能闭环。原计划该功能路径仍需正确接回U切口后另验。
- 保留父层真实门级单元、输入二极管和块内寄生。仅删除导出网表中无任何端口连接的FILLCELL/TAPCELL实例，以免定制井填充master缺LEF阻止链接；逐实例记录physical-only-removed.json。子叶宏和SRAM仍用原验收Liberty，并非所有子宏晶体管展开。报告的跨块路径本身起止为真实父层寄存器。
- 共用理想父层时钟源，源slew为0；块内时钟树传播，uncertainty=0.1ns。测试周期5ns、3.3333333333ns。其余外部输入slew0.05ns，IO max/min 0.8/0.2ns、外部输出2fF。连接后的内部数据线不保留外部set_load。父层时钟/控制/握手物理路由未实现。
