# Fixed-route A/B rebinding gates

No A/B routes or macro port rectangles are edited by this procedure. It can fail if new native routing overlaps old escapes; a failure must be reported before changing geometry.

1. Lock final C/U ODB/DEF/GDS/V/SPEF/SDC and G/S leaf views. Compare all BPin rectangles, macro transforms and selected macro ITerms against the pilot baseline. Use explicit B G hierarchy mapping from G-geometry-comparison.json. Final streamout must contain the upgraded G macro, not the original GDS accidentally retained by a parent config.
2. Export the new final ODB geometry and BTerm ports using the original export-C/U scripts in `/public/home/yuzelu/PingyangHuang/hpy-pr276-stress976.nTAy3LMX/run-export.sh` and its `export-ports.tcl`, but point AUDIT_ODB at new final artifacts and write only a new YUZE-LU directory. The original exporter derives its native geometry Tcl from a historical job; freeze/copy that resolved file and hash it rather than relying on a changing sacct lookup.
3. Original lower escape geometry is `lift-nine-C0` / `lift-nine-U0` plan.json, lower-paths.txt, lift-receipt.json. Final A accepted additions are already materialized in `/public/home/yuzelu/PingyangHuang/hpy-cu-p0-gate-top.2Ovvdrcq/landing-closure.xh8Q7CUU/lower-overlay.json`. Its `by_terminal` shapes preserve original escapes and accepted M10 landing additions. Reuse these exact shapes.
4. The original collision entry is `landing_overlay.py:lower_source/session/finish`, using `lower_rules.py:Checker.verify`. It checks original native geometry hashes; do NOT change expected hashes merely to bypass assertions. Record a new binding receipt with old and new hashes, verify unchanged BPin contract, then replay archived fixed lower shapes against new native geometry. The supplied `replay_lower_overlay.py` does this incremental M7-M10/via7-via9 collision check using explicit new exports and transforms. Native numerical nNNN owners are not stable across databases: derive owners from NEW ports.tsv, keyed by exact BTerm names.
5. Coordinate transforms must be explicit. A lower-overlay stores its final A placement coordinates. New native exports are block-local; use the selected A placement.json transform. For B, prepare.py copies C/U geometry with extra dx=72000/dy=200000 DBU, but verify this against the archived spec/pin rectangles and layout before using it. A placement-mapped visualization was not previously revalidated; never assume its display transform certifies routed geometry. The replay script requires separate native and overlay transforms and does not guess them.
6. Collision replay is only a first gate. Build a new GDS assembly with final routed native C/U and unchanged lower overlay, top segments and vias. The original `stream_overlay.py`, launched by `run_stream.sh`, streams post-metal overlay and checks exact rectangle readback; it does NOT alone prove assembled native+overlay full DRC. Repeat original top router geometric/connectivity checks on frozen A/B spec/routes, plus independent assembled net connectivity from actual final BPin to landing, no foreign-net joins, correct via enclosures and boundaries.
7. Run the same complete native FreePDK45 deck on the assembled native/lower geometry and the existing extension rules for custom M11/M12/via10/via11. Record exact deck hashes, hierarchy/top names, layer mapping and resulting counts. Do not equate legacy Checker success or overlay GDS readback with complete DRC. Exclude P networks as requested while retaining physical neighboring P obstacles if present in the selected layout.
8. Before/after hashes of A/B route/spec/placement files prove no top geometry was modified. Any blocker is reported with terminal, layer and rectangles. A changed escape or top route requires a new explicit route variant; it is not silently part of rebinding. Geometry acceptance still does not establish RC/STA top performance.

`replay_lower_overlay.py` has passed Python compilation only. It has not been run against final artifacts; its result must retain that narrow incremental-rule scope.
