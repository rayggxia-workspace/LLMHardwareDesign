## 方法与独立检查

1. `native_snapshot.py` 从六个唯一原 ODB 导出实际布线、过孔与端口，记录网络身份、层次及 SHA；相同类型重复实例复用同一来源。OBS 不当成金属。
2. P/J 内仍有子宏，单独读取外层 ODB 会漏内部导体。`native_topology.py` 从完整同版 GDS 的 metal1--metal10/via1--via9 恢复物理金属连通，纳入嵌套单元，并逐一核对真实 M10 接口。多边形必须精确拆成矩形；遇到不支持的几何拒绝，不用外接框代替。
3. 接口原生网络与相同上层网络合为同一导体，防止把已经相连的落点错误作为两块不同电位金属。PG 在小信号模型中视为理想交流地，保留其实际形状；不把宏范围视为地平面。
4. 在单一接口网络为 1、其余电极为 0 的 Maxwell 激励下，未直接接上层的剩余原生电极按实例归并为统计列。这不改变该基函数的电场；汇总列不等于真实信号短接，也不自动识别悬浮导体或器件阻抗，不能直接写成物理 SPEF 信号。若用于动态或悬浮导体有效负载分析，还需保留其身份及电路条件。
5. 分别记录原上层几何与新增原生几何来源的通量。统计归属本身不改变真实金属几何、介质或导体电位；原求解器高斯面的区间合并问题另行修复并做失败回归。统计分组通过线程、反射、标签不改总场、空组和等电位归并控制；局部电荷、偏置/深度及分布寄生仍独立核验，不能由总 C 的统计门槛代替。

## 对比口径

- 同一几何和电阻率下的 DC 上层电阻保留原值，不将介质/电容环境变化误报为电阻率变化。
- 对地 C、上层互容、对下层信号的互容及上层来源总电容分别统计。不能只看互容比例，更不能把不同统计口径相减。
- 目的网络分类必须准确：`other_boundary_nets` 包含该接口网络实际连接的上下层分支，`unbound_native_electrodes` 是其余原生电极汇总。旧字段 to_upper/to_native 指目的网络类别，不是末端金属来源。对地、总互容及其他接口网络互容的变化分别给出，来源分区的行不保证互易对称。
- 电容变化报告绝对值、逐网百分比及分位数，分开很小的分母与求解统计误差。上下文深度和高斯面偏置须做收敛对照。
- 现有 0.3% 标准误差门槛针对完整物理网络总 C；上层来源是其中一部分，其相对标准误差另列，不能自动沿用“总 C 已通过”的精度声明。逐网来源 σ 和与旧原始行的保守差值区间均保留。
- 同时比较受影响的下层接口电容和关键路径时序。仅“上层 C 相差少于某百分比”不足以认定宏模型能直接复用；目前没有用户指定或已验证的统一百分比接收门槛。
- 原传输模块 300 MHz WNS 为 -7.74 ns，原产品完整时序未通过。新增耦合误差与原有速度问题必须分开报告。
- 宏接口诊断的每一行，是该顶层线两端宏中与它连通的 M1–M10 金属电荷合计，包含两端共享 M10 落点。它不是某一个宏的独立输入电容，也不含晶体管器件电容，不能把该百分比直接当作 Liberty 输入电容或内部时序弧误差。

## 最终结果

三步寄生对比已完成：复用原完整上层提取，加入十个宏的真实 M1–M10 金属，再逐网比较。**旧上层电容需要更新；宏内部时序模型能否直接复用，尚未验收。** 电容变化不会按相同比例变成延迟变化。

| 指标 | 结果 |
| --- | ---: |
| 上层电容相对原值的变化，中位数 | +1.149% |
| 变化的 95 分位数 | +20.434% |
| 最小 / 最大变化 | −1.254% / +49.898% |
| 最大绝对增量 | 128.947 fF |
| 原几何、电阻率不变时，上层 DC 电阻变化 | 0% |

变化率分母为耦合前上层 C。以耦合后结果为参考时，旧上层 C 的绝对相对误差中位数为 1.141%，95 分位 16.967%，最大 33.288%。两种分母不能混用。95 分位表示约 95% 的网络变化不高于该值，不是置信区间。

最大变化的真实连接为 P1 io_rsp_valid[0] → T0 pj_rsp_valid[1]：233.648 → 350.233 fF，增加 49.898%；提高精度后为 348.718 fF，仍增加约 49.25%。四根变化较大网络的精细复核与主结果最大相差 0.534%，不足以解释约 50% 的变化。

七组宏接口抽样中，沿用原下层金属贡献、更新上层贡献时，合计线网金属电容的近似误差为 **0.029%–1.059%**；最差样本保守 95% 区间上界约 1.356%。这是两端宏相连金属的抽样诊断，不含器件电容，不是单个宏的输入电容或时序弧误差。样本未覆盖所有接口或宏类型，不能据此宣布整套宏时序库合格。下层金属自身的抽样相对变化可达 −11.094%，但其在整条线网中的占比较小。

宏内部模型可作为后续验证的复用候选。当前没有已约定的统一接收门槛，也没有耦合后完整 STA，不将任何百分比自动标为“可接受”。
