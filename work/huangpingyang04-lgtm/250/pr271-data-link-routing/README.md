## 调整底座并布通两组

1. 用原生 ODB 尺寸更新 9 个实例涉及的 5 类宏，调整行内坐标，消除 C0/U0、F0/U1、J1/U0、J1/U1、U0/U1 五处重叠。首次完成 606/641 条。
2. 比较 P1 左右镜像（MY，平移 0.19 µm 对齐 0.2 µm 网格）与错位摆放。首次镜像为 614/641，冲突分组重布后，错位摆放为 638/641，镜像为 639/641。
3. 在镜像布局增加两个 2×2 µm 的 M10 接点，分别把 `U0.link_rx_addr[0]` 的接点向北引 56 µm、`P0.aux_data[74]` 向北引 4 µm，达到 641/641。独立几何检查和 KLayout OAS 回读核对了 1,278 个 V10、3,396 个 V11，以及 637 根 M11/M12 信号网。
4. C0.E32 与 U0.N32 在本地复用已导出的 C–U SRAM 通路和预留、提交及 ACK 握手。P0→P1 按远端 lane 0 布请求、响应和标签相关信号。Verilator 的 `ffn_gate_up_mid` 定向回归将 Gate、Up 均绑定远端读，64 次响应握手全部在完成前收齐，16 个 Mid 字与本地供数逐位一致。
5. 调整版中 C0 的现有接收口已用于 Attention，E32 缺少独立远端操作数入口；投影链路留到原坐标版试验。可选的 P1→P2 按 K 窗口供数同样留到后续前端试验。

## 保留 #271 原坐标并试接四组

1. 保留方案 A 原有 12 个实例的坐标、朝向和宏版图，P1 维持 R0。在 C0 和 P2 附近的空隙分别加入 S128 远端读前端 `C0_projection_reader` 与 `P2_down_reader`。U0 有 128 个未导出的端子，沿原生网的 M10 接点引出，并保留本地 S↔N32 支路。
2. 对 P1 的 128 条原生 M10 引出做局部详细布线筛查。94 条受局部 DRT 问题阻塞，34 条通过该项筛查。最终叠加层纳入其中 32 条已被顶层路径使用的引出。
3. 从探索性布线中锁定通过独立几何检查的 618 条，并导出合并 OAS。KLayout 回读核对了原有 12 个实例、两个新增读前端、618 根顶层信号网、2,985 个 V11，以及 1,320 个 V10 的完整 M10 支撑。其余 341 条属于顶层待布。
4. C0.E32 定向回归覆盖远端 A 操作数的 ADD2、ADD3、PRODUCT，A 绕开 C0.S 本地读，B/C 保持本地。新增 SRAM 读前端的定向回归覆盖两个窗口的标签、错误返回、反压与退休。两个前端的模块级验证仍需接到原生 C0.E32、P2 的 `cp_*` 接口和实际算子调度。
