# PR #271 方案 A 顶层布线与中继对照

2026-11-15（中国标准时间） · Refs #250、#228

使用作业 114252 的两份逐位 handoff。摆位来自方案 A 作业 112878。上层占用输入为空，三个 P 的 4,251 根 DMA 网按 handoff 假设留在下层。1,184 网版本仅移除 650 根 U0↔DMA 网，Gather 替代通路尚未加入。M11 横走、M12 纵走，粗轨距 4.2 µm，细轨距 0.2 µm，接点窗口半径 8 µm。沿用交接的线宽和 V10/V11 间距、方向及边界。

## 如何比较

1. 每个配置先用 PR #259 的 `route_net` 在同一场景逐网做直连。本实验在加速配置中使用加权曼哈顿优先级，部分配置预留唯一 V10 落点，并允许按原方向及间距规则检查跨多格的连续平面线段。原始 `run.py` 对照独立提交。试验脚本放在本目录，不修改路由库。
2. 对直连通过的网，用实际生成的总长度、孔数和统一接收端电容做负载筛查。对无法布通的网记录几何失败。每类取限额内的单接收端样本。
3. 在空隙内生成虚拟 `BUF_X32` 候选，块包络作为放置禁区。候选用两段曼哈顿距离和估算负载筛选，每网最多试六个。试布前释放该网的旧路线，其他已布网保留。两段各调用 A*，独立检查全部输出路线、切孔间距、落点、几何连通和中继独占。负载超限的几何恢复单列记录。
4. 对同一批诊断样本再做无中继重试，保留相同固定邻线，给一段直连的预算为六个候选双段试布的总预算上界。对八组加权及八组长段配置的配对样本，用 Nangate45 TT Liberty、300 MHz 理想时钟及几何生成的高研究 RC 在 OpenSTA 分析。采用统一 `BUF_X4` 启动输出与 `DFF_X1/D` 接收负载。此前的高 RC 系数为 1.5，线电容为 0.2330855775 fF/µm，线电阻为 0.0225 Ω/µm，过孔模型为 0.2 fF、0.12 Ω。

原版 CLI 作业 114370/114371 分别用时 1:38:54 和 1:03:58。Slurm 将退出码 2 标为 FAILED，路由器以该退出码表示保留了通过几何校验的部分结果。两套分别有 1,734/1,096 根用尽预算、73/63 根找不到可用接点。加权 4 的定点修复作业 114451/114452 均以 0 退出。

加权 4 对照中，两套都诊断并试布 24 网。1,834 网配置选择 11 个虚拟 buffer，超载逻辑网由 257 降至 248。1,184 网配置选择 13 个，超载网由 131 降至 120。两套各新增布通 1 网。无中继复试也各新增布通 1 网，其中新增的直连依然超载。预留唯一落点的配置各将 `grid_access_not_found` 降到零。其余失败集中在搜索预算和当前占用下的路径搜索。单独拿出加权 4 路由失败样本做同预算隔离复试，在各 36 个样本中，1,834 网有 31 个、1,184 网有 30 个在空占用下可布通，两套都仅有 1 个在保留邻线时布通。

加权 3 的无中继复试把两套的布通数分别推到 **286 / 1,834** 与 **178 / 1,184**，其中新增 7 和 10 网。中继组分别新增 6 和 7 网，超载总数从 257 降到 248、从 147 降到 133。直连复试对同一批已经布通而超载的长线，未把任何一根降到电容上限以内。此处的直连复试用一段搜索的最大预算 72,000，对应 6 个中继候选各试两段、每段最多 6,000 节点。

## 范围与证据

两版仍存在大量未布通网。结果覆盖给定 toy 端点与研究规则。虚拟中继在摆位空隙参与算法试布，供电、下层接入和可制造位置待实际实现核验。布线几何由 PR #259 的独立检查器核验。配对 STA 来自工具实跑，使用假设的端点模型和几何生成 SPEF，整芯片全量 STA 与工艺签核待做。
