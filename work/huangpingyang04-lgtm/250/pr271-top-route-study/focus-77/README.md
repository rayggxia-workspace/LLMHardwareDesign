# PR #271 方案 A 的 77 个接入失败点复查与空板重布

2026-11-16（中国标准时间） · [PR #276](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/276) · Refs #250、#228

沿用 PR #271 方案 A 摆位、1,184 根网和原顶层规则。从前一轮作业 118302 的逐网清单取 77 个实际卡住的接点，涉及 77 根不同的网。70 根在只保留固定接点时能找到完整线路，7 根的候选线路仍有几何冲突。所有正式作业从零条 M11/M12 布线和零个 V11 开始；旧 825 根仅作逐网对照。

## 入口预留与 V11 排查

- 作业 118338 枚举接点局部可接的 M11 主轨短段，先给候选最少的接点分配，逐个检查同已留短段、固定端点的间距。原位置同时分配成功 69 个。`C0/outgoing_data[82]` 的原位置在本次试探中没有可用的 M11 入口候选。
- 只针对该 C0 接点，作业 118344 保留原模块摆位和固定下层占用，验证 M7–M10 新路径的连通、间距和原、新 M10 接点包围。新 M10 在 C0 南侧。作业 118345 复验全部 70 个入口都能同时预留。正式作业把这些短段放在普通入口预留之前，处理对应网时从指定主轨接入并复核整个网。[入口分配记录](reservations.tsv)
- 另外 7 根的首个几何失败样本全为同列 V11 过近，孔中心相距 0.4–2.4 µm，低于规则要求的 4.2 µm。CUGR 最后一阶段重试避开冲突孔位，并尝试在相邻位置符合间距的情况下调整 V11。另一路径先为各接点试配间距合规的短段，再从主轨用 CUGR 连起来。[V11 诊断记录](v11-audit.tsv)
- 完成优先试布后继续按可用路线数量安排其余网。成组重布首先检查仍未通的重点网，只有新网和临时拆除的旧网全部通过核验才提交，失败恢复原线路。最终候选来自本轮空板作业。独立验证覆盖接点包围、连通、线和孔间距。
