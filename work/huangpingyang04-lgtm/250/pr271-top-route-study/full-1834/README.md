## 交换器周边容量

作业 115463 找到一个局部截面容量上限。交换器 `sw` 的外框宽 376 µm、高 300 µm。共有 909 根独立逻辑网，一端 M10 落点在框内，另有一端在框外。按 M11 横向、M12 纵向，过框的路线分别消耗左右边和上下边的容量。两根不同网的中心至少相距 4 µm（2 µm 线宽加 2 µm 线距）。

- 左边和右边各最多 `floor(300 / 4) + 1 = 76` 根。
- 上边和下边各最多 `floor(376 / 4) + 1 = 95` 根。
- 四边合计至多 **342** 根，至少短缺 **567** 根。

这个上限允许任意连续的轨道起点，也未扣除过孔、转角和占用。另一次独立复算直接用完整 M10 引脚矩形判定内外侧，得到完全相同的 909 个网 ID。仅增加搜索预算、改变搜线顺序或在交换器外插入 buffer，仍须遵守这一上限。80 万状态上限的作业 115447 在复核容量后停止，未产出最终可验收路线。

在保留全部连接、继续采用方案 A 摆位的前提下，后续需要改交换器的引脚逃逸。例如用底层先把足够多的信号接到外框之外，再从外部 M10 落点送入 M11/M12 路由。按本次外框上限，至少需要为 567 根改变过框方式，实际数量还需在逐位绑定和几何复验后确定。上表仍是部分布通。
