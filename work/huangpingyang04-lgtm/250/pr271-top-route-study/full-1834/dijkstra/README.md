# PR #271 方案 A 的两级 Dijkstra 顶层布线

2026-11-15（中国标准时间） · [PR #276](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/276) · Refs #250、#228

保留作业 112878 的方案 A 摆位和作业 114252 的完整交接。输入含 1,834 根顶层逻辑网，其中 U0↔DMA 650 根。沿用相同的 M10 落点、引脚窗口、M11 横向与 M12 纵向规则。布线从空的后制层开始。

## 方法

1. 在引脚窗口内以累计代价搜索合法接入短线，得到通向主轨道的候选落点。
2. 以 5×5 条主轨道为一个粗格，在两层粗图上运行多源 Dijkstra。用已布线段长度和过孔估计剩余资源，按 CUGR 式 (8) 的剩余资源倒数给粗格边计价。把粗路径扩成两层引导区，并在首轮细搜未找到路径时扩宽一格重试。
3. 在引导区内再次用 Dijkstra，按累计线长、过孔和局部拥塞代价扩展。每步检查已占用几何、线距及过孔间距。每次细搜最多展开 55,000 个状态。细层拥塞成本采用简化资源权重。
4. 每组做三轮全网规划，并优先重排上一轮失败网。选取该组布通数最多的一轮做最多两轮局部拆线重布。每次最多挪四根已布网，只有这些网都恢复才接受新的路线。所有重布也使用两级 Dijkstra。

CUGR 的原始方案还包括 3D 模式布线初始化、概率溢出成本和全局引导补片。本实验移植其粗细两级迷宫搜索，按本项目固定两层和落点输出实际线段与过孔。[论文 §III-D](https://cwpui.com/doc/c10.pdf#page=4) · [CUGR 的 Dijkstra 实现](https://github.com/cuhk-eda/cu-gr/blob/9b1aa8a7db4e32877614d7a4f6aa983254e626ce/src/single_net/MazeRoute.cpp#L38-L92) · [本次路由源码](dijkstra-maze.cpp)
