## 顶层迷宫布线与回退

寻路只使用 CUGR 最后一阶段的细粒度迷宫循环，不运行模式布线和粗粒度迷宫。`FastMaze` 保留上游的代价堆、多个树起点以及到达端点后的状态更新，整板每个作业的前 24 次实际尝试还同时运行逐字节提取的上游 `MazeRoute::route()` 核对候选线段和过孔。整板轨道、引脚窗口和成本是项目适配，校验只覆盖这些实测调用。为密集接点临时保留通到主轨的短段，处理对应网时释放预留。遇到同一网的过孔间距冲突时，屏蔽冲突位置并重跑同一个细粒度循环。

局部重布最多暂时拆掉四根与候选线路相冲突的旧线。只有新线和被拆旧线全部通过连通、线距和过孔检查才提交，否则删掉本次试线并恢复原来的线段和过孔。整板输出另用 Python 验证器核验原始交接网表覆盖、已布通网的几何与连通性、M10 新旧接点交接，并检查局部重布保留了当轮首遍已通的全部网。部分作业先逐根核验并复用旧作业中仍适用的线，其余作业从空板开始处理全部 1,834 根。[迷宫布线与局部重布](transactional-maze.cpp) · [作者源码及论文](../reference-stage2/README.md) · [独立核验](verify-top.py)

最佳作业布通 **1,130 / 1,834（61.6%）**，较上轮作业 116336 净增 396 根。经新 M10 接点布通的 763 根中，有 129 根用到了 U0 的新接点。未通 704 根中，母控报文 407 根、U0↔DMA 252 根、C0→U0 搬运 45 根。

该结果从作业 116790 出发。116790 读入上轮顶层路径，逐根核验后复用 453 根，在 1,007 个密集接点中成功预留 919 个接入短段。首次遍历完成 1,090 根，经直连重试和局部拆线重布达到 1,110 根。后续两次纳入同一布局的经核验互补候选，把结果提高到 1,121 和 1,125 根。这三次作业中 20 次局部拆线重布通过并提交，55 次失败回退。最后逐根尝试可补布的候选，由 1,125 根升到 1,130 根。独立核验确认最终仍布通了这轮初次遍历已通的所有网。更换接点后，上一轮 734 根中有部分旧路线不再适用。[作业输出及核验回执](evidence.json)
