# PR #271 方案 A 的 CUGR 第二阶段整板细粒度布线

2026-11-15（中国标准时间） · [PR #276](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/276) · Refs #250、#228

沿用作业 112878 的方案 A 摆位和作业 114252 的完整交接。输入包含 1,834 根顶层网，其中 U0↔DMA 650 根。M10 落点、引脚窗口、线宽线距、过孔规则及 M11 横向、M12 纵向保持一致。导出的格点图与两级 Dijkstra 和加权 A* 对照的 SHA-256 相同。

## 方法

只运行 CUGR §III-D 的细粒度迷宫阶段，搜索区域取整板合法边界。每根网从固定 M10 落点生成可达的主轨道接入候选，再在物理轨道图上用双向多源 Dijkstra 逐个连接接收端。队列按累计边代价扩展。平面边和过孔使用论文式 (4)、(5) 的代价形式，以五条相邻物理轨道的实际占用估计资源。线距及过孔冲突是硬约束。每次全板细搜由找到合法路径或队列收敛结束。作业从空布线状态开始，各按一种网序逐网提交合法路线。[CUGR 论文 §III-B、§III-D](https://cwpui.com/doc/c10.pdf#page=3) · [实现源码](stage2-router.cpp)
