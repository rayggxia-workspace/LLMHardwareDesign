# PR #271 方案 A 的少路径优先顶层重布

2026-11-16（中国标准时间） · [PR #276](https://github.com/rayggxia-workspace/LLMHardwareDesign/pull/276) · Refs #250、#228

沿用 PR #271 方案 A 和 [上轮空板作业](../clean-1184/README.md) 核验的 M10/V10 接点。四份输入文件逐字节一致，包括摆位承接、下层引出和 M11/M12 布线图。四组正式作业均从零条 M11/M12 线段、零个 V11 开始，网表严格为 1,184 根。

## 按可用路线安排顺序

作业 118268 在只保留固定接点的图上，用 CUGR 最后一阶段分别试探 1,674 个驱动端到接收端的连接。再提高已试过路线经过位置的代价，以采样原路径以外的走法。对每条路径读取主方向上四分之一、二分之一、四分之三处的轨道位置，利用相差至少两根轨道的样本区分通道。每个连接最多采样到三条不同路线。共有 42 个连接在试探范围内未找到合法路径，187 个只采到一条，145 个采到两条，1,300 个采到三条。该数量是当前搜索范围和采样规则下的估计。[逐连接采样](path-options.tsv)

每个接收端对应一项工作，短支线与长线按同一规则排序。先看试探通道多少，再看接点出口数。前三组只在同档优先级内改变端点密度与跨度的优先级。第四组用作业 118291 对多端网的 613 个接收端增加一次近端试探。每个接收端同时参考距离最近的同网接点，取两种试探中更少的路径数，154 个连接因此提前。112 个连接的近端跨度缩到 600 µm 以内。[含近端支线的排序数据](near-options.tsv)

为选择少或密集的接点暂留到顶层主轨的入口。在同一根网已有一部分布通时，新增支线从已有线段和 V11 组成的树上接入。只有完整网才纳入布通统计。顶层 CUGR 迷宫循环和原始版本在实际调用中作路径级对照。

成组重布按实际间距冲突确定需要临时拆掉的线路。新线和受影响的每根旧线一起通过连通与间距核验才采用，失败恢复原线。绕行和间距修复只调整顶层的 V11，改动后复验。补布阶段的候选均出自本轮空板作业。
